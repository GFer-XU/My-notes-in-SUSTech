# 环境监测 · 名词解释速记手册

> **使用方法：** ★★★ = 几乎必考，★★ = 高频，★ = 需要了解。每个名词给出"标准答案模板"（加粗部分是得分关键词）和"一句话记忆锚"。考前只背加粗部分+记忆锚即可。

---

## 一、总论与基本概念

### 1. 环境监测 ★★★

**定义：** 对环境中**污染物的种类、浓度、分布及变化趋势**进行测定，以**判断环境质量**的全过程。

> 记忆锚：不只是"做实验"，而是从采样到评价的完整工作链。

### 2. 污染物形态 ★

**定义：** 污染物在环境中呈现的**化学状态、价态和异构状态**。同一污染物不同形态具有不同毒性。

> 记忆锚：同样是铬，Cr³⁺低毒而Cr⁶⁺剧毒——"形态决定毒性"。

---

## 二、水质监测

### 3. 水体 ★★★

**定义：** **地表水、地下水**及其包含的**底质、水中生物**等的总称。

> 记忆锚：水体 ≠ 水。它还包括河床底泥和水里的生物。

### 4. 地表水 ★★

**定义：** 流过或汇集在**地球表面**上的水，如海洋、河流、湖泊、水库、沟渠中的水。

### 5. 化学需氧量 COD ★★★

**定义：** 在一定条件下，**氧化1L水样中还原性物质**所消耗的**氧化剂的量**，以**O₂的mg/L**表示。

> 记忆锚：Chemical Oxygen Demand = 化学方法"吃掉"的氧。重铬酸钾法氧化率≈90%，高锰酸钾法≈50%。

### 6. 高锰酸盐指数 ★★★

**定义：** 以**KMnO₄为氧化剂**测得的化学需氧量，反映地表水受**有机物及还原性无机物**污染的程度。

> 记忆锚：跟COD测的是同一回事，只是氧化剂弱了（KMnO₄ vs K₂Cr₂O₇），氧化率只有≈50%，适用于较清洁的水。

### 7. 生化需氧量 BOD ★★★

**定义：** 在**有溶解氧**条件下，**好氧微生物**在分解水中有机物的**生物化学氧化**过程中所消耗的**溶解氧量**。

> 记忆锚：Biochemical Oxygen Demand = 微生物"吃"有机物时消耗的氧。BOD₅ = 20±1℃培养5天的结果。

### 8. 总有机碳 TOC ★★

**定义：** 以**碳含量**表示水体中有机物总量的综合指标。采用**燃烧法**，能将有机物**全部氧化**，比BOD₅或COD更能反映有机物总量。

> 记忆锚：Total Organic Carbon。测法 = 高温燃烧→CO₂→NDIR红外测。TC − IC = TOC。

### 9. COD、高锰酸盐指数、BOD、TOC的关系 ★★★

**要点：** 四者都反映水中有机物/还原性物质的量，但覆盖范围不同。BOD只测**可生物降解**部分（最窄）；COD测**可被强氧化剂氧化**的部分（较宽，含部分无机还原物）；高锰酸盐指数用弱氧化剂（更窄）；TOC燃烧法测**全部有机碳**（最全）。**BOD/COD > 0.5** → 可生化性好；**< 0.3** → 含难降解/有毒物质。

### 10. 溶解氧 DO ★★★

**定义：** 溶解于水中的**分子态氧**。

> 记忆锚：Dissolved Oxygen。DO高说明水质好。碘量法和氧电极法测定。

### 11. 氨氮 ★★

**定义：** 水中以**游离氨（NH₃）和离子氨（NH₄⁺）**形式存在的氮。

> 记忆锚：只包括"氨"态的氮，不含有机氮和硝态氮。

### 12. 凯氏氮 ★★

**定义：** 以**凯氏（Kjeldahl）法**测得的含氮量，包括**氨氮**和在此条件下能转化为铵盐的**有机氮**。**不含**硝酸盐氮和亚硝酸盐氮。

> 记忆锚：凯氏氮 = 氨氮 + 有机氮；总氮 = 凯氏氮 + 硝酸盐氮 + 亚硝酸盐氮。

### 13. 总氮 vs 凯氏氮 ★★★

**总氮 = 有机氮 + 氨氮 + 亚硝酸盐氮 + 硝酸盐氮**（所有形态的氮）。
**凯氏氮 = 有机氮 + 氨氮**（不含硝态/亚硝态氮）。

### 14. 水体富营养化 ★★

**定义：** 水体中**氮、磷等营养物质过多**，导致**藻类过度繁殖**、水质恶化的现象。

> 记忆锚：太"营养"了→藻疯长→水变绿变臭→DO↓→鱼死。

### 15. 酸度 vs 碱度 vs pH ★★★

- **酸度：** 水中能与**强碱反应**的物质总量，是水的**中和碱**的能力（容量概念，单位mmol/L）。
- **碱度：** 水中能与**强酸反应**的物质总量，是水的**中和酸**的能力（容量概念）。
- **pH：** 水中**H⁺活度**的负对数（强度概念，无量纲）。

> 记忆锚：酸度/碱度是"能力大小"（容量）；pH是"酸碱强弱"（强度）。两者不等价。

### 16. 真色 vs 表色 ★★

- **真色：** **去除悬浮物后**水的颜色（溶解性物质引起）。
- **表色：** **未去除悬浮物**时水的颜色（溶解物+悬浮物共同引起）。

> 记忆锚：真色 = 过滤后的颜色；表色 = 原样颜色。真色 ≤ 表色。

### 17. 瞬时水样 / 混合水样 / 综合水样 ★★★

- **瞬时水样：** 某**一时间**、某**一地点**采集的水样。适用于水质稳定的情况。
- **混合水样：** **同一采样点**、**不同时间**等时/等比例采集后混合的水样。
- **综合水样：** **同一时间**、**不同采样点**采集后混合的水样。

> 记忆锚：**"混合 = 同点不同时；综合 = 同时不同点"**——这是必背的区分口诀。

### 18. 一类污染物 vs 二类污染物 ★★★

- **一类污染物：** 毒性大、能在环境或生物体内蓄积的有害物质（如总汞、总镉、总铬、总砷、总铅、苯并(a)芘等），在**车间或车间处理设施排放口**采样。
- **二类污染物：** 长远影响小于一类的有害物质（如pH、BOD、COD、氨氮等），在工厂**总排放口**采样。

> 记忆锚：**本质差别在于采样位置**——一类"源头控"（车间口），二类"末端控"（总排口）。

### 19. 削减断面 ★★

**定义：** 河流受纳废水和污水后，经**稀释扩散和自净作用**使污染物浓度**显著降低**的断面，通常设在城市或工业区**最后一个排污口下游1500 m以外**。

> 记忆锚：1500 m是关键数字。断面顺序 = 背景→对照→控制→削减。

### 20. 消解 ★★

**定义：** 在测定含有机物水样中的**无机元素**（如重金属）时，用**酸或其他试剂**将样品中的有机物**分解破坏**，使待测元素转化为**可测定的形态**（通常为溶液中的离子态）。

> 记忆锚：目的是"破坏有机物+溶解悬浮物+统一价态"。湿法消解用酸；干灰化用高温灼烧（450-550℃），但**不适用于易挥发元素（As、Hg、Cd、Se、Sn）**。

## 三、空气和废气监测

### 21. 一次污染物 vs 二次污染物 ★★★

- **一次污染物：** 污染源**直接排放**、理化性质**未发生变化**的污染物。如SO₂、CO、NOₓ、颗粒物。
- **二次污染物：** 一次污染物**在大气中相互反应**或与大气组分反应生成的**新污染物**。如O₃、醛类、PAN（过氧乙酰硝酸酯）、硫酸雾、硝酸雾。二次污染物毒性往往**更强**。

> 记忆锚：一次 = "原装出厂"；二次 = "大气加工后的产品"。O₃和PAN是最典型的二次污染物。

### 22. 光化学烟雾 ★★★

**定义：** 大气中的**氮氧化物和碳氢化合物**在**紫外光**照射下发生反应，生成的以**O₃和PAN**等为主的混合污染物。具有强氧化性，**刺激眼睛、损害植物**。

> 记忆锚：洛杉矶事件。NOₓ + HC + 紫外光 → O₃ + PAN + 醛类。最具破坏性的产物是O₃和PAN。

### 23. TSP / PM₁₀ / PM₂.₅ / 降尘 ★★★

- **降尘：** 粒径**>100 μm**，靠重力自然沉降的颗粒物。
- **TSP（总悬浮颗粒物）：** 粒径**<100 μm**的悬浮颗粒物。
- **PM₁₀（可吸入颗粒物）：** 粒径**≤10 μm**，能通过咽喉进入**气管和支气管**的颗粒物。
- **PM₂.₅（细颗粒物）：** 粒径**≤2.5 μm**，能深入到**肺泡**。

> 记忆锚：从大到小 → 降尘(>100) > TSP(<100) > PM₁₀(≤10) > PM₂.₅(≤2.5)。数字越小，越能进入呼吸道深处，危害越大。

### 24. 空气质量指数 AQI ★★★

**定义：** 将常规监测的**主要空气污染物浓度**简化为**单一数值**、**分级表示空气质量**和污染程度的指标。计算方法：分别求各污染物的**分指数IAQI**（线性内插），取**最大值**即为AQI。

> 记忆锚：AQI = max{各IAQI}。AQI>50时，IAQI最大者为**首要污染物**；IAQI>100为**超标污染物**。参与计算的项目：SO₂、NO₂、PM₁₀、PM₂.₅、CO、O₃。

### 25. 酸雨 ★★

**定义：** pH值**小于5.6**的降水（清洁雨水被CO₂饱和后pH约5.6-5.7）。主要由**SO₂和NOₓ**转化为硫酸和硝酸所致。

> 记忆锚：pH < 5.6 即为酸雨。我国西南地区是重酸雨区。

### 26. VOCs（挥发性有机物）★

**定义：** 室温下**饱和蒸气压超过133.32 Pa**的有机物，如苯、卤代烃、含氧烃等。具有毒性和刺激性，部分有致癌作用。

### 27. 等速采样 ★

**定义：** 测定烟道排气中**烟尘浓度**时，烟气进入采样嘴的速度应与采样点**烟气流速相等**。流速过大或过小都会造成测定误差。

> 记忆锚：只在固定污染源（烟囱）测烟尘时才需要等速采样。

### 28. 硫酸盐化速率 ★

**定义：** 大气中的**SO₂、硫酸雾**等含硫化合物在一定条件下转化为**硫酸盐**的速度。用碱片法或PbO₂法挂片暴露一定时间后测定。

## 四、固体废物监测

### 29. 固体废物 ★★

**定义：** 在生产、建设、日常生活和其他活动中产生的**污染环境**的**固态、半固态**废弃物质。

### 30. 危险废物 ★★★

**定义：** 列入**《国家危险废物名录》**或经鉴别具有**易燃性、腐蚀性、反应性、放射性、急性毒性、浸出毒性**等危险特性的固体废物。

> 记忆锚：六大特性 = **燃、蚀、反、放、急、浸**。只要具有**其中之一**即为危险废物。

### 31. 浸出毒性 ★★★

**定义：** 固体废物按**规定的浸出方法**进行浸取，浸出液中有害成分的**浓度超过鉴别标准**时所表现出的危险特性。

> 记忆锚：模拟固废进入填埋场后被雨水淋溶的场景——"浸出来的水有多毒"。

### 32. 急性毒性 / LD₅₀ ★★

**定义：** LD₅₀（半数致死剂量）是指能引起实验动物（小鼠/大鼠）在**48 h内死亡半数以上**的剂量。LD₅₀越小，毒性越大。

### 33. 份样 / 份样数 / 份样量 ★

- **份样：** 从一批固体废物中的**一个点或部位**按规定量取出的样品。
- **份样数：** 按固废批量大小确定（批量越大，份样数越多）。
- **份样量：** 一个份样的质量，由固废的**最大粒度**决定（粒度越大，份样量越大）。

### 34. 热值（高热值/低热值）★

- **高热值H₀：** 单位质量固废**完全燃烧**释放的总热量（含水蒸气潜热）。
- **低热值Hₙ：** 高热值扣除水分蒸发和加热消耗的能量后的实际可利用热量。

> 记忆锚：垃圾焚烧发电用的是低热值。

## 五、土壤质量监测

### 35. 土壤 ★★

**定义：** 陆地地表具有**肥力**并能**生长植物**的**疏松表层**，介于大气圈、岩石圈、水圈和生物圈之间，厚度一般约2 m。

### 36. 土壤背景值（本底值）★★★

**定义：** 在**未受或少受人类影响**的情况下，土壤中**元素的含量**。是判断土壤是否受到污染的**参照标尺**。

> 记忆锚：背景值 = "没被人碰过的状态下土壤里本来有多少"。实测值 > 背景值 → 可能被污染。

### 37. 混合样 vs 剖面样 ★★

- **混合样：** 在同一采样单元内多点采集、混合均匀后的样品，用于了解**污染状况**。耕地取0-20 cm表层，果林取0-60 cm。四分法缩分。
- **剖面样：** 在土壤剖面上**分层采集**的样品（A/B/C层），用于了解**污染深度**和垂向分布。剖面规格1.5×0.8×1.0 m，**自下而上**采。

> 记忆锚：混合样看"面上污染了没有"，剖面样看"污染到了多深"。

### 38. 单项污染指数 / 综合污染指数（内梅罗指数）★★★

- **单项污染指数：** Pᵢ = Cᵢ（实测值）/ Sᵢ（标准值）。Pᵢ > 1说明该项超标。
- **综合（内梅罗）污染指数：** P综 = √[(P̄² + P_max²) / 2]。兼顾**平均水平**和**最严重的单项**。
- **分级：** ≤0.7安全 → 0.7-1.0警戒 → 1.0-2.0轻污染 → 2.0-3.0中重污染 → >3.0严重污染。

> 记忆锚：内梅罗公式的精妙在于——即使平均不超标，只要有一项很高（P_max大），综合指数也会被拉高。

## 六、物理性污染监测

### 39. 声功率 / 声强 / 声压 ★★★

- **声功率W：** 单位时间内声波通过垂直于传播方向某指定面积的**声能量**，单位W。在噪声监测中指声源的**总声功率**。
- **声强I：** 单位时间内声波通过**垂直于传播方向单位面积**的声能量，单位W/m²。
- **声压p：** 声波引起的介质中**压强的变化量**（与静压之差），单位Pa。

> 记忆锚：功率是"总量"，声强是"单位面积上的量"，声压是"压力变化"。**叠加时声能/声强可以代数相加，声压不能直接相加。**

### 40. 声压级 Lₚ ★★★

**定义：** 声压平方与基准声压平方之比取以10为底的对数再乘以10（= 20 lg(p/p₀)），单位**dB**。基准声压**p₀ = 2×10⁻⁵ Pa**。

> 记忆锚：Lₚ = 20 lg(p/p₀)。p₀ = 2×10⁻⁵ Pa是人耳刚能听到的最弱声压。

### 41. 等效连续A声级 Leq ★★★

**定义：** 用一个**相同时间内声能量与之相等**的**连续稳定A声级**来表示该时段噪声的大小。它是评价**非稳态噪声**的基本量。

> 记忆锚：Leq是"能量平均"而非算术平均——同样60、60、70三段，Leq≈66 dB（偏向大值），不是简单算术平均的63.3。

### 42. 响度 / 响度级 ★★

- **响度：** 人耳判别声音由轻到响的**主观强度感觉**。单位**宋（sone）**。1宋 = 40 dB、1000 Hz纯音正前方的响度。
- **响度级：** 将待测声音与**1000 Hz纯音比较**，当两者听起来一样响时，该纯音的**声压级分贝值**即为待测声音的响度级。单位**方（phon）**。

> 记忆锚：响度是"主观感觉有多响"（宋），响度级是"等效成1000Hz纯音有多少dB"（方）。

### 43. 计权声级（A计权）★★

**定义：** 通过噪声测量仪器中的**计权网络**（特殊滤波器），模拟**人耳对不同频率的灵敏度**而测得的声压级。A计权模拟人耳对**55 dB以下低强度噪声**的频率响应，是环境噪声监测中**最常用**的计权方式。

> 记忆锚：A计权 = 模拟人耳听觉曲线。环境监测几乎都用A计权，所以Leq通常就是LAeq。

### 44. 声级计 ★

**定义：** 按照一定的**频率计权和时间计权**测量声音的**声压级和声级**的仪器，是声学测量中**最常用的基本仪器**。

### 45. 放射性衰变（α/β/γ）★★★

- **α衰变：** 不稳定重核（Z>82）放出**⁴He核**（α粒子），质量数减4、原子序数减2。
- **β衰变：** 原子核放出**电子**（β⁻）或正电子（β⁺），实质是核内质子与中子互变。
- **γ衰变：** 处于激发态的原子核向低能态跃迁时放出**电磁辐射**（γ射线），不改变质量数和原子序数。

> 记忆锚：α放"氦核"（大块头）→ β放"电子"（小颗粒）→ γ放"光"（电磁波）。穿透力：α最弱 < β < γ最强。

### 46. 半衰期 T₁/₂ ★★★

**定义：** 放射性核素因衰变**减少到原来一半**所需的时间。

> 记忆锚：T₁/₂越短→衰变越快→短期危害大但消散快；T₁/₂越长→长期持续辐射。

### 47. 照射量 / 吸收剂量 / 剂量当量 ★★★

- **照射量X：** X = dQ/dm，单位**C/kg**（旧单位伦琴R）。描述X/γ射线在**空气中产生的电离能力**。
- **吸收剂量D：** D = dε/dm，单位**Gy（戈瑞）**。**单位质量物质吸收的辐射能量**。
- **剂量当量H：** H = D·Q·N，单位**Sv（希沃特）**。考虑了**不同辐射的生物效应差异**（Q为品质因数）。

> 记忆锚：照射量看"电离了多少空气"（C/kg）→ 吸收剂量看"吸了多少能量"（Gy）→ 剂量当量看"对人体危害多大"（Sv）。**从物理到生物效应层层递进。**

### 48. 光污染 ★

**定义：** 包括**白亮污染**（如建筑玻璃幕墙的反射）和**彩光污染**（如霓虹灯、广告牌）等，对人的视觉和生理产生不良影响。

## 七、分析方法与仪器

### 49. 朗伯-比尔定律 ★★★

**定义：** 当一束平行单色光垂直通过均匀、非散射的吸光物质时，**吸光度A与吸光物质浓度c及光程长度b成正比**：**A = Kbc**。这是**分光光度法定量分析的基础**。

> 记忆锚：A = Kbc，三个变量——A吸光度、b光程（比色皿厚度cm）、c浓度。标准曲线法定量。

### 50. 分光光度法 ★★

**定义：** 基于**分子吸收光谱**的分析方法。将待测物通过显色反应转变为**有色化合物**，在特征波长处测量**吸光度**，依据**朗伯-比尔定律**进行定量分析。

### 51. 原子吸收光谱法 AAS ★★

**定义：** 基于**基态原子蒸气**对其**特征共振辐射的吸收**进行定量分析的方法。样品在火焰或石墨炉中被原子化为基态原子，空心阴极灯发出特征光通过原子蒸气后被吸收减弱，吸光度与浓度成正比。

> 记忆锚：AAS = Atomic Absorption Spectrometry。关键词："基态原子吸收特征光"。每种元素需要一根专用灯。

### 52. ICP-OES ★★

**定义：** 以**电感耦合等离子体**（ICP，温度6000-8000 K）为激发光源，样品被原子化、激发后**发射特征波长的光**，据**波长定性、强度定量**（I=aC^b），可**同时测定多种元素**。

> 记忆锚：跟AAS的根本区别——AAS看"吸了多少光"，ICP看"发了多少光"。最大优势 = 多元素同时测。

### 53. 色谱法 ★★

**定义：** 又称**色层法或层析法**，利用不同组分与**固定相和流动相**之间的作用力（分配、吸附、离子交换等）的差别，当两相做相对移动时，各组分在两相间进行**多次平衡**而达到**相互分离**。

> 记忆锚：本质就是"赛跑"——谁在固定相上待得久（分配系数大）谁跑得慢，先后出来就分开了。

### 54. 污泥沉降比SV₃₀ / 污泥体积指数SVI ★★

- **SV₃₀（污泥沉降比）：** 曝气池活性污泥混合液倒入1000 mL量筒中**静置30 min**后，沉降污泥体积与混合液体积之比，以**%**表示。
- **SVI（污泥体积指数）：** 30 min沉降后**1 g干污泥**所占的体积（mL），SVI = SV₃₀(mL/L) ÷ MLSS(g/L)。

> 记忆锚：SV₃₀看"沉了多少"（体积比），SVI看"1克干泥占多大地方"（结构松紧）。SVI过高说明污泥膨胀。

## 八、经典污染事件（案例题常用）

### 55. 日本水俣病 ★★

**关键词：** **甲基汞（Hg）**→ 工厂含汞废水排入海湾 → 汞在鱼贝体内富集 → 居民长期食用 → **中枢神经系统**中毒 → 对应"**汞的监测**"。

### 56. 拉夫运河事件（Love Canal）★

**关键词：** 美国纽约州 → 化学公司在废弃运河中**填埋危险化学废物** → 社区建在上面 → 居民患病、出生缺陷↑ → 对应"**危废填埋与渗滤液**"。

### 57. Times Beach事件 ★

**关键词：** 美国密苏里州 → **二噁英（dioxin）**污染的废油喷洒道路抑尘 → 全镇撤离 → 对应"**焚烧/二噁英、危废标准**"。

### 58. 洛杉矶光化学烟雾 ★★

**关键词：** 汽车尾气中**NOₓ + 碳氢化合物（HC）** → **紫外光**照射 → 生成**O₃、PAN**等二次污染物 → 刺激眼睛、损伤植物 → 对应"**光化学烟雾、二次污染物**"。

## 速查：易混概念对比一览

| 易混对 | 核心区分 |
|-------|---------|
| 混合水样 / 综合水样 | 混合=同点不同时；综合=同时不同点 |
| 一类 / 二类污染物 | 一类在车间排放口采样（源头控）；二类在总排口采样 |
| 真色 / 表色 | 真色去除悬浮物后测；表色不去除 |
| 总氮 / 凯氏氮 | 凯氏氮不含硝态/亚硝态氮 |
| COD / 高锰酸盐指数 | 氧化剂不同（K₂Cr₂O₇ 90% vs KMnO₄ 50%） |
| BOD / COD / TOC | BOD测可生化部分；COD测可化学氧化部分；TOC测全部有机碳 |
| 一次 / 二次污染物 | 一次=直接排放；二次=大气反应生成 |
| AAS / ICP-OES | AAS=原子吸收光；ICP=原子发射光。AAS不能同时多元素 |
| 湿法消解 / 干灰化 | 湿法用酸；干灰化450-550℃灼烧，不能用于As/Hg/Cd/Se/Sn |
| 声功率/声强/声压 | W总量/I单位面积/p压力变化。叠加时能量可加，声压不可直接加 |
| 照射量/吸收剂量/剂量当量 | X电离(C/kg) → D能量(Gy) → H生物效应(Sv)，层层递进 |
| α / β / γ | α放氦核→β放电子→γ放电磁波；穿透力α<β<γ |
