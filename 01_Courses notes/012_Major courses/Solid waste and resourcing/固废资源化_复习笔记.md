# 第 1 章 绪论与基本概念

## 1.1 固体废物的定义 ★

**固体废物**：在生产、生活和其他活动中产生的**丧失原有利用价值**，或**虽未丧失利用价值但被抛弃或放弃**的固态、半固态和置于容器中的气态的物品、物质，以及法律、行政法规规定纳入固体废物管理的物品、物质。

> 关键词：丧失利用价值 / 被抛弃 / 固态·半固态·容器中气态 / 法规纳入管理。

## 1.2 固体废物的四大特性 ★（名词解释高频）

| 特性 | 含义 |
|---|---|
| **无主性** | 被丢弃后不再属于谁，找不到具体负责者（尤其城市生活垃圾） |
| **分散性** | 丢弃、分散于各处，需要收集 |
| **危害性** | 给生产生活带来不便，危害人体健康 |
| **错位性** | 一个时空领域的废物，在另一时空领域是宝贵资源——"在时空上错位的资源" |

## 1.3 固体废物的危害

- 危害程度与固废**性质和数量**有关，处理依据主要是**当地环境污染控制标准**，控制程度与经济发展、民众生活水平密切相关。
- 主要污染物（控制对象）：**重金属、难降解有机污染物、恶臭、病原菌**，可通过水、气传播。

## 1.4 固体废物的性质

- **物理性质**：物理组成、色、臭、温度、含水率、空隙率、渗透性、粒度、密度、磁性、电性等。→ 决定**压实、破碎、分选**等处理方法。
- **化学性质**：元素组成、重金属含量、pH、营养元素（N/P/K）、C/N、BOD₅/COD、热值、灰分熔点、闪点燃点、挥发分、灰分、固定碳等。→ 决定**堆肥、发酵、焚烧、热解、浮选**等。
- **生物化学性质**：病毒、细菌、寄生虫卵等生物污染物组成、有机组分可降解性。→ 决定**堆肥、发酵、填埋**等生化处理。

## 1.5 固体废物的分类

- 按**化学成分**：有机废物 / 无机废物（也分有机固废、无机固废、电子废物、危险废物）
- 按**热值**：高热值废物 / 低热值废物
- 按**处理处置方法**：可资源化、可堆肥、可燃、无机废物
- 按**来源**：城市生活垃圾 / 工农业生产废物
- 按**危害特性**：有毒有害 / 无毒无害

## 1.6 处理与资源化方法层级 ★（论述）

按减量优先级（"无废—少废—资源化—末端处置"）：

1. **无废**（最高境界，但不可能）
2. **少废**（勤俭节约、清洁生产）
3. **源头分类**（生活垃圾、建筑垃圾为主）
4. **再用、再生** Reuse & regeneration
5. **加工处理**生产合格下游原料或产品
6. **焚烧**获取能源（供热、发电）
7. **卫生填埋**（生活垃圾）/ **安全填埋**（危险废物）

> 核心思想："师法自然 + 人为干预"——从堆场→卫生填埋→安全填埋的演进；从混乱杂乱到分类分选是**熵减过程**，从混杂体系回收有价物资也是熵减，难度递增。

**九类主要处理对象**：生活垃圾、危险废物和废液、建筑垃圾、电子废物、大宗工业废物、污水厂污泥（80%含水率）、污染土壤河湖泥、农林废弃物（生物质）、放射性废物。

# 第 2 章 生活垃圾分类

## 2.1 现状数据（了解）

- 全球每年约 20 亿吨固废，预计 2050 年达 34 亿吨；高收入国家（16% 人口）产生 34% 垃圾。
- 回收率最高：德国 67%、韩国 59%、斯洛文尼亚 58%。
- 中国每年约 2.2 亿吨城市生活垃圾，人均 0.8–1.2 kg/天，全国平均回收率 < 30%；2023 年焚烧处理 > 60%，填埋 < 40%，焚烧厂 > 600 座。

## 2.2 末端生活垃圾组成 ★

- 含水率 50–65%
- 塑料 12–18%（干重）、纸张 8–15%、纤维 20–30%、食品废物（湿重 60–70%、干重 20–30%）、建筑垃圾 10–20%
- 特点：**高含水率、组分复杂、混合后"脏"**——必须**分类收运**，否则资源化质量极差。

## 2.3 四种源头分类方案 ★（论述/选择）

| 方案 | 内容 | 特点 |
|---|---|---|
| **C₁** | 源头不分类 + 集中分拣 | 与现有模式相同，增中转/集中分拣 |
| **C₂** | 可回收 + 有毒有害 + 不可回收 | 单独收有毒有害，避免二次污染 |
| **C₃** | 可回收 + 有毒有害 + 干垃圾 + 湿垃圾 | 干湿分类，降低清运量 |
| **C₄** | 可回收 + 有毒有害 + 易腐烂 + 不腐烂 | 便于有机易腐垃圾资源化处置（最优） |

**确定分类模式的原则**：①实现减量化·资源化·无害化；②高含水率源头沥水降转运成本；③有价废物高效分类回收；④有机垃圾占比最大，由地方企业堆肥等资源化。原则补充：概念清晰易界定、可接受度高（建议干湿分类）、操作简单运行成本低。

## 2.4 四大类生活垃圾 ★

1. **有机易腐类**（厨余、植物残体、果皮）
2. **惰性无机废物**（灰土、煤渣、砖块、草木灰）
3. **可回收废物**（废纸、塑料、金属、玻璃）
4. **有毒有害废物**（废电池、农药瓶、日光灯管、油漆桶）

> "大分流、小分类"成为主流模式（先把建筑垃圾、大件垃圾、餐厨垃圾等大流分出，再细分类）。

## 2.5 小家电回收（作业 Ch2-3）

**小件废弃家电**：除"四机一脑"（电视、冰箱、洗衣机、空调、电脑）外，靠充电/蓄能电池维系运行、长宽高 30 cm 以下、易被错误丢入干垃圾的小型电子废弃物（剃须刀、电动牙刷、鼠标、移动电源等）。

- 回收价值观点：虽单件价值低，但**数量庞大、更换频率高、含贵金属与重金属**，集中回收具规模效益与环保价值（避免重金属污染 + 回收铜金等）。源头约占干垃圾 0.15–0.30%，末端约 0.75%。

## 2.6 收集与转运

**垃圾收集点布点原则**：定位设置、摆放整齐；点周 2–3 m 整洁；容器密封完好；特种垃圾用专用密封容器；分类、袋装、定时投放；特种/工业/建筑垃圾与生活垃圾分开收集；作业后车走地净，直送转运站或处置场。

**收运模式**：直运（收集车直接运至处理厂）/ 转运（经转运站压缩后大车运输）。转运适于运距远、规模大；优点降运输成本，缺点增设施投资。**选择运输模式原则**：经济性、运距、规模、环境卫生、交通条件。

## 2.7 传染病分类 ★（作业 Ch2-8，名词解释/选择）

按法定管理：

- **甲类**：鼠疫、霍乱
- **乙类**：艾滋病、病毒性肝炎、麻疹、狂犬病、登革热、肺结核等
- **丙类**：流行性感冒、流行性腮腺炎、风疹、急性出血性结膜炎等

**常见病菌死亡温度**（焚烧/堆肥灭菌依据）：多数肠道致病菌 55–60 ℃ 30 min 内死亡；新冠 56 ℃ 30 min 灭活；朊病毒（疯牛病）需 300–400 ℃ 持续 3–5 h。
**消毒分级**：高水平（含氯/二氧化氯/过氧乙酸/臭氧/紫外）、中水平（碘类/醇类/酚类）、低水平（季铵盐/胍类）。

# 第 3 章 固体废物预处理

## 3.1 破碎设备 ★

| 设备 | 原理 | 类型 |
|---|---|---|
| **颚式破碎机** | 动颚与固定颚成夹角，挤压破碎 | 简摆式 / 复摆式 |
| **圆锥破碎机** | 定锥与动锥两截锥体，偏心旋转挤压 | 旋回（粗碎）/ 菌形（中细碎） |
| **锤式破碎机** | 转子带锤头高速旋转，冲击+磨剥，篦条筛控制粒度 | 单转子 / 双转子 |

锤式：生产能力大、破碎比高、能耗低、结构简单；缺点是破碎坚硬料锤头磨损大、粘湿料处理能力降低。

## 3.2 粉磨 ⚙

**球磨机临界/适宜转速公式**：

$$n_c = \frac{42.4}{\sqrt{D_0}}, \quad n_t = \frac{32.2}{\sqrt{D_0}}$$

- nc = 临界转速，nt = 理论适宜转速（r/min）；D₀ = 筒体有效直径（内径 − 2×衬板厚度，m）。
- 实际工作转速一般为临界转速的 65–85%（多为 65–78%）。

**磨介填充率**：φ = Vₜ/Vₘ × 100%，一般 25–45%。

**粉磨流程**：开路系统（无分级，流程简单但易过粉磨、能耗高）/ 闭路系统（有分级，消除过粉磨、可调粒度、效率高，但流程复杂）。循环负荷率 K = 回料量/成品量，一般 50–300%。
**辊压机**：两辊挤压（50–500 MPa）形成"料饼"，"预应力粉碎"改善易磨性。

## 3.3 气力输送系统 ★（作业 Ch3-2）

**低压式气力输送**——两种模式对比：

| | 正压输送 | 负压（真空）输送 |
|---|---|---|
| 原理 | 风机置于进料端，**高压气流推送**物料 | 风机置于末端抽气形成**负压吸入**物料 |
| 进/出料 | 单点进料、可多点卸料 | 可多点进料、单点卸料 |
| 输送距离/压力 | 距离长、压力高、输送量大 | 距离短、压力低 |
| 优缺点 | 适合长距离大输量；但供料需克服正压、易扬尘 | 系统密闭无粉尘外泄、卫生好；但输量小、风机磨损大 |

关键部件：1-罗茨风机；2-回转给料器；3-给料仓；4-分路阀；5-过滤器（除尘器）；6-吸嘴。
其他：机械式（吹扫式回转供料器、螺旋输送泵、喷射泵）；高压（单仓泵、双仓泵串/并联）；栓流式（脉冲、密相低速，降能耗减磨损）。

## 3.4 干燥与脱水 ★

**物料与水分的结合方式**（作业 Ch3-3）：

1. **化学结合水**——离子结合、结晶水。**脱除不属于干燥范围**。
2. **物理化学结合水**——吸附水、渗透水、微孔毛细管水、结构水。
3. **机械结合水**——巨孔毛细管水、空隙水、润湿水。

- **平衡水分**：物料与一定温湿度空气接触达到的恒定含水量。
- **自由水分（可脱除水分）**：超出平衡水分、干燥过程能脱除的部分。
- 干燥与脱水主要针对**机械结合水和物理化学结合水中的自由水**。
- **去湿三方法**：机械去湿（浓缩、过滤）；化学去湿（浓硫酸、无水氯化钙、分子筛吸湿）；加热/冷冻去湿（蒸发或升华）。

**转筒干燥器**（作业 Ch3-5）——两种运行模式对比：

| | 顺流式 | 逆流式 |
|---|---|---|
| 气流与物料方向 | 同向 | 逆向 |
| 特点 | 脱水强烈、干燥速率大、终温低 | 干燥速率均匀、终水分低、热效率高 |
| 缺点 | 干燥速率不均、终水分受介质终湿度限制、含尘高 | — |
| 适用 | 初水分高、可强烈脱水、高温敏感/易燃料（粘土、矿渣、煤） | 终水分要求很低、不能强烈脱水（砂子、石灰石） |

## 3.5 分选设备 ★（作业 Ch3-6，论述+示意图）

分选原理基于物料物理/化学特性差异，通过机械、气流、磁场、电场、光学等实现分离。

### ① 风力分选（密度/粒度差异）

- **卧式风力分选机**：侧面水平送风，物料下落被气流吹散，按运动轨迹落入轻/中重/重质收集槽。水平风速 5 m/s 时轻质组分废纸约 90%、重质组分黑色金属 100%；最佳风速约 20 m/s。
- **立式风力分选机**：垂直上升气流，轻质随气流上行、重质沉降。分选精度高（≥95%），适合细微/轻质颗粒，占地小、能耗低。

### ② 磁力分选（磁性差异）

- 依靠磁场将磁性物质（铁磁性金属、危废电池）选出。
- 关键：选择合适磁场力 f_磁，使 **f_磁 > f_机（重力/离心力等机械力） > f_非磁**，从而磁性物被吸住、非磁性物落下分离。
- 设备：带式磁选机（电磁铁吸附磁性产品，刮片刮出）。

### ③ 静电分选（导电性差异）

- 高压发生装置对接地旋转辊筒放电形成高压电场。
- 物料经电晕电极带负电。
- **导体**（金属）导电性好，电荷迅速经接地辊释放，离心力作用下被抛入导体接料斗；**非导体**（塑料）电荷无法释放，吸附在辊筒表面，随转至后方由毛刷扫入非导体料斗。
- 金属回收率高（>90%），适于分离有色金属与塑料。

## 3.6 木塑复合材料 ★（作业 Ch3-7）

**木塑复合材料（WPC）**：木质纤维（木粉、竹粉）+ 热塑性塑料（PE、PP、PVC）+ 添加剂（偶联剂、稳定剂、润滑剂），经挤出/注塑制成。

- **主要成分作用**：木质纤维提供强度刚性；热塑性塑料提供韧性防水性；添加剂改善加工性能。
- **优势**：与木材相比——材质均一、耐水性好、易直接成型、加工方便；与塑料相比——热稳定性好、成本较低。
- 应用：栏杆、墙板、托盘、栅栏、户外桌椅、花箱等。

**常见塑料制品成分**（作业 Ch3-8）：塑料袋多为 LDPE/HDPE/PP；饮料瓶 PET；洗发水瓶 HDPE；方便面碗/吸管 PP。**抗高温性能最好的是 PP（聚丙烯）**（餐盒、可微波）。
**"脏料"来源**（作业 Ch3-9）：废塑料/木料表面附着的食物残渣、油污、泥沙、标签胶、混入的其他材质等，来自分类不彻底、清洗不到位与再吸附。

# 第 4 章 有机固废厌氧发酵

## 4.1 有机固废概述

- 中国有机固废产量世界第一，每年 60–100 亿吨，存量 200 亿吨。
- 来源三分：**生活源**（4 亿吨：生活垃圾、厨余、污泥、医疗废物）、**农业源**（40 亿吨：秸秆、畜禽粪污）、**工业源**（20 亿吨：废塑料、轮胎、菌渣、含油污泥）。
- 双重属性：**资源属性 + 污染属性**（碳=生物质能、氮=氮肥、磷=战略资源；重金属、新兴污染物、病原菌）。

## 4.2 厌氧发酵定义与过程 ★（名词解释 + 论述，作业 Ch4-2）

**厌氧发酵（厌氧消化）**：在无外加氧化剂条件下，被分解的有机物作为**还原剂被氧化**，另一部分有机物作为**氧化剂被还原**的生物学过程。

**三阶段**（基本生化过程）：

1. **液化（水解）阶段**：水解发酵细菌将大分子（纤维素、蛋白质、脂肪）水解为可溶性单糖、氨基酸、脂肪酸。
2. **酸化（产酸/产氢产乙酸）阶段**：产酸菌将水解产物转化为挥发性脂肪酸（乙酸、丙酸、丁酸）、醇、H₂、CO₂；产氢产乙酸菌进一步转化为乙酸、H₂、CO₂。
3. **气化（产甲烷）阶段**：产甲烷菌利用乙酸、H₂/CO₂ 生成 CH₄。

**三大类微生物**：水解发酵细菌 → 产氢产乙酸细菌 → 产甲烷细菌（数量最多最重要的是细菌，以厌氧菌和兼性厌氧菌为主）。

## 4.3 影响发酵的环境条件 ★（论述，作业 Ch4-3）

| 因素 | 要点 |
|---|---|
| **① 温度** | 常温（自然）、中温 28–38℃、高温 48–60℃。甲烷菌对温度敏感，温度波动影响大 |
| **② 营养比（C/N、C/P）** | 适宜 C/N =（20–30):1；磷需求约为氮的 1/5 |
| **③ 混合搅拌** | 使原料分布均匀、增加微生物与基质接触、及时分离产物，提高产气、加速反应 |
| **④ 添加剂** | 过磷酸钙促纤维素分解；K、Na、Ca、Mg、Zn、P 等微量元素促反应 |
| **⑤ 酸碱度 pH 与缓冲** | 水解/产酸菌适应 pH 5–6.5，甲烷菌 6.6–7.5；**pH<4.8 过度酸化、发酵停止**；丙酸积累是酸抑制主因（脂肪酸 >2000–3000 mg/L 受阻）；碱度应 >2000 mg/L 保证缓冲；氨毒性应 <1000 mg/L |
| **⑥ 生物固体停留时间（污泥龄 SRT）与负荷** | 容积负荷与发酵时间成反比；SRT 与厌氧效果直接相关 |

## 4.4 沼气发酵工艺分类 ★

- **按温度**：高温（50–60℃，产气率 >2.0 m³/m³·d，滞留期短）/ 中温（30–35℃，>1.0 m³/m³·d，应用最多）/ 常温（随气温变化，简单廉价，固废少用）。
- **按发酵级数**：单级（一个池，简单但条件难控）/ 两级及多级（分解彻底、滞留期长、投资高）。
- **按投料运转方式**：
  - **连续发酵**：连续进料，产气稳定，适于稳定来源（城市污水、大中型畜牧场粪便）。
  - **半连续发酵**（作业 Ch4-4）：一次性投较多原料启动，产气趋降时定期添新料排旧料，维持稳定产气率。**我国农村主要采用**。
  - **批量发酵**：一次投料，不添新料，产气先升后降，不均衡。
  - **两步发酵**（作业 Ch4-5）：①水解产酸池（高浓度原料，产浓挥发酸液）→②产甲烷池（以酸液产气）。**优势**：大幅提高产气率、甲烷含量提高、两阶段菌群分别优化、运行更稳定。

## 4.5 干式 / 半干式 / 湿式厌氧发酵 ★（作业 Ch4-6）

| 类型 | 罐内含固率 TS | 特点 |
|---|---|---|
| **湿式** | < 10% | 物料呈流动态；需压榨/稀释预处理；沼液量大、后续处理难；水耗能耗高；适合餐饮垃圾、污泥 |
| **半干式** | 10–15% | 居中；需较高去杂率 |
| **干式** | > 15%（原料 TS 20–35%） | 半固态、无流动液；占地小、流程简单、能耗低、沼液少；但易氨氮积累、产气率较低、传质难、对罐体搅拌要求高 |

> ⚠ 含固率 <10% 时罐内易分层，预处理须去除骨头贝壳（重）和塑料纤维（轻）；>15% 适当搅拌即可不分层、无需去杂。
> 干式工艺代表：Valorga、Kompogas、Dranco 等。

## 4.6 厌氧消化设备与设计 ⚙ ★

### 总需热量（保温，作业 Ch4-7）

$$Q = Q_1 + Q_2 + Q_3 + Q_4$$

- Q₁ = 加热料液到设计温度所需热量
- Q₂ = 维持消化器发酵温度所需热量
- Q₃ = 管道散热量
- Q₄ = 沼气及饱和水蒸气带走的热量

换热面积按热平衡计算，留 10–20% 余量。

### 中央隔断结构 ★（作业 Ch4-8，名词/简答）

消化罐内设长度约为直径 **2/3** 的中央垂直隔断墙：使罐内发酵物料围绕它形成圆周路径，物料只有走完平均为罐直径**两倍**的路径后才出料，**保证物料不短路（防短流）**、停留时间充足、发酵充分。物料进出口均在罐底、分列隔墙两侧；重力出料。

### 厌氧消化罐设计计算 ⚙（作业 Ch4-9）

$$V_{有效} = \frac{K \cdot Q_{有机} \cdot T}{D_{ave} \cdot N}, \quad V_{总} = \frac{V_{有效}}{E}, \quad VOL = \frac{Q_{有机} \cdot DM \cdot VDM}{V_{有效}}$$

- K = 峰值系数（1.1）；N = 消化罐数量；Q_有机 = 分选后有机垃圾量（t/d）；
- D_ave = 罐内消化物平均密度（0.95–1.05 t/m³）；T = 停留时间（32–35 d）；
- E = 有效容积比（0.83）；DM = 干物质百分比；VDM = 挥发性干物质百分比；VOL = 有机容积负荷。

**例**（300 t/d，含水率 65%，DM=35%，VDM=65%，D_ave=1，T=34，K=1.1，N=3）：
- V_有效 = 1.1×300×34/(1×3) = **3735 m³**
- V_总 = 3735/0.83 ≈ **4500 m³**
- VOL = 300×0.35×0.65×1000/3735/3 ≈ **6.09 kg VDM/(m³·d)**

## 4.7 沼气与沼渣沼液

**厨余厌氧沼气组分** ★（作业 Ch4-10）：CH₄ 40–65%、CO₂ 35–60%、H₂S 800–4800 ppm、O₂ <0.5%、N₂ <3.0%、饱和湿度、30–45℃。
- **能否直接替代天然气？不能**。原因：①CH₄ 含量低于天然气（>90%），热值低（沼气含 CO₂ 时 20920–25100 kJ/m³，天然气高位发热量 ≥31.4 MJ/m³）；②含 H₂S（腐蚀、有毒）、CO₂、水汽等杂质超标。需经**脱硫、脱水、脱碳（脱 CO₂）、脱氮**提纯后才能作天然气。
- 脱硫反应：Fe₂O₃·H₂O + 3H₂S → Fe₂S₃·H₂O + 3H₂O（再生：Fe₂S₃·H₂O + 2O₂ → Fe₂O₃·H₂O + 3S）。
- 沼气发热量 37660 kJ/m³；1 kg 有机物产纯沼气 200–300 L；1000 m³ 沼气 ≈ 600 m³ 天然气。

**沼渣沼液农用**（作业 Ch4-11）：欧洲多制成有机肥、液态肥土地利用；我国因①政策法规壁垒（标准/许可）、②生活垃圾来源沼渣沼液重金属/病原菌/盐分风险、③管理与市场不成熟，多外运焚烧（沼渣）、按污水处理（沼液），资源化率低。沼渣干化后多与生活垃圾混烧；沼液宜"预处理+生物处理+深度处理"。

## 4.8 餐厨垃圾预处理 ★（作业 Ch4-12）

- **餐饮垃圾**：餐馆、饭店、食堂的饮食剩余及后厨加工废弃物。
- **厨余垃圾**：家庭丢弃的果蔬、剩饭、瓜果皮等易腐有机垃圾。
- **餐厨垃圾** = 餐饮 + 厨余的总称。

**预处理 7 个子单元及目的**：①接收及滤水（滤出渗滤液）→ ②粗分选（去 ≥55 mm 大块杂质，效率 ≥90%）→ ③精分除杂制浆（破碎至 8 mm 浆料、去 ≥8 mm 杂质）→ ④除砂（平流除砂去砂砾，防磨损/沉积）→ ⑤螺旋挤压脱水 → ⑥除油（油水三相分离，回收油脂）→ ⑦杂物装载。
**目的**：去除杂质（保护设备、防分层）、调质制浆（提高传质与产气）、分离油脂（资源化+防抑制）、脱水调含固率。

# 第 5 章 有机固废好氧堆肥

## 5.1 堆肥化定义与原理 ★（名词解释 + 论述）

**堆肥化**：在**控制条件下**，利用自然界广泛分布的细菌、放线菌、真菌等微生物，使可生物降解的有机物转化为**稳定腐殖质**的生物化学过程。

定义强调：①原料是可生物降解固废；②人工控制（区别于卫生填埋、自然腐烂）；③本质是生物化学过程，产品稳定无害。产物即**腐殖土**（深褐色、疏松、泥土味）。

**好氧堆肥原理**：微生物新陈代谢，分为：
- **同化作用（合成）**：有机物 + O₂ → 细胞物质（微生物繁殖）
- **异化作用（分解）**：有机物 → CO₂ + H₂O + NH₃ + 能量（释放/转化为热）

化学方程：
- 不含氮有机物：CₓHᵧOᵤ + (x + y/4 − z/2)O₂ → xCO₂ + (y/2)H₂O + 能量
- 细胞质合成：n(CₓHᵧOᵤ) + NH₃ + O₂ → C₅H₇NO₂（细胞）+ CO₂ + H₂O + 能量
- 中温阶段细胞氧化：C₅H₇NO₂ + 5O₂ → 5CO₂ + 2H₂O + NH₃ + 热

## 5.2 温度动态变化与微生物演替 ★（论述，作业 Ch5-1）

| 阶段 | 温度 | 微生物 | 过程 |
|---|---|---|---|
| **中温（升温）阶段** | 15–45℃ | 嗜温性微生物活跃 | 易降解有机物分解，温度上升 |
| **高温阶段** | 45℃以上（50–65，极限 80–90℃） | 嗜热微生物 | 半纤维素、纤维素、蛋白质强烈分解；>70℃ 多数嗜热菌死亡/休眠；**杀灭病原菌、虫卵、杂草种子** |
| **腐熟（降温）阶段** | 降温 | 嗜温菌重新占优 | 内源呼吸后期，难降解物分解，腐殖质增多稳定化，需氧量↓、含水率↓ |

> 温度与微生物群落**耦合**：温度决定优势菌群，菌群代谢产热又驱动温度变化，形成"嗜温→嗜热→嗜温"演替。
> 无害化卫生要求：**>55℃ 持续 5 天以上**；蛔虫卵死亡率 95–100%；粪大肠菌值 10⁻¹–10⁻²。

## 5.3 好氧堆肥分类

- **按温度**：中温堆肥（15–45℃，不能有效灭菌，少用）/ 高温堆肥（50–65℃，灭菌、减臭，常用）。
- **按物料运动形式**：间歇式 / 连续式（机械连续进出料，周期 3–7 d）。
- **按堆制方式**：露天堆肥 / 强制通风条垛 / 筒仓式（静态/动态发酵仓）/ 立式发酵塔（多层）/ 卧式滚筒 / 箱式 / **膜覆盖系统正压好氧堆肥**。

**膜覆盖系统**：e-PTFE 膜（0.2 μm 微孔）阻挡粉尘/气溶胶/微生物，内表面冷凝水膜溶解 NH₃、H₂S、VOC 等臭气；通风均匀、发酵均匀、不形成厌氧区；微超压。

## 5.4 影响堆肥的主要因素 ★（论述，作业 Ch5-3）

**最主要三条件**：**通风供氧、含水率、温度**（高温二次发酵工艺）。

| 因素 | 适宜范围 / 作用机制 |
|---|---|
| **通风** | 目的：供氧分解有机物 + 带走水气干化。方式：自然/通风管/翻堆/风机强制通风 |
| **含水率** | 适宜 **45–60%**；水是微生物介质，影响孔隙度透气性；太低用粪水/污泥调节 |
| **温度** | 最佳 50–60℃；>55℃ 持续数天杀菌灭卵 |
| **孔隙结构** | 决定通风效率、密度、保水性；过小抑氧供给，过大降比表面积延缓降解 |
| **C/N 比** | （20–30）:1 或（4–30):1；过高速率慢、过低 N 损失大产生氨臭 |
| **C/P 比** | （75–150):1 |
| **pH** | 7.5–8.5 |
| **粒度** | 12–60 mm |

## 5.5 臭气的成分、来源与控制 ★（论述，作业 Ch5-2）

- **主要臭气成分**：氨（NH₃）、硫化氢（H₂S）、甲基硫醇、胺类、VOC、有机酸。
- **产生来源**：①**生物途径**——局部或某段时间内**厌氧**，蛋白质/含硫有机物分解产生；②**非生物途径**——高温挥发、pH 偏碱促 NH₃ 逸出。
- **控制方法**：
  - 工程控制：保证供氧均匀、避免厌氧区；密闭进料 + 膜覆盖 + 尾气处理；优化 C/N（提高 C/N 减少 NH₃）；控制 pH 与含水率。
  - 生物控制：生物滤池/生物洗涤、接种功能菌、添加生物炭等吸附剂（炭基辅料 20–30 d 显著降氨挥发）。

## 5.6 腐熟度评价 ★（名词解释 + 简答，作业 Ch5-4）

**腐熟度**：成品堆肥的稳定程度——工程上是反应完成信号，农业上是质量指标。

评价方法：
1. **直观经验法**：茶褐/黑褐色、无恶臭、质地松散、泥土芳香味。
2. **淀粉测试法**：碘液显色，淀粉含量越低腐熟度越高（残淀粉呈蓝黑色）。
3. **耗氧速率法**：微生物耗氧速率越低、腐熟度越高、生物越稳定。
4. **种子发芽指数（GI）**：发芽率 >90%（C/N=15–20）表示腐熟、无植物毒性。
5. 其他：C/N 下降至 15–20、温度回落至常温、腐殖化指标。

## 5.7 碳氮损失途径与减损 ★（论述，作业 Ch5-5）

**碳损失途径**：
- 60–70% 被微生物分解以 **CO₂** 形式损失
- 0.39–1.24% 局部厌氧产 **CH₄** 损失
- 0.3–0.6% 随渗滤液**淋溶**损失

**氮损失途径**：N 主要形态为铵态氮、硝态氮、有机氮；损失途径——硝化转为 NO₃⁻、**氨（NH₃）挥发（主途径，占 44–99%）**、被固定为铵化合物。

**减损方法（工艺优化）**：
- 调节 C/N（提高 C/N 减 C/N 损失，但过高有植物毒害）；通风速率 0.2 m·min⁻¹·m⁻³ 兼顾腐熟与减碳损。
- 添加调理剂：2–5% 木质素、蘑菇渣促腐殖质生成；**生物炭基辅料**吸附 NH₃ 减氮损。
- 接种微生物：链霉菌、高温放线菌促腐殖化、减矿化损失。
- 控制 pH 不过高、含水率适当、降低局部厌氧。

## 5.8 堆肥农用效益与危害 ★（论述，作业 Ch5-6/7）

**协同效益**：①**改土**——增有机质、改善结构、降容重、增孔隙、提高持水力（腐殖质带负电吸附 NH₄⁺/K⁺/Ca²⁺）；②**培肥**——增 N/P/K 及速效养分；③**促生增产**——促根系、提产量改品质；④**碳减排**——有机碳固持入土、替代化肥减排。
**潜在危害**（作业 Ch5-7）：①**重金属**累积（长期施用富集 Cd、Pb 等）；②**有机污染物 / 抗生素 / 微塑料**残留；③**病原菌、寄生虫卵**（腐熟不彻底）；④**盐分**累积、烧苗；⑤N/P/K 含量低（常 <3%）肥效有限。→ 须控制有毒有害物含量并跟踪监测土壤重金属。生活垃圾混合堆肥仅限园林、沙漠、盐碱地、滩涂绿化，不得用于食用作物。

# 第 6 章 热解与气化

## 6.1 热解定义 ★（名词解释）

**热解（Pyrolysis）**：利用有机物的热不稳定性，在**无氧或缺氧**条件下加热蒸馏，使有机物热裂解，经冷凝后形成各种新的气体、液体和固体，从中提取燃料油、油脂和燃料气的过程。

**三类产物**：
- **可燃气（煤气）**：C₁–C₅ 烃类、H₂、CO；
- **液态油（焦油/生物油）**：有机酸、芳烃、焦油、甲醇、丙酮、醋酸等；
- **固体燃料（炭/焦炭、炭黑）**：纯碳及聚合高分子含碳物 + 灰渣。

## 6.2 热解过程及产物特征 ★（论述，作业 Ch6-1）

随温度升高依次：**干燥 → 干馏 → 气体生成**。

| 温度区间 | 过程 |
|---|---|
| ~200℃ | 水分物理蒸发析出 |
| 250–500℃ | 干馏：结合水析出、脱氧脱硫、CO₂ 析出；纤维素/蛋白质/脂肪裂解为小分子气、液、固含碳物 |
| 500–1200℃ | 干馏产物进一步裂解，液/固化合物裂解为 H₂、CO、CO₂、CH₄ 等气态产物 |

中间产物两种趋势：①大分子裂解为小分子/气体；②小分子缩聚为大分子。涉及裂解、脱氢、加氢、缩合、桥键反应。**高温热解以吸热为主**。

**产物分布与条件**：
- 低温慢速（炭化）→ 固体焦类产率最大；
- 高温快速/闪速热解 → 气液产物最大化，气体热值 15–21 MJ/m³；
- 温度升高 → 气体（C₅以下、CH₄、H₂）增多、油类和固碳减少。

## 6.3 热解 vs 焚烧 ★（论述，作业 Ch6-2）

| 维度 | 热解 Pyrolysis | 焚烧 Incineration |
|---|---|---|
| 供氧 | 无氧/缺氧 | 过量空气（氧化） |
| 反应热 | 吸热 | 放热 |
| 主产物 | 可燃气、油、炭（**燃料，便于贮存远输**） | CO₂ + H₂O（热量就近利用发电/供热） |
| 温度 | 400–800℃ | 850–1100℃（>850℃ 控二噁英） |
| 环境 | 无氧抑制二噁英/呋喃，废气少 | 易生二噁英、NOₓ，需烟气净化 |
| 产物利用 | 油气可远距离运输储存 | 余热发电/供热，就近利用 |
| 适用 | 废轮胎、塑料、生物质制油制气、PCB | MSW、危废、医废大规模减量 |

## 6.4 影响热解的主要参数 ★（论述，作业 Ch6-3）

| 参数 | 影响 |
|---|---|
| **温度** | 低温多液体，高温多气体；定向调控核心变量 |
| **升温速率** | 低温低速→固体产率↑；高温高速→气体产率↑ |
| **停留时间** | 物料粒度小/温度高→反应时间短；分子结构复杂→时间长 |
| **湿度（含水率）** | 影响产气量与成分；高温下水也是反应物；含水率高→合成气热值↓ |
| **反应器类型** | 固定床 / 流化床（700–850℃，适细颗粒高湿低热值料，气固接触好）/ 回转窑 / 等离子 |
| **物料特性** | 粒度越小越易热解；化学结构、物理形态影响产率 |

> **定向调控**：要油→中低温、中等升温速率、适当停留；要气→高温、快速升温、长停留 + 焦油二次裂解；要炭→低温慢速热解。

## 6.5 气化主要反应 ⚙

$$C + O_2 \to CO_2 \ (-393\ \text{kJ/mol})$$
$$2C + O_2 \to 2CO \ (-221)$$
$$C + H_2O \to CO + H_2 \ (+135,\ 水煤气反应)$$
$$C + CO_2 \to 2CO \ (+173,\ 还原/Boudouard)$$
$$C + 2H_2 \to CH_4 \ (-84)$$
$$CO + H_2O \to CO_2 + H_2 \ (-38,\ 水煤气变换)$$

城市有机垃圾热解气主要成分：H₂ 49–54%、CO 21–24%、CO₂ 14–18%、CH₄ 6.5–12%。

## 6.6 固定床气化炉：上吸式 vs 下吸式 ★（论述+示意图，作业 Ch6-4）

固定床自上而下分层：**干燥层 → 热解层 → 还原层 / 氧化层 → 灰渣**（层序随气流方向不同而异）。

| | **上吸式（逆流）Updraft** | **下吸式（顺流）Downdraft** |
|---|---|---|
| 气化剂流向 | 自下而上，与物料逆流 | 自上而下，与物料同向（与下行物料并流） |
| 层序（自上而下） | 干燥→热解→还原→氧化→灰渣 | 干燥→热解→氧化→还原→灰渣 |
| 燃气出口 | 顶部（经热解/干燥层带出焦油） | 底部（经高温氧化区，焦油被裂解） |
| 焦油含量 | **高**（燃气未过高温区） | **低**（焦油流经氧化层裂解，气质好） |
| 气化效率/热效率 | 热效率高（出口气温低、显热回收好） | 略低，但燃气洁净 |
| 操作稳定性 | 简单稳定、适应性广 | 对原料粒度/水分要求高 |
| 优缺点 | 结构简单、可处理高水分料；但**焦油多、燃气脏**，后续净化难 | **燃气洁净、焦油少**，适合直接发电；但出口气温高、需处理细粉 |

**改进方向**：两段供风/中部供气、加内构件强化焦油二次裂解、加催化剂裂解焦油、与流化床/等离子耦合提高气质与碳转化率。

# 第 7 章 焚烧（计算重点章）

## 7.1 焚烧定义、优缺点 ★

**焚烧**：以一定量**过剩空气**与有机废物在焚烧炉内进行**氧化燃烧反应**，使有毒有害物质在高温下氧化、热解被破坏，同时实现**无害化、减量化、资源化**的高温热处理技术。

**优势**（作业 Ch7-1）：无害化（破坏毒性/灭菌）、减量化（减重减容 80–90%）、资源化（余热发电供热）、经济性、实用性、适应性广（固/液/气、生活/工业/危废）。
**局限性**：①炉渣热灼减率 3–5%（仍有未燃尽）；②气相残留 CO；③不完全燃烧产**二噁英**等高毒有机物；④飞灰富集**重金属、二噁英**（危废）；⑤经济性与资源化仍待改善；⑥需配套昂贵烟气净化。

## 7.2 燃烧术语与发热量 ★⚙

- **发热量**：单位质量（固/液）或体积（气）燃料完全燃烧、且产物冷却到燃烧前温度时放出的热量（kJ/kg 或 kJ/Nm³）。
- **高位发热量 HHV（Qgr）**：完全燃烧且产物中水蒸气**全部冷凝为水**时放出的热量。
- **低位发热量 LHV（Qnet）**：产物中水蒸气**仍为气态**时放出的热量（扣除水汽化潜热）。

> ★ HHV 与 LHV 的实际应用差异（作业 Ch7-3）：实际焚烧/锅炉烟气以**气态**排出，水汽化潜热无法回收，故**热平衡、热效率计算用 LHV**；HHV 用于燃料品质标定/理论比较。两者差值 = 烟气中水蒸气的汽化潜热。

**标准燃料**：标准煤 LHV = 29270 kJ/kg（7000 kcal/kg）；标准油 = 41820 kJ/kg；标准气 = 41820 kJ/Nm³。

**清洁燃料 vs 劣质燃料** ★（作业 Ch7-4）：

| | 清洁燃料（3 例） | 劣质燃料（3 例） |
|---|---|---|
| 实例 | 柴油/煤油、天然气(NG/LNG)、液化石油气(LPG)；焦炉煤气、水煤气 | 劣质煤（高灰高硫低挥发）、石油焦（硫>6%）、垃圾/污泥衍生燃料 |
| 判别依据 | 发热量高、灰分硫分低、燃烧充分、污染小 | 高灰分(≥35%)、低挥发分(≤10%)、低热值(≤4500 kcal/kg)、高硫(2–4% 甚至更高) |

水煤气理论组成：CO 50% + H₂ 50%；焦炉煤气主成分 H₂ 50–60%、CH₄ 20–30%。

## 7.3 维持燃烧条件与发热量公式 ⚙ ★

**维持 MSW 燃烧基本条件**：LHV > **3350 kJ/kg**（否则需添加辅助燃料）。

**LHV（Dulong 方程）**：

$$LHV = 81C + 342.5\left(H - \frac{O}{8}\right) + 22.5S - 5.85(9H + W) \quad \text{(kcal/kg)}$$

$$LHV = 340C + 1430\left(H - \frac{O}{8}\right) + 105S - 25(9H + W) \quad \text{(kJ/kg)}$$

- C、H、O、S、W 为各元素/水分质量分数（kg/kg）。
- **有效氢 (H − O/8)**：燃料中氧以结合水形式存在，与之结合的氢不可利用，须从全氢中减去。

**HHV ↔ LHV 转换**：

$$LHV = HHV - 2.442\left(\frac{9H}{100} + \frac{M_{ar}}{100}\right) = HHV - 0.206H - 0.023M_{ar}\ (\text{kJ/g 基})$$

（2.442 kJ/g = 水的汽化潜热；H = 氢质量%；Mar = 收到基水分%）

## 7.4 焚烧产物 ★

- C → CO₂；H → H₂O（有 F/Cl 时生 HF/HCl）；S → SO₂/SO₃；P → P₂O₅；
- 有机 N → 主要 N₂ + 少量 NOₓ；有机 Cl → HCl（氢不足时生 Cl₂：2HCl + ½O₂ ⇌ Cl₂ + H₂O）；
- 金属 → 视温度生成卤化物、硫酸盐、磷酸盐、碳酸盐、氢氧化物、氧化物。

## 7.5 理论空气量与过剩空气 ⚙ ★

**理论（最低）空气量 A₀**——完全燃烧所需最低空气量：

- 质量基准（kg 空气/kg 废物）：

$$A_0 = \frac{1}{0.232}\left[2.67C + 8\left(H - \frac{O}{8}\right) + S\right]$$

> 推导：完全燃烧耗氧（kg O₂/kg）：C+O₂→CO₂（32/12=2.67）；4H+O₂→…（8）；S+O₂→SO₂（1）；扣除自带氧 O。空气含氧质量分数 0.232，故 A₀ = O₂需求/0.232。

- 体积基准（Nm³ 空气/kg 废物）：

$$A_0 = \frac{1}{0.21}\left[1.866C + 5.6\left(H - \frac{O}{8}\right) + 0.7S\right]$$

> 1.866 = 22.4/12（C 燃烧每 kg 需 O₂ 体积）；空气含氧体积分数 0.21。

**理论空气需求量推导步骤**（作业 Ch7-5）：①写各元素完全燃烧反应式（C+O₂→CO₂；2H₂+O₂→2H₂O；S+O₂→SO₂）；②按化学计量计算耗氧量；③扣除燃料自带氧；④除以空气含氧分数（质量 0.232 / 体积 0.21）得 A₀。

**实际空气量** A = m·A₀（m = 过剩空气系数）。
**过剩空气率** = (m − 1) × 100%。废气含氧量可判别过剩空气状况。
**经验值**：焚烧固废 m = 1.2–1.9（过剩空气量 50–90%）；废液废气 m = 1.2–1.3。

**过剩空气的作用** ★（作业 Ch7-6）：实际系统氧与可燃物难理想混合，需多于理论的助燃空气保证完全混合燃烧。
- 过低 → 燃烧不完全、冒黑烟、有害物焚烧不彻底；
- 过高 → 降低燃烧温度、影响效率、增加排气量与热损失。

## 7.6 四大控制参数（3T + E）★（论述，作业 Ch7-2）

| 参数 | 要点 |
|---|---|
| **① 焚烧温度 Temperature** | 高于着火温度；含氰废物 850–900℃ 全分解；**>925℃ 防二噁英**；<1500℃ 抑 NOₓ；过高增金属挥发、NOₓ、需辅助燃料 |
| **② 湍流/搅拌 Turbulence** | 表征垃圾与空气混合程度；扰动方式：空气流、机械炉排、流态化、旋转扰动 |
| **③ 停留时间 Time** | 有害组分氧化燃烧所需时间，影响焚烧完善程度与炉膛尺寸（炉膛 >850℃、烟气停留 ≥2 s） |
| **④ 过剩空气 Excess air** | 保证充分供氧，过低不完全、过高降温增损 |

参数关系：燃烧温度↑可减小所需湍流、停留时间；过剩空气率↑会降低燃烧室温度、增热损失。

## 7.7 物质平衡与热平衡

- **物质平衡**：输入（生活垃圾 + 空气 + 水 + 化学药剂）= 输出（干烟气 + 水蒸气 + 废水 + 飞灰 + 炉渣）。
- **热平衡**：输入热（垃圾热值 Qr,w + 辅燃料 Qr,a + 助燃空气 Qr,k）= 有效利用热 Q₁ + 各项损失（Q₃化学不完全燃烧 + Q₄机械不完全燃烧 + Q₅辐射 + Q₆灰渣物理热 + 排烟热损失）。

## 7.8 焚烧系统组成（7 子系统）★（作业 Ch7-9）

完整焚烧系统流程：**垃圾接收 → 焚烧 → 余热利用 → 烟气净化 → 灰渣处理（+ 蒸汽冷凝水系统 + 渗滤液处理）**。

1. **垃圾接收系统**：储仓、抓斗（垃圾发酵沥水）。
2. **焚烧系统**：炉排炉/流化床/回转窑（新建以**机械炉排炉**为主）。
3. **助燃空气系统**：一次风（炉下，干燥助燃）、二次风（炉上，扰动燃尽降 CO）、烘干垃圾、冷却炉墙炉排。
4. **余热利用系统**：直接热能利用（小规模）/ 余热发电（13–22.5%）/ 热电联用（~50%）。
5. **蒸汽及冷凝水系统**：见 7.10。
6. **烟气净化系统**：脱酸（干法/半干法/湿法）、脱硝（SNCR/SCR）、除尘（袋式）、活性炭吸附二噁英/重金属。
7. **灰渣处理系统**：飞灰固化稳定化后安全填埋；炉渣资源化（建材）。

## 7.9 焚烧炉类型

- **机械炉排炉**：动/定炉排相对运动使垃圾翻动、搅拌、推进，依次干燥→燃烧→燃尽"三段"；适应性强、应用最广。
- **流化床焚烧炉**：固定层→沸腾流动层→循环流动层；600–750℃，气固接触剧烈、燃烧均匀，适细颗粒/低热值料。
- **回转窑焚烧炉**：先气化后燃烧，回转窑（650–800℃）+ 气化室 + 二燃室（>1200℃）+ 燃尽室；可处理固/液/半固多相废物，危废常用。

## 7.10 冷凝水与预处理 ★（作业 Ch7-10）

- **为何用大量冷凝水/冷却水**：①余热锅炉汽水循环需大量补水产生蒸汽发电；②烟气降温（急冷防二噁英再生成）；③设备冷却。
- **预处理目的**：地表水含悬浮物、硬度（Ca²⁺/Mg²⁺）、有机物、溶解盐，直接进锅炉会**结垢、腐蚀、积盐**。预处理（活性炭吸附 + 离子交换 + 反渗透）制成纯水/超纯水，**防结垢、防腐蚀、保证汽水品质与设备安全**。

## 7.11 重金属在焚烧中的转化 ★（分类举例，作业 Ch7-11）

按挥发性分类（瑞士焚烧厂元素分布为例）：

1. **难挥发性（留底渣）**：Cu、P 等——主要进入**炉渣/底灰**（Cu 96%、P 89% 入底灰）。
2. **半挥发性（富集飞灰）**：Pb、Zn、Cd、Sb 等——高温挥发、随烟气冷却**冷凝富集于飞灰**（Cd 82%、Sb 80% 入余热锅炉飞灰）。
3. **易挥发性（气相/极细飞灰）**：Hg 等——高温下呈气态，部分随烟气排放，需活性炭吸附。

> ⚠ 飞灰因富集重金属和二噁英属**危险废物**（HW18），须固化稳定化后专区填埋。

## 7.12 二噁英与 NOₓ 控制 ★（论述，作业 Ch7-7）

**二噁英控制（"3T+急冷"）**：
- 高温（炉膛 >850℃ 甚至 >925℃）+ 湍流 + 停留时间（≥2 s）保证有机物彻底分解（**3T 原则**）；
- 烟气**急冷**（几秒内从高温降至 <400℃），避开 250–500℃ 二噁英**再合成（de novo）温区**；
- 控制 CO 与未燃尽碳、降低飞灰颗粒（催化前驱体）；
- 活性炭吸附 + 袋式除尘脱除残余二噁英；源头减氯。

**NOₓ 控制**：
- 源头：控制焚烧温度 <1500℃（抑制热力型 NOₓ）、分级燃烧/低氮燃烧、控制过剩空气。
- 末端脱硝：**SNCR**（选择性非催化还原，850–1100℃ 喷氨/尿素，无催化剂，效率较低）；**SCR**（选择性催化还原，加催化剂，低温高效）。

## 7.13 焚烧炉启停操作 ★（作业 Ch7-12，以机械炉排炉为例）

**冷态启动**：①检查系统、引风/送风机启动建立微负压；②启动助燃燃烧器烘炉，按升温曲线**逐步升温至炉膛 >850℃**；③达温后投入垃圾给料，逐步增至额定负荷；④烟气净化、余热锅炉同步投运；⑤炉温稳定后退出助燃燃烧器。
**热态停炉**：①停止进料，将炉排上垃圾**燃尽**（燃尽前炉膛保持 >850℃）；②按设计**降温曲线**逐渐降温；③定期启动助燃燃烧器保证 <850℃ 时立即助燃（防二噁英）；④停送风、引风，关卸料门，投运垃圾池排风除臭；⑤余热锅炉、烟气净化按程序停运。

## 7.14 焚烧热量计算例题 ⚙ ★（作业 Ch7-8 详见《作业答案》）

垃圾热值 11630 kJ/kg，求可利用热量。核心：**可利用热 = 总输入热 −（未燃碳损失 + 蒸发水分潜热 + 灰渣显热 + 辐射损失）**。详见作业答案。

# 第 8 章 卫生填埋

## 8.1 卫生填埋定义 ★（名词解释，作业 Ch8-1）

**卫生填埋（Sanitary Landfill）**：利用工程手段，采取有效技术措施，**防止渗滤液及有害气体**对水体、土壤和大气的污染，最大幅度**压实减容**，随时采用膜或土**覆盖**，使整个过程对公共卫生安全及环境均无害的一种垃圾土地处理方法。

**与传统垃圾堆场（简易堆放）的区别**：传统堆场——无防渗、无渗滤液导排处理、无填埋气导排处理、无日覆盖、无封场；卫生填埋——具备防渗系统、渗滤液收集导排处理、填埋气导排利用、日覆盖、封场，并满足环境防护要求。

**环境防护要求**：防渗（防地下水污染）、渗滤液导排处理、填埋气导排利用、雨污分流、日覆盖与封场、地下水监测、卫生防护距离。

## 8.2 填埋场类型 ★（作业 Ch8-2）

| 类型 | 适用条件 | 设计特点 |
|---|---|---|
| **平地型** | 平原地形 | 汇水面积小、易防洪导排；需下挖、场底易地下水渗出；单元划分易、易雨污分流 |
| **山谷型** | 利用山谷库容 | 汇水面积大需截洪；不需下挖、库容大；单元划分难、雨污分流复杂；破坏山区环境 |
| **坡地型** | 一定坡度地形 | 上游有汇水；场底天然坡度利于渗滤液导排；单元划分较易 |
| **滩涂型** | 海滩/河滩 | 地基软需加固；其余类似平原型 |

**选址**：否定法（排除生态红线、基本农田、水源保护区、洪泛区、地质灾害区、岩溶/火成岩带）+ 肯定法（评价交通、地形、距居民区）。考察标准：卫生防护距离、工程/水文地质、天然水体保护、空气噪声土壤、交通居住、对其他行业影响等。

## 8.3 防渗层构造 ★（绘图+说明，作业 Ch8-3）

**垂直防渗**：填埋区四周建垂直防渗幕墙（深入下部不透水层 ≥2 m，常用水泥膨润土搅拌桩 k≤10⁻⁶ cm/s），隔离场内外地下水；主要用于山谷型（须为独立水文地质单元）；投资小但效果难保证。

**水平防渗（复合衬层，从下到上）** ——典型 HDPE 复合衬层结构：

```
   垃圾体
———————————————————————
   渗滤液收集导排层（碎石/卵石 + HDPE 花管 + 土工布反滤）
———————————————————————
   保护层（土工布）
———————————————————————
   HDPE 防渗膜（≥1.5 mm，主防渗屏障，k≈10⁻¹³ cm/s，抗拉抗穿刺耐老化）
———————————————————————
   压实黏土保护/防渗层（≥0.6 m，k≤5×10⁻⁷ cm/s）
———————————————————————
   基础层（地下水收集导排层，距年最高地下水位 ≥1 m）
```

**各层功能**：
- 碎石导排层 + HDPE 花管：及时导排渗滤液，降低水位、减少停留、降水头压力。
- 土工布：反滤（防淤堵）、保护膜防穿刺。
- **HDPE 膜**：核心防渗屏障，阻渗滤液下渗。
- 压实黏土：辅助防渗 + 缓冲，万一膜破损时阻滞。
- 基础层/地下水导排：收集导排地下水，距最高地下水位不足 1 m 须建地下水收集导排系统。
- 双层衬层系统：两层 HDPE 之间设**渗漏检测层**监测渗漏。

## 8.4 渗滤液 ★（作业 Ch8-4）

**主要污染物**：高 COD、BOD₅、**高氨氮（NH₃-N）**、重金属、SS、色度、盐分、难降解有机物（腐殖酸）；早期可生化性好（BOD/COD 高），后期（老龄渗滤液）可生化性差、氨氮高。
**环境风险**：污染地下水、地表水、土壤，毒性大，须**零排放**理念。

**处理工艺与选择依据**：
- **物理化学法**：吹脱（脱氨氮，pH 调碱曝气）、混凝沉淀（去浊度色度重金属、COD 30–60%）、吸附、高级氧化（Fenton、臭氧、电解、湿式氧化）、膜分离（MF/UF/**NF/RO**）；用于预处理和深度处理。
- **生物化学法**：厌氧（高浓度有机物）+ 好氧（**MBR 膜生物反应器** = 生物处理 + MF/UF 固液分离）。
- **自然处理法**：稳定塘、土地处理。
- **组合工艺**（主流）：**中温厌氧 + MBR + NF/RO**。
- **选择依据**：渗滤液水质（C/N、可生化性、氨氮）、龄期、排放标准、浓缩液出路（RO 浓缩液处理是难点）。

## 8.5 填埋气导排与利用

- 成分：CH₄ ~50–60%、CO₂；可发电、提纯。
- **主动导排**：垂直/水平导气井 + 盲沟 + 管道 + 抽气设备主动抽出；减少排放与横向迁移、回收 CH₄。
- **被动导排**：靠填埋气自身压力沿导排井盲沟排出（无机械抽气）。

## 8.6 填埋场封场 ★（作业 Ch8-6）

**封场**：填埋至设计终场标高后进行终场覆盖与环境治理（局部封场 / 整场封场）。

**封场覆盖结构（自下而上）** —— 基本组成系统：

```
   带植被的表土层（绿化土层）
   保护层
   排水层（土工网/土工复合排水层）
   防渗层（HDPE 膜 / GCL / 压实黏土）
   排气层（气体导排层）
———————————————————————
   垃圾堆体
```

**封场工程基本组成系统**：①气体导排层（排气）；②防渗层（阻雨水入渗）；③排水层（导排雨水）；④保护层；⑤植被表土层（绿化）。
**封场后维护**：渗滤液收集处理、填埋气收集处理、防洪排水设施维护、绿化维护、地下水监测（封场 32 年后可终止现场监管与渗滤液处理）。

## 8.7 矿化垃圾与可持续填埋 ★（作业 Ch8-5）

**矿化垃圾（Aged refuse）**：填埋场垃圾经 8–10 年基本稳定化后的产物，可开采利用。

**稳定化后垃圾组成**：细料（~50%）、塑料（~25%）、砖石（~11%）、玻璃、木竹、橡胶、布、金属等。

**定量化指标**：有机质 9–15%；填埋 ≥8–10 年；微生物 >10⁶⁻⁸/g 干垃圾；粒径 <40 mm；阳离子交换容量 1.20–1.49 mmol/g。

**资源化利用价值（有）**：
- **矿化垃圾作生物反应器填料/介质**：比表面积大、结构松散、水力传导渗透好、阳离子交换能力强、微生物丰富——可用于渗滤液处理、污水处理、土壤改良。
- 细料可作覆盖土/回填土/制砖；金属、塑料、玻璃分选回收；土地复用（封场 >10 年就地修复 + 矿化垃圾开采）。

# 第 9 章 危险废物

## 9.1 危险废物定义 ★（名词解释，作业 Ch9-1）

**危险废物**：列入《国家危险废物名录》或根据国家规定的鉴别标准和方法认定的，具有**腐蚀性、毒性、易燃性、反应性、感染性**等一种或一种以上危险特性，以及不排除具有以上危险特性的固体、液体或其他形态的废物。

## 9.2 危险废物的典型特性 ★（作业 Ch9-1）

| 特性 | 鉴别标准 | 对环境/人体危害 |
|---|---|---|
| **腐蚀性 C** | 浸出液 pH ≥12.5 或 ≤2.0；55℃ 对 20 号钢腐蚀率 ≥6.35 mm/a | 灼伤皮肤、腐蚀设施、污染土壤水体 |
| **毒性 T（浸出毒性/急性毒性）** | 浸出液危害成分超限值（如 Pb≤5、Cd≤1、Cr⁶⁺≤5 mg/L）；急性毒性 LD₅₀（经口固体≤200、液体≤500 mg/kg） | 重金属/有机毒物致癌致畸、生物累积 |
| **易燃性 I** | 液体闪点 <60℃（闭杯）；固体摩擦/自燃起火持续燃烧；气体易燃范围宽 | 火灾爆炸风险 |
| **反应性 R** | 不稳定易爆；遇水/酸放易燃有毒气体（含氰废物 ≥250 mg HCN/kg，含硫 ≥500 mg H₂S/kg）；废氧化剂/有机过氧化物 | 爆炸、释放毒气 |
| **感染性 In** | 医疗废物（病原体） | 传播疾病 |

> 浸出毒性浸出方法：HJ/T 299（硫酸-硝酸混合液 pH 3.2，液固比 10:1，振荡 8 h）；GB5086 翻转法（蒸馏水 pH 自然，振荡 18 h）。

## 9.3 鉴别程序 ★（关键步骤，作业 Ch9-3）

1. **是否属于固体废物**——首先判断是否为固废（不是则不适用）。
2. **是否列入《国家危险废物名录》**——列入则**直接认定为危废**（出具鉴别报告）。
3. **依据工艺分析是否可能具有危险特性**——不能确定来源则报环保部认定。
4. **危险特性检测**——编制鉴别方案、采样检测（腐蚀性/易燃性/反应性/毒性）。
5. **对照鉴别标准判定**——任一特性超标准 → 危废；均不超 → 非危废，出具鉴别结论。

## 9.4 混合判定规则 ★（作业 Ch9-4）

- 具有**毒性、感染性**的危废与其他固废混合 → **混合后仍属危废**（且处理后仍是危废）。
- 仅具**腐蚀性、易燃性、反应性**的危废与其他固废混合 → 经鉴别**不再具有危险特性**的，**不属于危废**。

> 答：取决于原危废的危险特性类别。若含毒性/感染性，混合后仍为危废；若仅腐蚀/易燃/反应性且混合后经鉴别不再具危险特性，则不属于危废。

## 9.5 危险废物处置原则 ★（论述，作业 Ch9-2）

1. **源头减量**——优先在产生源头减少危废生成。
2. **资源化利用**——尽可能作原料利用，或有效分离去毒实现无害化。
3. **末端安全处置**——无法资源化/去毒的，进行固化稳定化、安全填埋、焚烧。

> 即"减量化—资源化—无害化"。实际应用：源头清洁生产；分类收集（避免混合污染）；危废经营许可与转移联单（五联单）管理；豁免管理清单（16 类，满足条件可豁免）。

## 9.6 安全填埋作业原则 ★（作业 Ch9-5）

①应先**固化稳定化**；②必须**成型、块状化**填埋，不能散装；③应有**屋盖**防雨水进入；④**不得与生活垃圾、城市污泥混合填埋**（专用安全填埋场）；⑤入场须满足浸出毒性控制限值。
**环境风险防控意义**：固化稳定化降低浸出毒性、屋盖防雨减渗滤液、专区填埋防交叉污染、双衬层防渗防地下水污染。

## 9.7 刚性填埋 vs 柔性填埋 ★（论述，作业 Ch9-6）

| | **柔性填埋（双人工复合衬层）** | **刚性填埋（钢筋混凝土）** |
|---|---|---|
| 结构 | HDPE + 黏土双层复合衬层 | 钢筋混凝土框架基础 + HDPE，分独立单元（≤50 m²、≤250 m³/单元） |
| 防渗 | 混凝土 k≤10⁻⁶ cm/s + 人工衬层 k≤10⁻¹² cm/s、厚≥2 mm | 高防水等级 |
| 优点 | 造价低、技术成熟、操作简便 | 地质限制小、渗漏控制易、入场指标宽、后期管理易、利于回取利用、预处理要求低 |
| 缺点 | 地质要求高、入场废物受限、需预处理、渗漏控制难、发现/修复难、后期费用极高 | 建设成本高、规范不成熟 |
| 适用 | 大宗、经预处理稳定化的危废 | 砷含量 >5% 的废物**应进**刚性填埋；高危/反应性废物 |

> ⚠ 医疗废物、与衬层不相容废物、液态废物、反应性/易燃性废物**不得进入刚性填埋场**。

## 9.8 固化/稳定化技术 ★（至少 3 种，作业 Ch9-7）

**目的**：使危废中污染组分呈化学惰性或被包容，便于贮运利用处置。
- **固化**：用添加剂改变废物工程特性（渗透性、强度等），是特定的稳定化过程。
- **稳定化**：将污染物全部/部分固定于支持介质/黏结剂上。

| 技术 | 原理 | 适用废物 |
|---|---|---|
| **水泥固化** | 高 pH 形成不溶氢氧化物/碳酸盐，重金属固定于水泥晶格 | 无机废物，尤其**重金属**（Pb/Cr/Cu/Zn/Sn/Cd） |
| **石灰固化** | 加熟石灰，Ca 与硅铝酸根生成硅酸钙/铝酸钙水化物 | 含重金属无机污泥 |
| **熔融固化（玻璃化）** | 与玻璃质混合 1500℃ 熔融成玻璃体，致密结构永久稳定 | 高放射性废物、飞灰 |
| **药剂稳定化** | pH 控制（重金属成难溶氢氧化物）、氧化还原（Cr⁶⁺→Cr³⁺、As⁵⁺→As³⁺）、沉淀（硫化物/硅酸盐/碳酸盐/铁氧体共沉淀） | 重金属废液/污泥 |
| **热塑性固化/沥青固化** | 热塑性材料包覆 | 放射性、可溶性盐类 |

## 9.9 危险废物主要处理方法（有价金属回收）

- **湿法工艺**：酸浸/氨浸富集分离金属；浸出效果好、工艺成熟；但流程长、试剂耗量大、二次污染（废水/废气/污泥）多、成本高。
- **焙烧-浸出（火湿联合）**：火法富集 + 湿法分离；减容率高；但能耗高、流程长、未完全解决二次污染。
- **微生物法（生物冶金）**：特殊菌种选择性结合/吸附/溶解有色金属；选择性强、清洁环保、耗酸碱少；但周期长、效率低、菌种难培养。
- **一体化熔炼**：与硅石/铁矿/石灰配料入炉，煤焦还原产 90–99% 合金块；规模大、金属非金属分离好；但能耗高、渣型控制难、尾气难治。
- **固化安全填埋**：固化后填埋，简单廉价，但浪费土地与金属资源。

> 锌铅危废碱介质湿法：NaOH 碱浸 + 硫化钠分离（锌铅、锌铁、锌铜、铅铜、铅铁等组合分离效果极佳）。

# 第 10 章 工业固体废物

## 10.1 定义、分类、危害 ★

**工业固体废物**：工业原料生产、产品加工、燃料燃烧、矿物开采、交通运输、环境治理过程中废弃的固态和半固态物料（**非危险废物**）。

**按行业分类**：煤系（煤矸石、粉煤灰）、冶金（高炉渣、钢渣）、石油化工、矿业（废石、尾矿）、轻工业（下脚料、污泥）、其他（金属碎屑、电镀污泥、废轮胎）。

**危害**：露天堆积侵占土地、阻塞河道；自燃产 CO/SO₂/H₂S/NOₓ 诱发火灾；酸性淋溶水污染土壤水体；细颗粒降尘污染；放射性元素危害；崩塌危及安全。

**处理原则（3C）**：避免产生（Clean）、综合利用（Cycle）、妥善处理（Control）；早期"三化"——资源化、减量化、无害化。

**资源化途径**：①生产建材（水泥/砖/混凝土掺料，耗渣量大投资少）；②回收有价组分（提镓钪等）；③筑路筑坝回填；④农肥土壤改良（硅钙肥、钙镁磷肥）。

## 10.2 典型大宗工业固废 ★（作业 Ch10-1/3）

| 固废 | 来源 | 主要成分 | 环境影响/利用 |
|---|---|---|---|
| **煤矸石** | 采煤、洗煤过程；成煤伴生低碳黑灰岩石 | C（低）、SiO₂、Al₂O₃、Fe₂O₃ 等 | 占煤产 10–20%；自燃产 SO₂、酸性淋溶；用作发电、烧结砖、水泥、制气 |
| **粉煤灰** | 燃煤电厂烟气捕集的非挥发煤残渣（飞灰） | SiO₂ 43–56%、Al₂O₃ 20–32%、CaO、Fe₂O₃ + 未燃碳；玻璃体 50–80%（活性） | 产量约煤用量 25%；扬尘、占地；用作水泥(掺 20–40%)、混凝土掺料、制砖、筑路、改良剂 |
| **高炉渣** | 炼铁时（1400–1600℃）浮于铁水的熔渣 | CaO+SiO₂+Al₂O₃+MgO >90% | 水渣（急冷玻璃体，有水泥活性）/气冷渣（似碎石）/膨珠；制水泥、骨料 |
| **钢渣** | 炼钢（1500–1700℃）废渣 | CaO、SiO₂、FeO、游离 CaO/MgO | 游离 CaO/MgO 安定性差；作冶炼溶剂、筑路、制砖 |
| **赤泥** | **制铝工业提取氧化铝**排出（拜耳法） | Fe₂O₃、Al₂O₃、SiO₂、CaO、Na₂O；强碱性 NaOH/Na₂CO₃ | **强碱性(pH 10–13)**、含放射性、利用率仅 4%；回收铁（还原磁选）、铝钛钒、作陶粒/建材 |
| **磷石膏** | 磷矿+硫酸**制磷酸**排出废渣（每吨磷酸排 4–5 t） | CaSO₄·2H₂O，含残 P₂O₅、F、有机物 | 累积堆存>3 亿吨，含 P/F 污染水土；制硫酸铵、水泥缓凝剂、建材石膏板 |
| **电石渣** | **电石(CaC₂)水解制乙炔/PVC** 排出（产 1 t PVC 排 2 t） | Ca(OH)₂ 为主 | 强碱性；制水泥、渣砖、筑路、漂白液、氯酸钾（产 1 t KClO₃ 用 10 t 电石渣省 4 t 石灰） |
| **硫铁矿渣** | 硫铁矿制硫酸沸腾炉烧渣 | Fe 50–60%、Cu/Pb/Zn/Au/Ag | 回收 Fe（炼铁/铁红铁黄颜料）、Cu/Pb/Zn（氯化焙烧-浸出）、制水泥制砖 |

## 10.3 有色金属提取冶金 ★（论述，作业 Ch10-4）

**任务**：从矿石、精矿、二次资源中分离伴生元素，产出金属或其化合物。

| 方法 | 原理 | 适用金属 | 典型工艺 |
|---|---|---|---|
| **火法冶金（干法）** | 高温从矿石提取金属/化合物，无水溶液参加 | 重金属（Cu、Pb、Sn、Ni、Co） | 焙烧→熔炼→还原→吹炼→火法精炼→真空精炼 |
| **湿法冶金（水法）** | 用溶剂经化学反应（氧化/还原/中和/水解/络合）提取分离 | 轻金属、稀有金属、贵金属（富集）、低品位/复杂矿 | 浸出→液固分离→溶液净化→金属提取（萃取/沉淀/电积） |
| **电冶金** | 用电能提取回收精炼金属 | Al、Mg（熔盐电解）；Cu、Zn、Ni（水溶液电解） | 电热法（电能→热能熔炼）/ 电解法（电化学析出） |

**有色金属提取三步骤**：①矿物分解和化合物制取（破坏矿物结构，焙烧/造锍熔炼/浸出，分离伴生元素）→ ②金属制取（还原产粗金属：碳还原/金属热还原/氢还原/电解/置换）→ ③金属精炼（火法精炼 / 电解精炼产纯金属）。

**金属-方法对应**：重金属（Cu/Pb/Sn/Ni/Co）→ 火法制粗金属 + 电化冶金制纯金属；轻金属 → 湿法制纯化合物 + 电冶金制金属；稀有金属 → 湿法制化合物 + 火法/电冶金制金属；贵金属（Au/Ag）→ 湿法富集 + 火法 + 电冶金。

## 10.4 水溶液电解 vs 熔盐电解 ★（对比，作业 Ch10-5）

| 对比项 | **水溶液电解** | **熔盐电解** |
|---|---|---|
| **电解质状态** | 金属盐**水溶液**（如 CuSO₄、ZnSO₄ 溶液） | 熔融盐（如冰晶石-氧化铝熔体 Na₃AlF₆-Al₂O₃） |
| **操作温度** | 低温（常温~100℃以下） | 高温（如铝电解 ~950℃） |
| **适用金属** | 电位较正、不与水反应的金属：Cu、Zn、Ni、Co、Cr 等 | 电位很负、与水反应的活泼/轻金属：**Al、Mg、Na、稀土** |
| **阴极反应** | 金属离子还原析出：Mⁿ⁺ + ne⁻ → M（伴 H₂ 析出竞争） | 金属离子还原析出：Mⁿ⁺ + ne⁻ → M（如 Al³⁺ + 3e⁻ → Al） |
| **阳极反应** | 析氧（不溶阳极）或阳极溶解（精炼，可溶阳极） | 碳阳极氧化（如 2O²⁻ + C → CO₂ + 4e⁻，阳极消耗） |
| **能耗/原因** | 能耗较低 | 能耗高（高温熔融） |

> 原理差异核心：活泼金属（Al/Mg/Na）在水溶液中会优先析氢、无法电沉积，**必须用熔盐电解**；而 Cu/Zn/Ni 等可在水溶液中电解（提取或精炼）。
> 按目的分：电解提取（从浸出液直接电积）/ 电解精炼（粗金属阳极溶解、阴极析出纯金属，阳极泥富集贵金属）。

**铝电解槽**（预焙阳极）：阳极炭块组、阴极炭块组、槽壳槽罩、导电系统；电解质为冰晶石-氧化铝熔体。

# 第 11 章 电子废物

## 11.1 电子废物概述 ★

**来源**：家庭（电视/冰箱/空调）、办公室（电脑/打印机）、工业制造（IC 废品/废电缆）、其他（手机/笔记本/玩具）。
**分类（10 大类）**：大型家电、小型家电、信息通讯设备、家庭娱乐设备、照明设备、电动工具、电动玩具、医疗设备、监视控制仪器、自动售货机。主要由塑料、玻璃、金属（>30 种）构成。
**现状**：2019 全球 5360 万吨，年增 3–4%；中国居首（>1000 万吨）；仅 17.4% 有效回收，76% 去向不明。
**资源价值高**：1 t 废线路板可提金 900 g、锡 30 kg、铜 130 kg、塑料 270 kg；2019 全球 e-waste 潜在价值 $57 billion（Fe、Cu、Au 价值最高）。

## 11.2 电子废物危害 ★（论述，作业 Ch11-1）

**有害物质**：①**重金属**——铅（焊点）、汞（元件/灯管）、镉（电阻）、铬（防腐）、铍（基板）；②**溴系阻燃剂**（电路板，难降解高毒，全球 250–300 kt/a）；③**POPs**——二噁英、多氯联苯(PCB)、多溴联苯(PBB)、多溴二苯醚(PBDE)；④氯氟碳化物（制冷剂）。

**危害分析（环境 + 人体两方面）**：
- **环境污染**：随意丢弃/露天焚烧/酸浸 → 重金属、POPs 渗入**土壤、地下水、地表水、大气**（1 mg 汞污染 360 t 水）；焚烧塑料/阻燃剂产二噁英、呋喃。
- **人体健康**：重金属经食物链/饮水富集——Pb（神经/血液/儿童智力）、Hg（神经/肾）、Cd（肾/骨痛病）、Cr⁶⁺（致癌）；POPs 致癌、致畸、内分泌干扰；阻燃剂干扰甲状腺/生殖。拆解工人暴露风险最高。

## 11.3 废印刷电路板（PCB）资源化 ★（论述，作业 Ch11-2）

**PCB 组成**：Cu 26.8%、Pb 4.7%、Al 1.9%、Fe 5.3%、Sn 1.0%、SiO₂ 15%、玻璃纤维、树脂、Au 80 g/t、Ag 3300 g/t、Pd 等贵金属。

**主要来源**：废弃计算机、手机、家电、通讯设备及工业电子设备中的电路板。

**资源化回收策略**：
- **资源化途径层级**：整机利用 → 元器件利用 → 物质回收（最大化资源化）→ 焚烧/填埋。
- **预处理**：①**物理机械法**（破碎 2–4 级至 <1 mm，金属-非金属解离度 90% + 摇床/气流/静电分选）；②**焚烧**（破碎后焚烧分解树脂，残渣金属送冶炼，气体二次焚烧；工艺简单但环境风险高、有机物未利用）；③**高温/真空热解**（无氧裂解有机物回收油气与金属，抑制二噁英呋喃，废气少）。
- **冶炼**：
  - **湿法冶炼**：强酸/碱浸出 Cu/Au/Ag，电解或加沉淀剂分次回收；主要用于贵金属分离提纯（成本高、腐蚀毒性大、二次污染）。
  - **火法冶炼**（主流）：800℃ 焚烧 + 二燃室 >1200℃ 分解二噁英 + 急冷至 <400℃；或直接鼓风炉/卡尔多炉/顶吹炉 1200–1300℃ 还原熔炼产粗铜（含 Cu 80–90%，贵金属入粗铜，Pb 入渣烟气）→ 火法+电解精炼产 99.95% 阴极铜，**阳极泥富集 Au/Ag**用火湿联合回收；Cu 回收率 >98%、可自热。
  - **协同处置**：与废杂铜协同（热平衡）；与电镀污泥协同（弱还原产粗铜 + 无害化污泥回收 Cu/Ni）。
- **可行性**：火法 Cu 回收率高、二噁英可控、可自热、规模化，但需二燃额外热源；微生物法/旋流电沉积更绿色但效率/规模待提升。生命周期对比：火法(PCB) 与生物浸出(PCB) 能耗、废气、废水、固废均显著低于火法(原矿)。

## 11.4 旋流电沉积技术 ★（论述，作业 Ch11-3）

**旋流电沉积（Cyclone electrodeposition）基本原理**：电解液以**旋流（高流速切向）**方式从底部输入电解槽，强制对流减薄阴极表面**扩散边界层**，**消除浓差极化**，使低浓度金属离子也能持续高效电沉积。

**与传统电沉积对比及优势**：

| | 传统电沉积 | 旋流电沉积 |
|---|---|---|
| 流态 | 静止/弱搅拌 | 旋流强制对流 |
| 浓差极化 | 严重（边界层厚） | **消除/减弱**（边界层薄） |
| 低浓度沉积 | 低浓度时为**粉状**、效率低 | 低浓度（1–2 g/L Cu²⁺）实现**片状**致密电沉积 |
| 效率 | 低 | Zn、Cu 直接电沉积效率 >90% |
| 多金属分离 | 难 | 通过调 pH 实现 Cu、Ni、Zn **分步电沉积** |
| 废水 | 有排放 | 避免废水排放、溶液循环 |

**优势总结**：①消除浓差极化、提高传质与电流效率；②低浓度下获致密片状金属（非粉末）；③可分步选择性回收多金属；④清洁、溶液循环、近零废水排放。

## 11.5 生物冶金 ★（名词+对比，作业 Ch11-5）

**生物冶金（生物浸出 Biohydrometallurgy）**：利用微生物（如**嗜酸性硫杆菌 Acidithiobacillus**）及其代谢产物（无机酸/有机酸、Fe³⁺ 氧化剂）将固废中的金属组分溶解浸出的冶金技术。

**作用机制**：
- **直接机制**：微生物直接附着于矿物表面，催化氧化金属硫化物。
- **间接机制**：微生物将 Fe²⁺ 氧化为 **Fe³⁺**（强氧化剂）、将 S 氧化为 **H₂SO₄**（酸性环境），Fe³⁺/酸再化学浸出金属，金属溶出后 Fe³⁺ 还原为 Fe²⁺ 循环再生。
- 纳米催化（N-CNTs、石墨烯）可提升嗜酸硫杆菌浸出速率 >20%。

**三种冶金方法优缺点对比**：

| 方法 | 优点 | 缺点 |
|---|---|---|
| **火法冶金** | 工艺简单、处理量大、可自热、不需预处理 | 能耗高、金属损失大（如 Li 损失严重）、二次污染（烟气/二噁英）严重 |
| **湿法冶金** | 能耗低、金属回收率高、产品纯度高（**当前主流**） | 流程长、化学试剂耗量大、含酸/碱废水、浸出选择性差（杂质多）、设备腐蚀 |
| **生物冶金** | 能耗低、成本低、操作条件温和、环境友好、回收率高 | **菌种难培养、浸出周期长、效率低、易受污染** |

## 11.6 废锂离子电池回收 ★（论述，作业 Ch11-4）

**锂电池构成**：正极、负极、电解液、隔膜、外壳。
- 正极材料：含锂过渡金属氧化物——LiCoO₂、LiNiO₂、LiMn₂O₄、**LiFePO₄（磷酸铁锂）**、LiNiₓCoᵧMn₁₋ₓ₋ᵧO₂（**三元 NCM**）。
- 电解液：溶质 LiPF₆/LiClO₄/LiBF₄ + 有机溶剂（PC、DEC）。
- 隔膜：PE/PP 微孔膜。

**为何回收主要集中于正极材料**：①正极含 **Co、Li、Ni 等高价值金属**，经济驱动强；②负极（石墨）和电解液价值低、回收报道少；③正极金属回收技术成熟、效益高。

**有效分离回收技术路线及关键步骤**：

```
废锂电池
  │
① 预处理：盐水浸泡放电（防短路自燃）→ 人工/机械拆解（去外壳）
  │              → 分离正极、负极、隔膜（60℃干燥 24 h）
  │
② 正极活性物质与铝箔集流体分离（去 PVDF 黏结剂干扰）：
   溶剂溶解法(NMP溶 PVDF) / NaOH 碱溶法(溶 Al 箔，保留 LiCoO₂)
   / 超声辅助 + 机械搅拌 / 热处理(高温分解黏结剂) / 机械分选
   （选择性破碎：Al 富集>2mm、Cu/Al 0.25–2mm、Co/石墨<0.25mm）
  │
③ 金属提取（核心）：
   • 火法冶金：高温还原熔炼成合金（Umicore 工艺，无需预处理但 Li 损失大）
   • 湿法冶金（主流）：无机酸(H₂SO₄/HCl/HNO₃)+ 还原剂(H₂O₂/NaHSO₃)
     将高价 Co/Mn 还原为易溶 Co²⁺/Mn²⁺；或环境友好有机酸(柠檬酸/草酸)
     反应例：2LiCoO₂ + 3H₂SO₄ + H₂O₂ → 2CoSO₄ + Li₂SO₄ + O₂ + 4H₂O
   • 生物冶金：微生物代谢酸浸出
  │
④ 浸出液分离纯化：溶剂萃取 + 化学沉淀 + 结晶 → 单一金属盐
  │
⑤ 产品制备：共沉淀法/溶胶凝胶法直接制三元正极材料前驱体
   （Co/Ni/Mn 性质相似难分离，直接调比例重制前驱体，避免分离）
```

**关键步骤**：放电 → 拆解 → 正极材料与集流体分离 → 浸出（酸 + 还原剂）→ 萃取/沉淀分离纯化 → 制备金属盐/正极前驱体。
