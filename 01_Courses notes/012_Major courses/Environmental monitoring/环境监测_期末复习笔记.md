# 第零部分　全局认知与考试地图

## 0.1 一句话抓住"环境监测"

环境监测＝**对环境中污染物（及物理因素）的种类、浓度、分布和变化趋势进行测定，以判断环境质量**的全过程。它不是单纯"做实验"，而是一条**完整的工作链**。考试中几乎所有大题都可以挂到这条链上。

## 0.2 监测工作链（万能流程，务必背熟）

```
明确监测目的
   ↓
确定监测对象 / 项目
   ↓
布点 / 设站（采样点位设计）
   ↓
样品采集 → 现场测量（流量/气象等）
   ↓
样品保存 / 运输
   ↓
样品预处理（消解 / 富集 / 分离 / 提取）
   ↓
分析测定（选仪器与方法）
   ↓
数据处理 / 结果表达
   ↓
质量保证与质量控制（QA/QC，贯穿全程）
   ↓
评价（与标准比较、计算指数、分级）
```

> **答题模板**：遇到"如何制定××监测方案/如何监测××"的简答题，按"目的→资料收集→项目→布点→采样时间频率→采样与分析方法→结果表达与质保"展开，几乎不会丢大分。

## 0.3 "五要素 + 结果"分析框架

任何一个监测方向，都可以拆成下面 6 个抓手。本笔记第一部分就是用它把五大方向并排做成"框架卡"。

| 要素 | 要回答的问题 |
|---|---|
| ① 监测目的 | 为什么测？（现状/监视/应急/管理/科研/仲裁） |
| ② 监测对象 | 测什么介质？（地表水/地下水/废水；环境空气/废气；固废/危废；土壤；声/光/辐射） |
| ③ 监测项目 | 测哪些指标？（通常有"必测/选测""一类/二类""基本项目"等分类） |
| ④ 布点与采样 | 在哪测、怎么采、何时采、采多少？ |
| ⑤ 技术与仪器 | 用什么方法和仪器测？ |
| ⑥ 结果与评价 | 怎么算、怎么表达、和什么标准比、怎么分级？ |

## 0.5 高频考点速览（先有个数）

- **概念辨析**：一次/二次污染物、瞬时/混合水样、酸度/碱度/pH、总氮/凯氏氮、BOD/COD/TOC 关系、真色/表色、TSP/PM₁₀/PM2.5、α/β/γ 衰变、声功率/声强/声压。
- **流程类**：河流断面布设（对照/控制/削减）、空气三种布点法、土壤布点法、固废份样数与四分法、采样后保存方法。

- **案例**：水俣病(Hg)、拉夫运河/Times Beach(危废/二噁英)、洛杉矶光化学烟雾。

# 第一部分　五大监测方向系统框架

> 每个方向给一张"框架卡"，按 0.3 的六要素组织。先把卡片记熟，简答题就有了骨架。

## 1.1 水质监测（第2章）

**① 监测目的（6 类，常考"列举"）**
1. 地表水——**经常性监测**：掌握水质现状及变化趋势。
2. 生产生活过程——**监视性监测**：掌握废污水排放量、污染物浓度与排放总量，评价是否达标。
3. 事故——**应急监测**：分析事故原因、危害、对策。
4. 环境管理——为制定标准、法规、规划**提供数据**。
5. 环境科研——为质量评价、预测预报**提供基础数据**。
6. 污染纠纷——**仲裁监测**：提供科学依据。

**② 监测对象**：环境水体（江河、湖库、地下水、海洋）＋ 污染源（生活污水、医院污水、工业废水）＋ 底质 ＋ 活性污泥。

**③ 监测项目（按介质分，常考分类）**
- 地表水基本项目：水温、pH、DO、高锰酸盐指数、COD、BOD₅、氨氮、总氮(湖库)、总磷、铜锌硒砷汞镉铅、六价铬、氟化物、氰化物、硫化物、挥发酚、石油类、阴离子表面活性剂、粪大肠菌群。
- 地下水：必测项目（pH、总硬度、溶解性总固体、氨氮、硝酸盐氮、亚硝酸盐氮、挥发酚、总氰化物、高锰酸盐指数、氟化物、砷汞镉六价铬铁锰、大肠菌群）＋ 选测项目。
- 废（污）水：**第一类污染物**（在车间或车间处理设施排放口采样：总汞、烷基汞、总镉、总铬、六价铬、总砷、总铅、总镍、苯并(a)芘、总铍、总银、总α/总β放射性）；**第二类污染物**（在排污单位排放口采样：pH、色度、悬浮物、BOD、COD、石油类、动植物油、挥发酚、总氰化物、硫化物、氨氮、氟化物、磷酸盐、甲醛、苯胺类、硝基苯类、阴离子表面活性剂、总铜锌锰）。
- 🔑 **一类 vs 二类的本质差别 = 采样位置**：一类毒性大、需在"源头"（车间排放口）控制；二类在工厂总排口控制。

**④ 布点与采样**（详见第三部分 3.1、3.2）
- 河流断面：背景、**对照、控制、削减**断面（一个河段只需后三种）。
- 湖库：一般设监测垂线，无明显功能区用网格法。
- 垂线上采样点按水深分（见 3.1）。
- 采样频率：饮用水源地每月≥1 次；河流单月 1 次、全年≥6 次（丰、枯、平水期各 2 次）；国控断面每月 5–10 日。

**⑤ 技术与仪器**（详见第二部分）
- 无机：化学法（重量、容量）、AAS、分光光度法、ICP-OES、电化学法、离子色谱、AFS、ICP-MS、气相分子吸收。
- 有机：GC、HPLC、GC-MS。

**⑥ 结果与评价**：与 GB3838 等标准比较；排污总量＝某时段平均浓度 × 该时段废水排放量。

## 1.2 空气和废气监测（第3章）

**① 监测目的**：掌握环境空气质量现状与变化趋势；为污染源管理、应急、标准制定、科研提供依据。

**② 监测对象**
- 环境空气（含室内空气）。
- 污染源：固定污染源（烟囱/烟道排气）、流动污染源（机动车尾气）。
- 降水（酸雨监测）。

**③ 监测项目与污染物分类（高频）**
- 按形成：**一次污染物**（污染源直接排放，理化性质未变：SO₂、CO、NOₓ、颗粒物、苯并芘）；**二次污染物**（一次污染物间或与大气组分反应生成的新污染物：O₃、醛类、PAN、硫酸雾、硝酸雾——多为气溶胶，毒性常更强）。
- 按存在状态：**分子状态**（SO₂、CO、NOₓ、HCN、苯、汞、NH₃、H₂S、Pb、Cd、氟化物等）；**粒子状态**（降尘>100μm；TSP<100μm；PM₁₀<10μm 可吸入；PM2.5<2.5μm）。

**④ 布点与采样**（详见 3.1、3.3）
- 布点原则：周围 50 m 内无污染源，采样口水平面≥270° 采集空间。
- 布点法：功能区布点、**网格布点**（多个均匀源，下风向占 60%）、**同心圆布点**（污染群）、**扇形布点**（孤立高架点源，夹角≤90°，常用 45°）。
- 采样法：**直接采样**（浓度高：注射器、塑料袋、采气管、真空瓶）；**富集采样**（浓度低 10⁻⁹–10⁻⁶：溶液吸收、填充柱阻留、滤料阻留、低温冷凝、静电沉降、扩散/渗透、自然积集）。

**⑤ 技术与仪器**：分光光度法（SO₂、NOₓ 等）、GC（CO、烃类）、非分散红外（CO）、化学发光、重量法（TSP、PM₁₀、降尘、硫酸盐化速率）。

**⑥ 结果与评价**：空气质量指数 **AQI**（由各污染物分指数 IAQI 取最大值）；首要污染物＝AQI>50 时 IAQI 最大者。

## 1.3 固体废物监测（第4章）

**① 监测目的**：① 鉴别是否危险废物；② 为处理处置（填埋、焚烧）提供依据；③ 监督污染控制效果。

**② 监测对象**：工业固体废物、**危险废物**、生活垃圾、医疗废物、渗滤液。

**③ 监测项目——危险废物的"特性鉴别"（核心考点）**
危险废物＝列入《国家危险废物名录》或经鉴别具有下列特性之一：

| 特性 | 判定要点 |
|---|---|
| **易燃性** Flammability | 液体闪点<60℃；固体经摩擦/吸湿能自燃 |
| **腐蚀性** Corrosivity | 浸出液 pH≤2 或 ≥12.5；对钢腐蚀>0.64 cm/a（≤55.7℃） |
| **反应性** Reactivity | 无爆震即剧变；遇水剧烈反应/生成爆炸性混合物/放出毒气；受热或引发能爆炸 |
| **放射性** Radioactivity | 天然放射性比活度>3700 Bq/kg |
| **急性毒性** Acute toxicity | 能使半数以上小鼠 48 h 内死亡（LD₅₀ 试验） |
| **浸出毒性** Leaching toxicity | 按规定浸出法浸取，浸出液中有害成分超过鉴别标准（见 3.4 浸出毒性表） |

**④ 布点与采样**（详见 3.1）
- 份样数：按批量大小查表（如批量 100–500 t，最少 20 份）。
- 份样量：取决于最大粒度（粒度越大，最小份样量越大）。
- 布点：堆存/运输固废用对角线、梅花、棋盘、蛇形；运输车/容器分上(1/6)、中(1/2)、下(5/6)三层。
- 制样：粉碎→过筛→**四分法**缩分；湿样室温自然干燥。

**⑤ 技术与仪器**：浸出试验＋水质分析方法；LD₅₀ 动物试验；热值用量热计；pH 计；腐蚀性玻璃电极法。

**⑥ 结果与评价**：以干样计；污染物<0.1% 用 mg/kg，>0.1% 用百分数。

## 1.4 土壤质量监测（第5章）

**① 监测目的**：① 土壤质量现状监测；② 土壤污染事故监测；③ 污染物土地处理动态监测；④ 土壤背景值调查。

**② 监测对象**：农田土壤、污染场地土壤（背景值 vs 污染区）。

**③ 监测项目**：金属化合物、非金属无机物、有机化合物（六六六、DDT、苯并(a)芘等）。判断污染的"标尺"＝**土壤背景值**（未受/少受人类影响下土壤中元素的含量）。

**④ 布点与采样**（详见 3.1）
- 原则：哪里有污染就在哪布点；点位不设在田边、沟边、路边、肥堆边、水土流失/表土破坏处。
- 点数：每单元至少 3 个；n = (s·t/d)²（t=1.96 @95%，d=0.2 @精度80%）。
- 布点法：**对角线**（小块、污灌）、**梅花**（小而均匀）、**棋盘**（中等；固废污染>20点）、**蛇形**（大而不均匀）、**放射状**（大气污染型）、**网格**（背景值/农化污染）。
- 样品类型：**混合样**（查污染状况，0–20 cm 耕作层，果林 0–60 cm，四分法）；**剖面样**（查污染深度，按 A/B/C 层分层采，剖面 1.5×0.8×1.0 m，自下而上采）。
- 重金属样品尽量用竹铲、竹片采集（避免金属污染）。

**⑤ 技术与仪器**：消解（混合酸 / 碱熔 / 高压釜 / 微波）；AAS、ICP；GC（有机氯农药、BaP）；XRF（固体直接测）。

**⑥ 结果与评价**：单项污染指数＝实测值/标准值；综合污染指数（内梅罗）= √[(平均单项² + 最大单项²)/2]；据综合指数分 5 级（≤0.7 安全 … >3.0 严重污染）。

## 1.5 物理性污染监测（第7章：噪声 / 振动 / 放射性 / 光）

**① 监测目的**：评价声、振动、辐射、光等物理因素对环境和人体的影响。

**② 监测对象 & 标志量**

| 子方向 | 对象 | 标志量/单位 |
|---|---|---|
| 噪声 | 城市/工业/交通噪声 | 声压级 Lp(dB)、等效连续A声级 Leq |
| 振动 | 振动源 | 振级 |
| 放射性 | α/β/γ 辐射、电磁辐射 | 放射性活度(Bq)、照射量(C/kg)、吸收剂量(Gy)、剂量当量(Sv) |
| 光污染 | 白亮污染、彩光污染 | 照度等 |

**③–⑥ 噪声为主线（最常考）**
- 物理量：声功率 W(W)、声强 I(W/m²)、声压 p(Pa)；对应"级"：Lw、LI、Lp。
- 主客观关系：响度（宋, sone）、响度级（方, phon）、计权声级（A 计权最常用，模拟人耳）。
- 评价量：等效连续 A 声级 Leq、昼夜等效声级 Ldn。
- 仪器：声级计（按频率计权+时间计权测声压级）。
- 计算：声压级、噪声叠加/相减、Leq（见 3.4）。

**放射性要点**：α衰变（重核Z>82放⁴He）、β衰变（放电子，含β⁻/β⁺/电子俘获）、γ衰变（电磁辐射）；半衰期 T₁/₂；照射量 X=dQ/dm、吸收剂量 D=dε/dm、剂量当量 H=D·Q·N。

# 第二部分　仪器与分析技术总览（横向整合）

> 课程把各种仪器/方法零散分布在水、气、土、固废各章里。这一部分把它们**按技术家族归类**，并给出两张"双向查找总表"：① 方法→测什么；② 污染物→用什么方法。这是应对"方法-污染物配对"题型的核心武器。

## 2.1 五大技术家族（先建立大类）

| 家族 | 代表方法 | 核心原理一句话 |
|---|---|---|
| **光谱法** Spectrometry | 分光光度法、AAS、AFS、ICP-OES/AES、ICP-MS、气相分子吸收 | 物质对光的吸收/发射/荧光与浓度相关 |
| **色谱法** Chromatography | GC、HPLC、离子色谱IC、GC-MS、顶空/吹扫捕集 | 利用各组分在固定相/流动相分配系数差异分离 |
| **电化学法** Electrochemistry | 电位分析（离子选择电极、pH、氧电极）、阳极溶出伏安、库仑滴定、电导 | 测电位/电流/电量/电导与浓度的关系 |
| **滴定/重量法** Titrimetry/Gravimetry | 碘量法、重铬酸钾法、硝酸银滴定、重量法 | 经典化学计量反应 |
| **生物法** Biological | BOD培养法、微生物电极、毒性试验 | 利用微生物/生物对污染物的响应 |

## 2.2 各方法的"原理 + 测什么 + 特点"速记

**光谱法**
- **分光光度法**（UV/可见/红外）：基于分子吸收光谱，定量依据**朗伯-比尔定律 A=Kbc**。把待测物变成有色物，测特征波长吸光度。便宜、普及，常规监测主力。波长区：紫外 10–400 nm、可见 400–780 nm、红外 780 nm–300 μm。
  - 双硫腙分光光度法：测汞、铅、镉、锌等（生成有色螯合物）。
- **原子吸收光谱 AAS**：原子蒸气对其特征共振辐射的吸收；火焰/石墨炉把样品原子化为基态原子，测吸光度。冷原子吸收（253.7 nm，SnCl₂ 还原）专测汞。多用于微量、痕量金属。
- **原子荧光 AFS**：冷原子荧光测汞等。
- **ICP-OES/AES**（电感耦合等离子体发射光谱）：等离子炬 6000–8000 K，原子被激发发射特征光谱；**I=aC^b**。准确度高、检出限低、线性范围宽、**可多元素同时测定**。
- **ICP-MS**：按质荷比检测，痕量多元素。
- **气相分子吸收光谱**：测氨氮、硝酸盐氮、亚硝酸盐氮、硫化物等。

**色谱法**
- **气相色谱 GC**：分离挥发性、热稳定有机物。**检测器（高频考点）**：
  - **FID 火焰离子化**：破坏性、质量型、通用，灵敏度高、线性宽；只测有机物（含碳），**不能测惰性气体/空气/水/CO/CO₂/CS₂/NO/SO₂/H₂S**。
  - **ECD 电子捕获**：β放射源；高选择性，只对能俘获电子的化合物（卤代烃、含N/O/S）响应；测痕量农药、多氯联苯。
  - **TCD 热导**：通用、非破坏性、浓度型；灵敏度低→常量分析。
  - **FPD 火焰光度**：质量型、选择性；专测含 **S、P** 化合物（富氢火焰；S 特征 394 nm，P 特征 526 nm）。
- **离子色谱 IC**：连续测多种离子（氟、氯等阴离子）。
- **HPLC**：高沸点、热不稳定、大分子化合物（如多环芳烃 PAHs、苯并(a)芘）。
- **GC-MS**：定性定量兼备，痕量有机物、PAHs、VOCs。
- **顶空 GC / 吹扫捕集 GC**：挥发性卤代烃、VOCs 的预处理＋测定。

**电化学法**
- **电位分析（离子选择电极）**：F⁻（氟离子选择电极）、pH（玻璃电极）。
- **氧电极法（Clark 电极）**：测溶解氧 DO，I=KC。
- **阳极溶出伏安法**：测痕量重金属（镉、铅、铜、锌等）。
- **库仑滴定**：测 COD、SO₂；依据法拉第定律 W=ItM/(96500n)。
- **电导率**：测矿化度、降水电导率。

**滴定/重量法**
- **碘量法**：测溶解氧 DO（修正碘量法消除亚硝酸/亚铁干扰）。
- **重铬酸钾法**：测 COD（经典）。
- **硝酸银滴定法**：测氰化物、氯离子。
- **重量法**：测 TSP、PM₁₀、降尘、硫酸盐化速率（二氧化铅/碱片）、矿化度、可溶性盐分、油类。

**生物法**
- **BOD 五天培养法**：测 BOD₅。
- **微生物电极法**：快速测 BOD。
- **毒性试验（LD₅₀）**：危废急性毒性鉴别。

# 第三部分　关键流程、布点与计算详解（附例题）

## 3.1 布点方案大对比（务必能区分）

### 3.1.1 水质——河流监测断面（最常考）

| 断面 | 设置位置 | 作用 |
|---|---|---|
| **背景断面** | 基本未受人类活动影响的河段 | 评价整个水系污染程度的"本底" |
| **对照断面** | 流入监测河段前（一个河段一般只设 1 个） | 反映河段进水水质本底 |
| **控制断面** | 排污区（口）下游、污水与河水基本混匀处（数目按工业布局与排污口定） | 反映污染源对水体的影响 |
| **削减断面** | 城市/工业区**最后一个排污口下游 1500 m 以外** | 反映经稀释扩散自净后污染物明显降低的情况 |

> 记忆："**背-对-控-削**"，浓度变化是 本底→进水→受污染最重→自净降低。一个完整水系四种都设；某一河段只需"对照、控制、削减"三种。

**垂线上采样点的确定（按水深，常考）**

| 水深 | 采样点 |
|---|---|
| < 5 m | 水面下 0.5 m 处 1 个点 |
| 5–10 m | 水面下 0.5 m、河底上 0.5 m，共 2 个点 |
| > 10 m | 水面下 0.5 m、½ 水深处、河底上 0.5 m，共 3 个点 |

湖库：一般只设监测垂线；无明显功能区用**网格法**均匀布；重污染湖库在污染物主要输送路线上设控制断面。
地下水：两类井——**背景值监测井**（未污染地段、地下水流上游、垂直于流向）与**污染控制监测井**（污染源周围、尤其下游）。

### 3.1.2 空气——三种布点法对比

| 布点法 | 适用情形 | 要点 |
|---|---|---|
| **功能区布点** | 区域常规监测 | 分工业/商业/居民/交通/清洁区，各设若干点，不要求平均 |
| **网格布点** | 多个均匀分布的污染源 | 主导风向下风向点多，占总数 **60%** |
| **同心圆布点** | 多个污染源构成的污染群 | 以污染群中心为圆心画同心圆，圆周上布点，下风向多设 |
| **扇形布点** | 孤立高架点源、主导风向明显 | 点源为顶点、主导风向为轴；夹角一般 45°、**≤90°**；每条弧 3–4 点；上风向设对照点 |

补充：高烟囱（50 m）污染物最大落地浓度位置——不稳定 5–10 倍烟囱高、中性≈20 倍、稳定≥40 倍。

### 3.1.3 土壤——六种布点法

对角线（小块污灌，对角线 3–5 等分中点）、梅花（小而均匀，5–10 点）、棋盘（中等，>10 点；**固废污染土壤>20 点**）、蛇形（大而不均匀）、放射状（大气污染型，以污染源为中心画射线，下风向加密）、网格（背景值/农化污染）。

### 3.1.4 固体废物——份样数与采样点

- 份样数按批量查表（批量越大份样越多，如 1000–5000 t→30 份）。
- 份样量按最大粒度（粒度越大，最小份样量越大，如>150 mm→30 kg）。
- 堆存/运输固废：对角线、梅花、棋盘、蛇形。
- 运输车/容器：上(表面下 1/6 深)、中(1/2 深)、下(5/6 深)。
- 制样：粉碎→过筛→**四分法缩分**。

## 3.2 采样、保存与注意事项

### 3.2.1 水样类型（易混点）

| 类型 | 时间 | 地点 | 说明/适用 |
|---|---|---|---|
| 瞬时水样 | 某一时间 | 某一地点 | 水质稳定、变化不大时；一次性采样 |
| **综合水样** | **同时** | **不同点** | 不同采样点同时采集后混合（如为多条排污河渠建综合处理厂） |
| **混合水样** | **不同时** | **同点** | 同点不同时间等时/等比例混合（流量恒定、水质有变化的源） |
| 平均污水样 | 周期性 | 同/不同点 | 流量水质均变化的源（生活污水宜采此样） |
| 平均比例混合 | 不同时/同时 | 同点/不同点 | 排放量不稳定时按比例混合 |

> 区分口诀：**综合＝同时不同点；混合＝同点不同时**。

### 3.2.2 水样保存方法（高频）

四类基本手段：
1. **冷藏/冷冻**：抑制微生物、减缓挥发与反应。冷藏 2–5℃（不能长期）；冷冻 −20℃（不可充满容器）。
2. **加生物抑制剂**：如加 HgCl₂ 保存磷酸盐。
3. **调 pH**：测金属离子加 HNO₃ 至 **pH 1–2**（防水解沉淀＋防器壁吸附）；测氰化物/挥发酚加 NaOH 至 **pH 12** 生成稳定盐。
4. **加氧化剂/还原剂**：测汞加 HNO₃(pH<1)+0.05% K₂Cr₂O₇（保持高价）；测硫化物加抗坏血酸（防氧化）；测 DO 加硫酸锰+碱性碘化钾（固定）。

容器与瓶塞：碱性样品不能用玻璃塞→用橡皮塞；测有机物/细菌不能用橡皮塞。测溶解态组分先用 **0.45 μm 滤膜**过滤。

常考保存条目：COD 加 H₂SO₄ 至 pH<2、可存 7 d；DO（碘量法）加硫酸锰+碱性碘化钾、4–8 h（现场测）；氨氮/硝酸盐加 H₂SO₄ 至 pH<2、24 h；六价铬加 NaOH 至 pH 8–9、当天测。

### 3.2.3 采样注意事项（水）

需单独采样的项目：悬浮物、pH、DO、BOD、油类、硫化物、余氯、放射性、微生物。必须充满容器：DO、BOD、有机物。宜现场测定：pH、电导率、DO。采样需同步测水文与气象参数；样品瓶贴标签、塞紧密封、填采样登记表。

### 3.2.4 预处理

**消解（测含有机物水样中的无机元素）**——目的：破坏有机物、溶解悬浮固体、把待测元素氧化成单一高价态。消解后应透明澄清无沉淀。
- 湿法：硝酸（较清洁水）、硝酸-高氯酸（含难氧化有机物）、**硝酸-硫酸（5:2）**、硫酸-磷酸（消除 Fe³⁺ 干扰）、**硫酸-高锰酸钾（测汞）**、多元（测总铬用硫酸+磷酸+高锰酸钾）、碱分解（防易挥发组分损失）。
- 干灰化：450–550℃ 灼烧；**不适用于易挥发元素（砷、汞、镉、硒、锡）**。

**富集与分离**：气提（汞、硫化物）、顶空（VOCs）、蒸馏、溶剂萃取、固相萃取 SPE、吸附、离子交换、共沉淀、低温浓缩。土壤有机物提取常用振荡提取、索氏提取（农药、苯并(a)芘）。

## 3.3 评价标准与污染指数体系（结果表达）

- 水：与 GB3838-2002《地表水环境质量标准》比较；排污总量＝平均浓度×排放量。
- 气：AQI（见 3.4.6）。
- 土壤：单项/综合污染指数（见 3.4.9）。
- 固废：浸出毒性与鉴别标准比较。

## 3.4 ⭐重点计算专题（公式 + 例题 + 解析）

> 计算题是拉开分差的关键。下面每个专题给"公式 + 例题 + 解析"。建议每题自己默算一遍。

### 3.4.1 朗伯-比尔定律

$$A=\lg\frac{1}{T}=Kbc$$
A 吸光度；T 透射比；K 吸光系数；b 光程(cm)；c 浓度。A 与 c、b 成正比。
**用法**：标准曲线法——测一系列标准溶液 A 对 c 作图，再由样品 A 反查 c。

### 3.4.2 溶解氧 DO（碘量法）

反应链（要会写）：
```
MnSO₄ + 2NaOH → Mn(OH)₂↓
2Mn(OH)₂ + O₂ → 2MnO(OH)₂   （棕色沉淀，"固定"溶解氧）
MnO(OH)₂ + 2H₂SO₄ → Mn(SO₄)₂ + 3H₂O
Mn(SO₄)₂ + 2KI → MnSO₄ + I₂ + K₂SO₄
I₂ + 2Na₂S₂O₃ → 2NaI + Na₂S₄O₆   （硫代硫酸钠滴定）
```
- **修正碘量法**：含亚硝酸盐干扰→**叠氮化钠**法；含 Fe²⁺ 干扰→**高锰酸钾**法。
- DO(mg/L) = (c·V·8×1000)/V_水样（c：Na₂S₂O₃ 浓度 mol/L；V：滴定体积 mL；8＝氧当量）。

### 3.4.3 COD（重铬酸钾法）

$$COD_{Cr}(\text{mg O}_2/L)=\frac{(V_0-V_1)\times c\times 8\times1000}{V_{样}}$$
- V₀：滴定空白消耗硫酸亚铁铵体积(mL)；V₁：滴定水样消耗体积(mL)；c：硫酸亚铁铵浓度(mol/L)；8＝氧的摩尔质量的 1/2（每电子转移对应 8 g O）；V_样：水样体积(mL)。
- 试剂选择：COD>50 用 0.25 mol/L K₂Cr₂O₇；COD 5–50 用 0.025 mol/L（准确度较差）。
- 干扰：Cl⁻ 被氧化干扰→加 **硫酸汞** 络合掩蔽；催化剂 **硫酸银**；指示剂 **试亚铁灵（亚铁灵）**。吡啶不被氧化、芳香族不易氧化。

**例题**：取水样 20.0 mL，回流后用 0.250 mol/L 硫酸亚铁铵滴定，空白耗 V₀=20.0 mL，水样耗 V₁=12.0 mL。求 COD。
**解**：COD = (20.0−12.0)×0.250×8×1000/20.0 = 8.0×0.250×8×1000/20.0 = **800 mg/L**。

### 3.4.4 库仑滴定（法拉第定律）

$$W=\frac{I\,t\,M}{96500\,n}$$
W 电极反应物质量；I 电解电流；t 时间；M 摩尔质量；n 每摩尔转移电子数；96500 法拉第常数。

### 3.4.5 BOD（生化需氧量）

**定义**：有溶解氧条件下，好氧微生物分解有机物所耗 DO（20±1℃，暗处，5 天＝BOD₅）。

**理论需氧量例题（配平化学方程）**：求 1.67×10⁻³ mol/L 葡萄糖的理论需氧量。
C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O
1.67×10⁻³ mol/L × 6 (mol O₂/mol葡萄糖) × 32 (g/mol) = 0.321 g/L = **321 mg O₂/L**。

**五天培养法计算**：
- **稀释水未接种**：BOD₅ = (D₁−D₂)/P
- **稀释水接种**：BOD₅ = [(D₁−D₂) − (B₁−B₂)·f] / P

D₁ 培养前稀释样 DO；D₂ 培养 5 天后 DO；B₁、B₂ 接种对照培养前/后 DO；f＝接种稀释水占总体积的比例；P＝水样占总体积的比例（P=水样体积/300）。

**有效性判据**：稀释样 5 天**耗氧量 >2 mg/L 且剩余 DO >1（或2）mg/L** 才有效；多个有效稀释取平均。

**例题（简化"耗氧×300/取样体积"）**：某样两稀释 A、B：
| | A | B |
|---|---|---|
| 取样体积 mL | 15 | 30 |
| 初始 DO | 8.1 | 8.2 |
| 5 天 DO | 5.6 | 3.3 |
| 耗氧 | 2.5 | 4.8 |
BOD_A = 2.5×300/15 = 50 mg/L；BOD_B = 4.8×300/30 = 48 mg/L；两者均有效 → 平均 = (50+48)/2 = **49 mg/L**。
（若某稀释耗氧<2 或剩余 DO 不足，则该稀释无效，弃去。）

**BOD 反应模型（一级动力学）**：
- 剩余有机物（以氧当量）：$L_t=L_0e^{-k_1t}$
- 已耗（即时间 t 的 BOD）：$y_t=L_0(1-e^{-k_1t})$，L₀＝最终（总）碳质 BOD（UBOD）。
- k₁ 取值：未处理废水 0.12–0.46 d⁻¹（典型 0.23）；生物处理出水 0.12–0.23 d⁻¹。
- 温度校正：$k_T=k_{20}\theta^{(T-20)}$，θ 常取 1.047（20–30℃取1.056，4–20℃取1.135）。

**硝化（NBOD）**：NH₃ + 2O₂ → HNO₃ + H₂O；通常第 5–8 天才显著，故 BOD₅ 一般**不含硝化阶段**（属碳质 CBOD）。两阶段＝含碳氧化阶段＋硝化阶段。

**稀释水要求**：蒸馏水配，曝气 2–8 h 使 DO 近饱和，加 CaCl₂/FeCl₃/MgSO₄ 营养盐+磷酸盐缓冲，pH≈7.2，本身 BOD₅<0.2 mg/L；无微生物时加接种液（生活污水上清液等）。葡萄糖+谷氨酸标准液 1:50 稀释测得应在 **180–230 mg/L**。

### 3.4.6 空气质量指数 AQI

**分指数 IAQI**（线性内插）：
$$IAQI_P=\frac{IAQI_{Hi}-IAQI_{Lo}}{BP_{Hi}-BP_{Lo}}(C_P-BP_{Lo})+IAQI_{Lo}$$
- C_P 污染物实测浓度；BP_Hi/BP_Lo 与 C_P 相邻的浓度限值高/低位；IAQI_Hi/IAQI_Lo 对应分指数。
**AQI = max{IAQI₁, IAQI₂, …}**；AQI>50 时 IAQI 最大者为**首要污染物**；IAQI>100 者为**超标污染物**。
参与计算项目：SO₂、NO₂、PM₁₀、CO（日均）＋ O₃（8 h 均）（含 PM2.5）。

**例题**：某地 SO₂(24h)=80 μg/m³，NO₂(24h)=120 μg/m³，PM2.5(24h)=150 μg/m³，求各 IAQI、AQI 及首要污染物。
**解（用 GB3095-2012 分指数限值表内插）**：
- SO₂：80 落在 [50,150)→IAQI=(100−50)/(150−50)×(80−50)+50=50/100×30+50=**65**。
- NO₂：120 落在 [80,180)→IAQI=(100−50)/(180−80)×(120−80)+50=50/100×40+50=**70**。
- PM2.5：150 落在 [115,150]→IAQI=(200−150)/(150−115)×(150−115)+150=50+150=**200**。
- AQI=max{65,70,200}=**200**，首要污染物＝**PM2.5**（且 IAQI>100，为超标污染物）。
> 注：限值以现行 GB3095-2012 表为准，方法不变即"定位区间→线性内插→取最大"。

### 3.4.7 声压级及噪声叠加/相减（高频计算）

**三个"级"**（基准量记牢）：
$$L_W=10\lg\frac{W}{W_0}\quad(W_0=10^{-12}\,W)$$
$$L_I=10\lg\frac{I}{I_0}\quad(I_0=10^{-12}\,W/m^2)$$
$$L_p=10\lg\frac{p^2}{p_0^2}=20\lg\frac{p}{p_0}\quad(p_0=2\times10^{-5}\,Pa)$$

**噪声叠加**：声能/声强可代数相加，**声压不能直接相加**。总声压级：
$$L_{p总}=10\lg\!\left(10^{L_{p1}/10}+10^{L_{p2}/10}\right)$$
工程上用"增值曲线"：按两声级差 ΔL 查 ΔLp，加到较大者上。
- **例**：L_p1=96 dB，L_p2=93 dB，差 3 dB → 查曲线 ΔLp≈1.8 dB → L_p总=96+1.8=**97.8 dB**。
- 多声源：两两逐次叠加，与次序无关。

**噪声相减（扣背景）**：实测含背景 L_p、背景 L_p1，差 ΔL=L_p−L_p1 查背景修正曲线得 ΔLp，机器实际 L_p2=L_p−ΔLp。
- **例**：实测 104 dB，背景 100 dB，差 4 dB → 查得 ΔLp≈2.2 dB → 机器实际 = 104−2.2 = **101.8 dB**。

### 3.4.8 等效连续 A 声级 Leq

$$L_{eq}=10\lg\!\left(\frac{1}{T}\int_0^T 10^{0.1L_{pA}}\,dt\right)$$
离散形式（各级别 L_i 各占时间比例 t_i/T）：
$$L_{eq}=10\lg\!\left(\frac{1}{N}\sum_i 10^{0.1L_i}\right)\ (\text{等时间间隔})$$
**例**：等时间各测得 60、60、70 dB 三段，Leq=10·lg[(10⁶+10⁶+10⁷)/3]=10·lg[(1.2×10⁷)/3]=10·lg(4×10⁶)≈**66.0 dB**（注意是按能量平均，比算术平均偏向大值）。

### 3.4.9 土壤污染指数

- 单项污染指数：$P_i=\dfrac{C_i(\text{实测})}{S_i(\text{标准})}$
- 综合（内梅罗）污染指数：$P_{综}=\sqrt{\dfrac{\bar P^2+P_{max}^2}{2}}$（$\bar P$ 为各单项均值，$P_{max}$ 为最大单项）。
- 分级：P综≤0.7 安全(清洁)；0.7–1.0 警戒(尚清洁)；1.0–2.0 轻污染；2.0–3.0 中/重污染；>3.0 严重污染。
- 超标倍数=(实测−标准)/标准；分担率=某项指数/各项指数之和。

### 3.4.10 固废热值换算

高热值 H₀ → 低热值 Hₙ（扣除水蒸气与加热水分耗能）：
$$H_n=H_0\times\frac{100-(w_1+W)}{100}-5.85\,W_L$$
（w₁ 惰性物含量%、W 表面湿度%、W_L 剩余及吸湿性湿度%）。焚烧重要指标，垃圾焚烧可发电。

### 3.4.11 标准气体配制

- **静态配气**：原料气定量加入已知容积容器再充稀释气，浓度由加入量与容积算。例：100 mL 注射器取 99.99% CO，每次稀释 10 倍、连续 6 次→1×10⁻⁶。简单但活泼气体易被器壁吸附/反应。
- **动态配气**：连续稀释法、负压喷射法、渗透管法、气体扩散法、电解法。渗透管法定量可用重量法或化学分析法。

### 3.4.12 放射性相关

- 半衰期 T₁/₂：放射性核素衰变到原来一半所需时间。
- 照射量 X = dQ/dm（C/kg，旧单位伦琴 R）。
- 吸收剂量 D = dε/dm（J/kg，戈瑞 Gy）。
- 剂量当量 H = D·Q·N（Q 品质因数；单位 Sv）。

### 3.4.13 空气浓度两种表示及换算

- 质量浓度（mg/m³）：适用任何状态。
- 体积分数（mL/m³）：仅气态/蒸气态，不受 T、P 影响。
- 换算（标况）：质量浓度 = 体积分数 × M / 22.4（再按实际 T、P 修正）。

### 3.4.14 活性污泥（SV、SVI）

- 污泥沉降比 SV₃₀(%)：混合液倒入 1000 mL 量筒静置 30 min，沉降污泥体积/混合液体积。
- 污泥体积指数 SVI = SV₃₀(mL/L) ÷ MLSS(g/L)（即 1 g 干污泥沉降后占的体积 mL）。

# 第四部分　核心概念、标准与案例

## 4.1 必背名词解释清单（按概率排序）

- **环境监测**：对环境中污染物种类、浓度、分布及变化趋势进行测定，以判断环境质量的活动。
- **水体**：地表水、地下水及其包含的底质、水中生物等的总称（注意：不止"水"）。
- **化学需氧量 COD**：一定条件下，氧化 1 L 水样中还原性物质所消耗氧化剂的量，以 O₂ 的 mg/L 表示。
- **生化需氧量 BOD**：有溶解氧条件下，好氧微生物分解水中有机物的生化氧化过程所消耗的溶解氧量。
- **高锰酸盐指数**：以 KMnO₄ 为氧化剂测得的化学需氧量，反映地表水受有机物及还原性无机物污染程度。
- **总有机碳 TOC**：以碳含量表示水体有机物总量的综合指标（燃烧法，比 BOD/COD 更能反映有机物总量）。
- **溶解氧 DO**：溶解于水中的分子态氧。
- **一次污染物 / 二次污染物**：见 1.2。
- **光化学烟雾**：氮氧化物和碳氢化合物在紫外光作用下发生反应生成的混合污染物，最具破坏性的是 O₃ 和 PAN。
- **水体富营养化**：水体中氮、磷等营养物质过多导致藻类过度繁殖、水质恶化的现象。
- **危险废物**：列入国家危险废物名录或经鉴别具有易燃性、腐蚀性、反应性、毒性等危险特性的固体废物。
- **浸出毒性**：固废按规定浸出法浸取，浸出液中有害成分浓度超过鉴别标准的危险特性。
- **土壤背景值（本底值）**：未受或少受人类影响情况下，土壤中元素的含量；判断土壤是否污染的标尺。
- **声压级 Lp**：声压平方与基准声压平方之比取对数×10（=20 lg(p/p₀)），dB。
- **等效连续声级 Leq**：用相同时间内声能量相等的连续稳定 A 声级表示该时段噪声大小。
- **半衰期 T₁/₂**：放射性核素因衰变减少到原来一半所需时间。
- **空气质量指数 AQI**：将常规监测主要污染物浓度简化为单一数值、分级表示空气质量的指标（取各分指数最大值）。
- **瞬时水样 / 混合水样 / 综合水样**：见 3.2.1。

## 4.3 经典污染事件（案例分析常用）

- **日本水俣病**：甲基汞（Hg）污染海产，居民食用后中枢神经中毒。→ 对应"汞的监测"。古罗马用铅做美容粉/水管亦为铅害例证。
- **拉夫运河（Love Canal）事件**：填埋危险化学废物的社区，居民患病、出生缺陷增多。→ 危废填埋与渗滤液危害。
- **Times Beach（美国）**：二噁英（dioxin）污染撒布道路，全镇撤离。→ 焚烧/二噁英、危废标准。
- **洛杉矶光化学烟雾事件**：汽车尾气 NOₓ+HC 经紫外光生成 O₃、PAN，刺激眼睛、伤害植物。→ 二次污染物、光化学烟雾。
- **酸雨**（pH<5.6）：SO₂→H₂SO₄、NOₓ→HNO₃。我国西南为重酸雨区。

# 第五部分　速记卡与自测

## 5.1 数字速记（填空/选择高频）

- 河流削减断面：最后排污口下游 **1500 m** 外。
- 垂线采样：<5 m 一点；5–10 m 两点；>10 m 三点。
- 空气布点：扇形夹角≤90°(常45°)；网格下风向占 60%；周围 50 m 无源、270° 空间。
- 冷藏 2–5℃；冷冻 −20℃；测金属 pH 1–2；测氰化物/酚 pH 12；0.45 μm 滤膜。
- BOD₅：20±1℃、5 天、暗处；耗氧>2、剩余>2(或1) mg/L；稀释水 pH 7.2、BOD₅<0.2；标液 180–230 mg/L。
- COD：>50 用 0.25 mol/L，5–50 用 0.025 mol/L 重铬酸钾。
- 危废：闪点<60℃；浸出液 pH≤2 或 ≥12.5；钢腐蚀>0.64 cm/a；天然放射性>3700 Bq/kg。
- 土壤：每单元≥3 点；棋盘固废污染>20 点；混合样耕地 0–20 cm、果林 0–60 cm。
- 声学基准：p₀=2×10⁻⁵ Pa；W₀=I₀=10⁻¹² (W / W·m⁻²)。
- 波长：可见 400–780 nm；测汞 253.7 nm；SO₂ 577 nm；NOₓ 540 nm；FPD S 394/P 526 nm。
