## 模块一　公司金融基础（对应 Ross Ch1）

### 1.1 财务管理的三大决策领域
- **资本预算（Capital Budgeting）**：选择长期投资项目 →“买什么资产”。
- **资本结构（Capital Structure）**：债务与股权的比例 →“钱从哪来”。
- **营运资本管理（Working Capital Management）**：短期资产/负债的日常管理 →“短钱怎么周转”。
> 对应：Ch1-1。这是整门课的“地图”，后续所有内容都落在这三块上。

### 1.2 企业组织形式对比

| 维度 | 独资/合伙 | 公司制 |
|---|---|---|
| 责任 | **无限责任** | **有限责任** |
| 存续期 | 有限（依附业主） | 无限 |
| 所有权转让 | 困难 | 容易（股份自由买卖） |
| 筹资能力 | 弱 | 强 |
| 税收 | 仅个人层面**一次** | **双重征税**（公司层面+股东层面） |
| 设立/监管 | 简单、少 | 复杂、多 |

> 对应：Ch1-2、Ch1-3。**记忆抓手**：独资/合伙的命门是“无限责任+难筹资”，公司制的命门是“双重征税”，其余维度公司制几乎全胜。

### 1.3 代理问题（Agency Problem）
- **公司归股东所有**；股东选**董事会**，董事会聘/督/解雇**管理层**（委托链）。
- **根源**：**所有权与控制权分离**——经理人（代理人）替股东（委托人）经营。
- **表现**：经理追求私利（在职消费、盲目扩张、过度避险、短视、抵制有利并购）。
- **代理成本** = 直接成本（监督、激励）＋ 间接成本（次优决策的价值损失）。
- **公司目标**：管理层应**最大化现有股东每股股票的市场价值（股东财富最大化）**。
> 对应：Ch1-7。常考“为什么会有代理问题”“如何缓解”（激励薪酬、董事会监督、并购威胁、债务约束等）。

## 模块二　财务报表（对应 Ross Ch2）

### 2.1 资产负债表恒等式
```
资产 = 负债 + 所有者权益
总资产 = 流动资产 + 净固定资产
总负债 = 流动负债 + 长期负债
股东权益 = 总资产 − 总负债
```
### 2.2 净营运资本（Net Working Capital, NWC）
```
NWC = 流动资产 − 流动负债
```
> NWC>0 表示短期资产足以覆盖短期负债，是流动性的粗略指标。

### 2.3 利润表自上而下的结构
```
销售收入
− 成本（COGS 等）
− 折旧
= EBIT（息税前利润）
− 利息
= EBT（应税利润）
− 所得税（= EBT × 税率）
= 净利润
```
> 对应：Ch2-1、Ch2-2。**易错点**：① 折旧是**非现金费用**但在计税前要扣（产生折旧税盾）；② **利息在税前扣除**（利息税盾），所以先减利息、再计税。

## 模块三　资本预算决策准则（对应 Ross Ch9）

### 3.1 净现值（NPV）
```
NPV = −初始投资 + Σ CFt / (1+r)^t
```
- **法则**：NPV>0 接受；互斥项目选 NPV 最大者。**NPV 是最可靠的准则**（直接度量价值创造、可加、考虑全部现金流与货币时间价值）。

### 3.2 内含报酬率（IRR）
- **定义**：使 NPV = 0 的折现率。
- **法则**：独立项目 IRR > 要求回报率则接受。
- **缺陷**：① 非常规现金流可能有**多个 IRR 或无 IRR**；② **互斥项目**中 IRR 可能与 NPV 排序冲突；③ 隐含“按 IRR 再投资”假设。

### 3.3 交叉率（Crossover Rate）与 NPV–IRR 冲突
- **交叉率**：使两项目 NPV 相等的折现率；用**差额现金流（A−B）令 NPV=0** 求得。
- **冲突条件**：当**要求回报率 < 交叉率**时，NPV 与 IRR 对互斥项目排序相反。
- **根因**：项目**现金流时间分布不同**（“后置/递增”型对低折现率更敏感）或**规模不同**。
> 对应：Ch9-2（IRR_A≈26.79%、IRR_B≈38.54%、交叉率≈5.42%）。**结论**：互斥决策**以 NPV 为准**。

## 模块四　资本结构与财务杠杆（对应 Ross Ch16）

### 4.1 财务杠杆与 EBIT–EPS 分析
- **财务杠杆**：用债务融资放大股东回报（同时放大风险）。
- 无税时：`EPS = (EBIT − 利息) / 股数`；`ROE` 随 EBIT 同向、随杠杆放大。
- **盈亏平衡 EBIT（break-even / indifference EBIT）**：两种资本结构下 EPS（ROE）相等的 EBIT。
```
令 (EBIT − I₁)/N₁ = (EBIT − I₂)/N₂ 求解 EBIT*
高于 EBIT* → 高杠杆结构 EPS/ROE 更高；低于则相反。
```
### 4.2 债务回购股票的机制
```
新增债务额 / 回购价 = 回购股数 → 重组后股数下降，利息上升。
```
> 对应：Ch16-1（新增 $45M 债务回购 100 万股，盈亏平衡 EBIT = $47.7M）。**要点**：杠杆是把“双刃剑”——景气（高 EBIT）时放大收益，衰退（低 EBIT）时放大亏损与破产风险。MM 无税命题下，杠杆改变 EPS/ROE 的**水平与波动**，但本题“忽略税”，仅比较 EPS 高低临界点。

## 模块五　股利政策（对应 Ross 股利章）

### 5.1 现金股利 vs 股票股利 vs 股票分割
| 类型 | 是否流出现金 | 股数 | 每股价格 | 股东权益总额 | 公司价值 |
|---|---|---|---|---|---|
| 现金股利 | 是 | 不变 | 除息下跌 | 减少（现金流出） | 减少 |
| 股票股利 | 否 | 增加 | 按比例下跌 | **不变**（科目重分类） | **不变** |
| 股票分割 | 否 | 大幅增加 | 按比例下跌 | 不变 | 不变 |

### 5.2 股票股利的会计处理
- **小额股票股利（<20%~25%）**：按**市价**入账。
```
从留存收益转出 = 新发股数 × 市价
  → 转入普通股(面值) = 新发股数 × 每股面值
  → 转入资本公积      = 新发股数 × (市价 − 面值)
```
- **大额股票股利（≥20%~25%）**：常按**面值**入账（仅按面值从留存收益转出）。
> 对应：股利-2。**核心结论**：股票股利/分割**不改变股东权益总额、不改变公司价值**，只是“账面搬家”，每股价值按比例摊薄。**易错点**：别忘了由“普通股=面值×股数”反推股数（如 $20,000 ÷ $0.50 = 40,000 股）。

## 模块六　货币时间价值（对应 Bodie & Merton）

### 6.1 单笔现值/终值
```
FV = PV × (1+r)^n        PV = FV / (1+r)^n
```
> 远期现金流被复利“折”得很小（如 10% 下 60 年后的 $100 现值仅 $0.33）。

### 6.2 年金（Annuity）
```
普通年金现值（期末付）：PV = C × [1 − (1+r)^(−n)] / r
普通年金终值：          FV = C × [(1+r)^n − 1] / r
预付年金（期初付）：     PV(due) = PV(普通) × (1+r)
```
### 6.3 永续年金（Perpetuity）
```
普通永续：PV = C / r
增长永续：PV = C₁ / (r − g)   （g < r）  ← 即 Gordon 模型
```
> 对应：现值-3（a–e 正好覆盖单笔、普通年金、预付年金、永续）。**预付年金 = 普通年金 ×(1+r)**，因每笔提前一期、多滚一年利息。

### 6.4 复利、竞争与一价定律
- 同期限、同风险的金融产品，利率会被市场竞争拉平（**Law of One Price**）。
> 对应：储蓄-12（高利率银行吸引存款，低利率银行被迫提息）。

## 模块七　风险与收益、名义/实际利率（对应 Bodie & Merton）

### 7.1 持有期收益率
```
收益率 = (现金股利 + 期末价 − 期初价) / 期初价
       = 股利收益率 + 资本利得率
```
- “期望收益率”用预期价；“已实现收益率”用实际价。
> 对应：QC 2-14。

### 7.2 名义利率与实际利率（Fisher 关系）
```
精确式：(1 + 名义) = (1 + 实际) × (1 + 通胀)
       实际利率 = (名义 − 通胀) / (1 + 通胀)
近似式：实际 ≈ 名义 − 通胀
```
> 对应：QC 2-15、QC 2-16。**要点**：名义无风险（国库券）≠ 实际无风险；真实通胀事前未知，故实际回报有风险；TIPS 锁定实际利率。

### 7.3 杠杆与风险分配
- **剩余索取权人（股权）先承担损失**；债权人优先受偿、风险靠后。
- 财务杠杆放大股权的收益与风险。
> 对应：房地产-5（自有 $20k、借 $80k，股权投资者承担首损风险）。

## 模块八　债券估值（对应 Bodie & Merton）

### 8.1 零息债券、即期利率、贴现因子
```
零息债券价格(每$1面值) = 贴现因子 dₜ = 1 / (1 + sₜ)^t
即期利率 sₜ（spot rate）= dₜ^(−1/t) − 1
```
### 8.2 用贴现因子给息票债券定价
```
债券价格 = Σ (票息ₜ × dₜ) + 面值 × d_T
         = 票息 × d₁ + (票息 + 面值) × d₂ + …
```
### 8.3 到期收益率（YTM）vs 即期利率
- **YTM**：使债券所有现金流折现等于其价格的**单一**利率。
- **零息债券的 YTM = 该期限的即期利率**；
- **息票债券的 YTM 是各期即期利率按现金流加权的“复杂平均”**。
- **当收益率曲线非水平时**，相同期限、不同票息的债券 **YTM 不同**；YTM ≠ 即期利率。
> 对应：债券-3（2 年息票债价 $1,012.20；2 年零息 YTM 5.409%；2 年息票 YTM≈5.34%；二者不同因现金流分布不同）。

## 模块九　股票估值：股利贴现模型（对应 Bodie & Merton）

### 9.1 Gordon 增长模型（DDM）
```
V₀ = D₁ / (k − g)，  其中 D₁ = D₀ × (1 + g)，要求 k > g
```
- `k`：市场资本化率/要求回报率；`g`：股利永续增长率。
### 9.2 参数敏感性（反解）
- 给定市价 P，反解 g 或 k 来“合理化”价格：
```
P = D₀(1+g)/(k − g)
固定其一、解另一个。
```
> 对应：DDM-6（V₀=$26.25；要使 P=$20：g→2.73% 或 k→15.5%）。**要点**：分母 (k−g) 很小 → 估值对 g、k **极度敏感**；市价低于估值意味着市场预期更低增长或更高要求回报。

## 模块十　衍生品风险度量：希腊字母（对应 Hull）

### 10.1 泰勒展开统一框架
```
ΔΠ ≈ Delta×ΔS + ½×Gamma×(ΔS)^2 + Vega×Δσ + Theta×Δt + Rho×Δr
```
| 希腊字母 | 衡量 | 一阶/二阶 | 近似式 |
|---|---|---|---|
| **Delta (Δ)** | 对标的价格 S 的敏感度 | 一阶 | ΔΠ ≈ Δ × ΔS |
| **Gamma (Γ)** | Delta 对 S 的敏感度（曲率） | 二阶 | ΔΠ ≈ ½Γ × (ΔS)^2 |
| **Vega (ν)** | 对波动率 σ 的敏感度 | — | ΔΠ ≈ ν × Δσ |
| **Theta (Θ)** | 对时间流逝的敏感度 | — | ΔΠ ≈ Θ × Δt |

### 10.2 关键直觉
- **Delta 中性**组合：一阶价格风险被对冲，价值变动由 **Gamma 项**主导。
- **正 Gamma**：标的**大幅波动（无论涨跌）都有利**（(ΔS)² 与方向无关）→“做多波动率”。
- **正 Vega**：波动率上升有利。
> 对应：Hull 8.1（Δ=−2,100 → −$10,500）、8.2（ν=200 → +$400）、8.3（Γ=30，±$2 均 +$60）。

## 模块十一　金融机构的利率风险（对应 Hull Ch9）

### 11.1 重定价缺口（Repricing Gap）
```
缺口 = 利率敏感资产(RSA) − 利率敏感负债(RSL)
ΔNII ≈ 缺口 × Δ利率
```
- **负缺口（负债敏感）**：升息 → 净利息收入**下降**；
- **正缺口（资产敏感）**：升息 → 净利息收入**上升**。
> 对应：Hull 9.1（短期 RSA $5B < RSL $15B → 负缺口 −$10B → 升息使 NII 逐年下降）。本质是“**借短贷长**”的期限错配。

### 11.2 收益率曲线形态
- **通常上斜（长>短）**：期限/流动性溢价 + 升息预期 + 不确定性补偿。
- **倒挂（长<短）**：市场预期未来短期利率下降，常因预期衰退或当前短端因紧缩异常高企；**倒挂常领先衰退**。
> 对应：Hull 9.2。

## 模块十二　波动率的时间标度（对应 Hull Ch10）

### 12.1 √t 法则
```
SD(T 期) = 单期波动率 × √T
日波动率 = 年化波动率 / √(交易日数)   （Hull 常用 252）
```
### 12.2 正态下的置信区间
```
95% 区间 ≈ ±1.96 × 标准差
99% 区间 ≈ ±2.33 × 标准差（单尾 2.33，双尾 2.58）
```
> 对应：Hull 10.1（2%×√3 = 3.46%）、10.2（25%/√252 = 1.57%；95% 区间 ±3.09%）。**要点**：波动率（标准差）随 √时间 缩放，而非随时间线性缩放。

## 模块十三　风险度量：VaR 与期望损失 ES（对应 Hull Ch12）

### 13.1 在险价值（Value at Risk, VaR）
- **定义**：在给定置信水平 c 与持有期内，损失**不会超过**的临界值；即损失分布的 **c 分位数**。
- **解读**：99% VaR = $X → 有 1% 概率损失超过 $X。
- **缺陷**：① 只看“临界点”，**不反映尾部超出后的严重程度**；② **不满足次可加性**（非一致性度量）。

### 13.2 期望损失（Expected Shortfall, ES / CVaR）
- **定义**：在损失**超过 VaR 的条件下**，损失的**期望（平均）值**——即**最坏 (1−c) 尾部的平均损失**。
- **解读**：99% ES = $Y → 在最坏 1% 情形中，平均损失 $Y。
- **优点**：刻画尾部均值，**满足次可加性（是一致性风险度量）**。

### 13.3 一致性风险度量与次可加性（subadditivity）
- **次可加性**：ρ(A+B) ≤ ρ(A) + ρ(B)，即“**分散化不应增加风险**”。
- **VaR 可能违反**；**ES 始终满足**。
- 一致性（coherent）风险度量四公理：单调性、次可加性、正齐次性、平移不变性。
> 对应：Hull 12.3/12.4（解读 VaR、ES）、12.5（数值证明 VaR 违反、ES 满足次可加性：VaR 组合 $11M > 单项之和 $2M；ES 组合 $11.07M < 单项之和 $18.2M）。

### 13.4 计算离散损失分布的 VaR/ES（操作步骤）
```
1) 列出所有损失情形及其概率（独立时用乘法求联合概率）；
2) 按损失从小到大排序，算累计概率；
3) VaR = 累计概率首次 ≥ c 处对应的损失值；
4) ES = 最坏 (1−c) 概率质量上的概率加权平均损失
       （若 VaR 处概率跨越边界，需按比例切分该档概率）。
```

## 跨模块易错点清单

1. **利息税前扣、折旧也税前扣**：利润表别把顺序搞反（先 EBIT，再减利息得 EBT，再计税）。
2. **互斥项目用 NPV，不用 IRR**：IRR 高 ≠ 价值大；交叉率以下排序会反。
3. **预付年金 = 普通年金 ×(1+r)**：别忘乘 (1+r)。
4. **YTM ≠ 即期利率**（曲线非平时）：息票债 YTM 是各期即期利率的加权平均。
5. **股票股利不改变总权益与公司价值**：只是科目重分类；先由面值反推股数。
6. **Gamma 项与方向无关**：(ΔS)² 涨跌都为正；Delta 中性时由 Gamma 主导。
7. **波动率按 √t 缩放**，不是线性。
8. **VaR 只是临界值、可能不次可加；ES 看尾部均值、且一致**。
9. **负重定价缺口（负债敏感）下，升息使 NII 下降**。
10. **Gordon 模型对 (k−g) 极敏感**：分母小，参数微调引起估值剧变。
