## 二、公式手册（核心必背）

### 财务报表
```
资产 = 负债 + 所有者权益
NWC  = 流动资产 − 流动负债
EBIT = 销售 − 成本 − 折旧
净利润 = (EBIT − 利息) × (1 − 税率)
```

### 货币时间价值
```
单笔：FV = PV(1+r)^n ；  PV = FV/(1+r)^n
普通年金现值：PV = C·[1 − (1+r)^(−n)]/r
普通年金终值：FV = C·[(1+r)^n − 1]/r
预付年金现值：PV(due) = PV(普通)·(1+r)
永续年金：PV = C/r
增长永续(Gordon)：PV = C₁/(r − g)
```

### 资本预算
```
NPV = −C₀ + Σ CFt/(1+r)^t
IRR：令 NPV = 0 的 r
交叉率：对差额现金流 (A−B) 令 NPV = 0
```

### 资本结构（无税）
```
EPS = (EBIT − 利息)/股数
盈亏平衡 EBIT*：(EBIT−I₁)/N₁ = (EBIT−I₂)/N₂
回购股数 = 新增债务 / 回购价
```

### 股票股利（小额，按市价）
```
转出留存收益 = 新发股数 × 市价
→ 普通股 += 新发股数 × 面值
→ 资本公积 += 新发股数 × (市价 − 面值)
股东权益总额不变
```

### 风险与利率
```
收益率 = (股利 + 期末价 − 期初价)/期初价
Fisher：(1+名义) = (1+实际)(1+通胀)
实际利率 = (名义 − 通胀)/(1 + 通胀)
```

### 债券
```
贴现因子 dₜ = 1/(1+sₜ)^t（= 零息债券每$1面值价格）
即期利率 sₜ = dₜ^(−1/t) − 1
息票债券价格 = Σ 票息·dₜ + 面值·d_T
YTM：令现金流折现 = 价格 的单一利率
```

### 股票 DDM
```
V₀ = D₁/(k − g)，D₁ = D₀(1+g)，需 k > g
```

### 希腊字母（泰勒近似）
```
ΔΠ ≈ Δ·ΔS + ½Γ·(ΔS)^2 + ν·Δσ + Θ·Δt
Delta 中性时：ΔΠ ≈ ½Γ·(ΔS)^2（由 Gamma 主导）
```

### 波动率 & VaR
```
SD(T) = σ_单期 × √T
日波动率 = 年化/√252
95% 区间 ≈ ±1.96·SD ； 99% 单尾 z ≈ 2.33
VaR = 损失分布的 c 分位数
ES  = 最坏 (1−c) 尾部的平均损失
次可加性：ρ(A+B) ≤ ρ(A)+ρ(B)（VaR 可能违反，ES 满足）
```

## 三、模块要点速记

### ① 公司金融基础
- 三大决策：**投资(资本预算) / 融资(资本结构) / 营运资本**。
- 组织形式：独资合伙＝**无限责任+难筹资+寿命有限+难转让**；公司制＝**有限责任+易筹资+永续+易转让，但双重征税**。
- 代理问题：**所有权与控制权分离** → 经理私利 → 代理成本；目标＝**股东财富（股价）最大化**。

### ② 财务报表
- 恒等式 + NWC；利润表顺序：销售→EBIT→减利息→EBT→计税→净利润。
- **利息、折旧均在税前扣**（税盾）。

### ③ 资本预算
- **NPV 最可靠**；互斥项目**以 NPV 为准**。
- IRR 缺陷：多解/与 NPV 冲突。
- **折现率 < 交叉率 → NPV 与 IRR 排序冲突**（后置/递增型项目对低折现率更敏感）。

### ④ 资本结构
- 杠杆＝双刃剑：高 EBIT 放大 EPS/ROE，低 EBIT 放大亏损。
- **盈亏平衡 EBIT*** 以上才宜加杠杆。
- 用债务回购股票：股数↓、利息↑。

### ⑤ 股利政策
- 现金股利：现金↓、权益↓；**股票股利/分割：总权益与公司价值不变**，仅科目重分类、每股摊薄。
- 别忘**由面值反推股数**（面值×股数＝普通股账面）。

### ⑥ 货币时间价值
- 单笔/年金/永续三套公式；**预付＝普通×(1+r)**；远期现金流现值极小。
- 竞争 → **一价定律**：同质产品利率被拉平。

### ⑦ 风险与利率
- 总收益＝股利收益+资本利得；期望 vs 已实现。
- **Fisher**：名义无风险≠实际无风险（通胀未知）。
- 杠杆下**股权承担首损风险**，债权优先。

### ⑧ 债券
- 零息价格＝贴现因子；**零息 YTM＝即期利率**。
- 息票债券用贴现因子逐期定价。
- **曲线非平时 YTM≠即期利率**；息票债 YTM 是各期即期利率的加权平均。

### ⑨ 股票 DDM
- V₀ = D₁/(k−g)；对 **(k−g) 极敏感**。
- 市价低于估值 → 市场预期更低 g 或更高 k。

### ⑩ 希腊字母
- Δ 一阶、Γ 二阶（曲率）、ν 波动率、Θ 时间。
- **Delta 中性 → Gamma 主导**；**正 Gamma：大幅波动（涨跌皆可）有利**。

### ⑪ 银行利率风险
- 重定价缺口＝RSA−RSL；**负缺口（负债敏感）下升息使 NII↓**（借短贷长）。
- 收益率曲线通常上斜（期限溢价）；**倒挂＝预期降息/衰退信号**。

### ⑫ 波动率
- **√t 法则**；正态置信区间 ±1.96σ（95%）。

### ⑬ VaR / ES
- VaR＝分位临界值（不看尾部严重度，**可能不次可加**）。
- ES＝尾部平均损失（**一致性度量，满足次可加性**）→ 监管更青睐。

## 五、易错红线（考前再看一眼）

1. 利润表顺序：EBIT → 减利息 → EBT → 计税 → 净利润。**利息税前扣**。
2. **互斥项目用 NPV**；交叉率以下 IRR 与 NPV 排序相反。
3. 预付年金 **×(1+r)**，别漏。
4. **YTM ≠ 即期利率**（曲线非平）；息票债 YTM 是加权平均。
5. **股票股利不改变总权益/公司价值**；先用面值反推股数。
6. **(ΔS)² 与涨跌方向无关**；Delta 中性时 Gamma 主导。
7. 波动率按 **√t** 缩放，不是线性。
8. **VaR 可能违反次可加性，ES 满足**。
9. **负缺口（负债敏感）升息 → NII 下降**。
10. **Gordon 对 (k−g) 极敏感**：分母小，估值放大。
