## 二、名词解释

1. **卫生填埋**：利用工程手段采取技术措施，防止渗滤液及有害气体污染水/土/气，最大幅度压实减容、随时覆盖，使整个过程对公共卫生与环境无害的垃圾土地处理方法。
2. **腐熟度**：成品堆肥的稳定程度，工程上是堆肥反应完成的信号、农业上是产品质量指标（可用 GI>90%、淀粉消失、耗氧速率低等判定）。
3. **低位发热量（LHV）**：单位燃料完全燃烧、产物中水蒸气仍以**气态**存在时放出的热量（即从高位发热量中扣除水蒸气汽化潜热）。
4. **旋流电沉积**：使电解液以旋流（高流速切向）流动减薄阴极扩散边界层、消除浓差极化，从而在低金属离子浓度下也能高效获得致密片状金属、并可分步回收多金属的电沉积技术。
5. **危险废物**：列入《国家危险废物名录》或经鉴别具有腐蚀性、毒性、易燃性、反应性、感染性等一种或以上危险特性的固态、液态或其他形态的废物。

## 三、论述题（要点）

**1. 二噁英与 NOₓ 生成机制及控制**（详见笔记 7.12）
- 二噁英生成：①不完全燃烧残留前驱体（氯苯/氯酚）；②飞灰催化下 250–500℃ 经 de novo 反应再合成。
- 控制（"3T+急冷"）：炉膛 >850℃（>925℃ 更佳）+ 强湍流 + 烟气停留 ≥2 s 彻底分解；烟气急冷几秒内降至 <400℃ 避开再合成温区；控 CO 与未燃碳、降飞灰；活性炭吸附 + 袋式除尘；源头减氯。
- NOₓ 生成：热力型（高温 N₂+O₂）、燃料型（燃料 N 氧化）、快速型。
- 控制：源头控温 <1500℃、分级/低氮燃烧、控过剩空气；末端 SNCR（850–1100℃ 喷氨/尿素无催化剂）、SCR（加催化剂低温高效）。

**2. 上吸式 vs 下吸式气化炉**（详见笔记 6.6）
- 上吸式（逆流）：气化剂自下而上与物料逆流，燃气从顶部排出经热解/干燥层，**焦油含量高、燃气脏**，但热效率高、可处理高水分料。
- 下吸式（顺流）：气化剂与物料同向下行，燃气从底部经高温氧化区排出，**焦油被裂解、燃气洁净**，适合直接发电，但对原料粒度水分要求高、出口气温高。
- 适用：上吸式用于对气质要求不高、原料水分高的场合；下吸式用于需洁净燃气直接利用（发电）的场合。

**3. 堆肥温度动态与微生物演替、C/N 作用**（详见笔记 5.2、5.4）
- 三阶段："升温（中温 15–45℃）→ 高温（45–65℃，极限 80–90℃）→ 降温（腐熟）"。
- 耦合：中温阶段嗜温菌分解易降解物产热升温；高温阶段嗜热菌强烈分解纤维素/蛋白质并杀灭病原菌虫卵（>55℃ 持续 5 d）；降温阶段嗜温菌重占优分解难降解物、腐殖化稳定。温度决定优势菌群、菌群产热又驱动温度，互为因果。
- C/N 作用：碳为微生物能源、氮为合成菌体原料；适宜 C/N（20–30):1 促增殖与腐殖化；过高→降解慢、腐熟延迟；过低→氮过剩以 NH₃ 挥发损失、产臭。

## 四、计算题

**1. 焚烧热量平衡**（基准 1 kg 垃圾，输入热 11630 kJ）

- 未燃碳：灰分 0.20 kg 占残渣 95% → 残渣 R = 0.20/0.95 = 0.2105 kg，未燃碳 = 0.0105 kg
  Q₁ = 0.0105 × 32564 = **341.9 kJ**
- 水分蒸发（原生水 0.20 + 氢生成水 9×0.04=0.36 = 0.56 kg）
  Q₂ = 0.56 × 2420 = **1355.2 kJ**
- 残渣显热（ΔT = 650−65 = 585℃）
  Q₃ = 0.2105 × 0.323 × 585 = **39.8 kJ**
- 辐射损失 Q₄ = 0.005 × 11630 = **58.2 kJ**
- 总损失 = 341.9 + 1355.2 + 39.8 + 58.2 = **1795 kJ**

**可利用热量 = 11630 − 1795 = 9835 kJ/kg ≈ 9.84 MJ/kg**
**热利用效率 η = 9835/11630 ≈ 84.6%**

> 若 11630 已为低位热值（仅计原生水分蒸发 0.20×2420=484 kJ）：可利用热 ≈ 11630−341.9−484−39.8−58.2 = 10706 kJ/kg（η≈92%）。注明假设即可得分。

**2. 厌氧消化罐容积**

- 有效容积 V_有效 = K·Q_有机·T/(D_ave·N) = 1.1×300×34/(1.0×3) = 11220/3 = **3740 m³**（≈3735 m³）
- 总容积 V_总 = V_有效/E = 3740/0.83 ≈ **4506 m³**（≈4500 m³）
- 有机容积负荷 VOL = Q_有机·DM·VDM/V_有效 = 300×1000×0.35×0.65/3740 ≈ **18.2 kg/(m³·d)**（单罐计：除以 N 后 ≈6.1 kg VDM/(m³·d)）

> 注：VOL 若按"全厂总有效容积 3×3740=11220 m³"计：300×1000×0.35×0.65/11220 ≈ 6.08 kg VDM/(m³·d)，落在 6–11 合理区间。

## 五、综合题参考答案

1. 属于**间接机制**（也兼具直接机制，但题述以代谢产物浸出为主，为间接机制）。两个关键氧化反应：
   - Fe²⁺ 氧化：4Fe²⁺ + O₂ + 4H⁺ →(菌) 4Fe³⁺ + 2H₂O（生成强氧化剂 Fe³⁺）
   - S 氧化：2S + 3O₂ + 2H₂O →(菌) 2H₂SO₄（生成酸性环境）
   随后 Fe³⁺/酸化学浸出铜：Cu + 2Fe³⁺ → Cu²⁺ + 2Fe²⁺（Fe²⁺ 再被菌氧化循环）。

2. 传统电沉积中，阴极附近金属离子被消耗形成**扩散边界层**，低浓度时离子传质跟不上电极反应速率，**浓差极化**严重，导致沉积疏松呈粉状；旋流的高流速切向冲刷**减薄边界层**、强化传质、**消除浓差极化**，使阴极表面离子浓度维持较高、沉积均匀致密，故低浓度下也能得片状铜。

3. 环境效益优势（≥3）：①**能耗显著降低**（无需高温熔炼）；②**CO₂ 排放低**（避免燃料燃烧与高温过程）；③**废水排放少/可循环**（旋流电沉积近零废水、浸出液循环）；④**SO₂/NOₓ 等废气少**；⑤固废排放少；⑥常温常压、条件温和、二次污染小。

4. 生物冶金瓶颈：①**菌种难培养、对环境敏感、易染杂菌**；②**浸出周期长（数天）、效率/速率低**；③高金属浓度/毒性对菌有抑制；④规模放大传质与控制难。改进思路：①**纳米催化强化**（N-CNTs/石墨烯提速 >20%）；②选育/驯化耐受性强的高效菌株或混合菌群、基因工程改造；③优化反应器（滚筒卧式浸出反应器）与操作参数（pH、温度、固液比、Fe²⁺ 浓度）；④两段法（先生物产酸再浸出）提高效率。

## 二、名词解释

1. **热解**：利用有机物热不稳定性，在无氧或缺氧条件下加热使其热裂解，经冷凝得到可燃气、液态油和固体炭等新产物的过程（吸热过程）。
2. **矿化垃圾**：填埋场垃圾经 8–10 年达到基本稳定化、可开采利用的产物（有机质 9–15%、粒径 <40 mm、微生物丰富、阳离子交换能力强）。
3. **理论空气量（A₀）**：单位质量废物完全燃烧所需的最低（理论）空气量（kg 空气/kg 废物或 Nm³/kg）。
4. **固化/稳定化**：用添加剂或化学/物理手段使危险废物中的污染组分呈化学惰性或被包容固定，降低其浸出毒性与迁移性，便于安全贮运、利用或处置的技术。
5. **木塑复合材料**：以木质纤维（木粉/竹粉）为增强相、热塑性塑料（PE/PP/PVC）为基体，加偶联剂等添加剂，经挤出/注塑制成的复合材料。

## 三、论述题（要点）

**1. 源头分类意义、C₁–C₄ 对比、确定原则**（详见笔记 2.3）

## 五、综合题参考答案

1. 三阶段：**液化（水解）→ 酸化（产酸/产氢产乙酸）→ 气化（产甲烷）**。对酸抑制最敏感的是**产甲烷菌**（最适 pH 6.6–7.5，pH<6 受抑甚至停止）。

2. 影响：丙酸等挥发性脂肪酸积累使 pH 跌破 6，**抑制产甲烷菌活性**，产气与甲烷含量下降，严重时"酸化"导致发酵失稳停止。措施（≥2）：①投加碱度/缓冲剂（石灰、碳酸氢钠）维持 pH>7、碱度 >2000 mg/L；②降低有机负荷或进料速率、延长 SRT；③加强搅拌混合改善传质、避免局部酸积累；④两步发酵（产酸与产甲烷分离）；⑤控制 C/N≈25、补充微量元素。

3. 干式厌氧（TS>20%）优缺点：优点——需水少、沼液（消化液）产量小、占地小、流程简单、能耗低、无需大量稀释/去杂（不易分层）；缺点——传质受限、易氨氮积累抑制、产气率相对偏低、对罐体搅拌/进料设备要求高。

4. 不能直接作车用燃料原因：①CH₄ 含量（55–65%）远低于天然气（>90%），**热值低**；②含 **CO₂（35–45%）、H₂S、水汽**等杂质（H₂S 腐蚀且有毒）。提纯步骤：**脱硫（脱 H₂S）→ 脱水（脱水汽）→ 脱碳（脱 CO₂ 提高 CH₄）→ 脱氮**，提纯至生物天然气标准（CH₄>90%）后方可作车用燃料。
