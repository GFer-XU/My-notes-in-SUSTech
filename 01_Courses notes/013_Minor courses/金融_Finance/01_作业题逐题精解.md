## 第一部分　公司理财基础（Ross）

### Ch1-1　财务管理决策的三种类型 [LO1]

**题目**：财务管理的三类决策是什么？各举一个相关的业务交易例子。

**解答**

| 决策类型 | 核心问题 | 业务交易举例 |
|---|---|---|
| ① 资本预算（Capital Budgeting，投资决策） | 应投资哪些长期项目/资产？ | 决定是否新建一座工厂、上线一条新产品线、购置生产设备 |
| ② 资本结构（Capital Structure，融资决策） | 用什么方式、什么债务-股权比例来筹资？ | 发行公司债 vs. 增发股票；确定目标负债权益比 |
| ③ 营运资本管理（Working Capital Management） | 如何管理短期资产与短期负债（日常资金）？ | 确定给客户的赊销信用期、管理存货水平、安排向供应商付款 |

**要点**：三类决策分别对应资产负债表的“左上（长期资产）—右下（长期资本）—左上右上短期项”。资本预算解决“买什么”，资本结构解决“钱从哪来”，营运资本管理解决“短期资金如何周转”。

### Ch1-2　独资与合伙的劣势 [LO3]

**题目**：独资（sole proprietorship）和合伙（partnership）这两种企业组织形式的四个主要劣势是什么？相对于公司制，它们有哪些好处？

**四大主要劣势**
1. **无限责任（unlimited liability）**：业主对企业债务承担个人无限连带责任，个人财产可被追偿。
2. **存续期有限（limited life）**：企业寿命依附于业主，业主去世/退出即终止。
3. **所有权转让困难（difficult ownership transfer）**：份额难以自由买卖。
4. **筹资能力受限（difficulty raising capital / equity）**：难以向众多投资者募集大额股本，制约规模扩张。

**相对公司制的好处**
- 设立简单、成本低、受监管少（无须公司章程/特许）；
- 利润仅在个人层面纳税一次，**避免双重征税**；
- 业主保留对企业的完全控制权；
- 信息披露与合规要求少。

### Ch1-3　公司制的主要劣势与优势 [LO3]

**题目**：公司制（corporation）的主要劣势是什么？至少说出两条公司制的优势。

**主要劣势**：**双重征税（double taxation）**——公司利润先在公司层面缴企业所得税，分配的股利再在股东层面缴个人所得税，同一笔收益被征两次。

**优势（任举两条及以上）**
1. **有限责任（limited liability）**：股东损失以出资额为限。
2. **所有权易于转让**：股份可在市场上自由买卖。
3. **存续期无限（unlimited life）**：公司独立于股东而持续存在。
4. **筹资能力强**：可向大量投资者发行股票/债券，便于募集巨额资本。

### Ch1-7　代理问题 [LO4]

**题目**：谁拥有公司？所有者通过什么过程控制公司管理层？代理关系存在的主要原因是什么？由此会产生哪些问题？

**解答**
- **谁拥有公司**：**股东（stockholders/shareholders）**。
- **控制管理层的过程**：股东在股东大会上**投票选举董事会（board of directors）**；董事会代表股东**聘任、监督并可解雇高管**，制定重大方针。即“股东 → 董事会 → 管理层”的委托链。
- **代理关系存在的主因**：**所有权与控制权分离（separation of ownership and control）**。股东（委托人 principal）通常不亲自经营，而由职业经理人（代理人 agent）日常管理，于是产生代理关系。
- **可能产生的问题（代理问题/代理成本）**：管理层可能追求自身利益而非股东财富最大化——如过度在职消费、盲目扩张（empire building）、为保住职位而过度规避风险或追求短期业绩、抵制对股东有利的并购等。由此产生**代理成本**：直接成本（监督与激励支出）＋间接成本（次优决策造成的价值损失）。

### Ch2-1　编制资产负债表 [LO1]

**题目**：Penguin Pucks 公司：流动资产 $4,800，净固定资产 $27,500，流动负债 $4,200，长期负债 $10,500。求股东权益与净营运资本。

**解答**（依据会计恒等式：资产 = 负债 + 所有者权益）

```
总资产   = 流动资产 + 净固定资产 = 4,800 + 27,500 = 32,300
总负债   = 流动负债 + 长期负债   = 4,200 + 10,500 = 14,700
股东权益 = 总资产 − 总负债       = 32,300 − 14,700 = 17,600
净营运资本(NWC) = 流动资产 − 流动负债 = 4,800 − 4,200 = 600
```

**答案**：股东权益 = **$17,600**；净营运资本 = **$600**。

### Ch2-2　编制利润表 [LO1]

**题目**：Billy's Exterminators 公司：销售额 $734,000，成本 $315,000，折旧 $48,000，利息 $35,000，税率 35%。求净利润。

**解答**（自上而下逐行）

```
EBIT(息税前利润) = 销售 − 成本 − 折旧 = 734,000 − 315,000 − 48,000 = 371,000
EBT(应税利润)    = EBIT − 利息          = 371,000 − 35,000        = 336,000
所得税           = EBT × 35%            = 336,000 × 0.35          = 117,600
净利润           = EBT − 所得税         = 336,000 − 117,600       = 218,400
```

**答案**：净利润 = **$218,400**。
**注意**：利息是在税前扣除的（利息税盾），所以折旧、利息都要在计税之前减去。

### Ch9-2　互斥投资：IRR 与交叉率

**题目**：两个互斥投资如下，求各自 IRR 与交叉率（crossover rate）；在什么情况下 IRR 与 NPV 准则对两项目的排序会不同？

| 年份 | 投资 A | 投资 B |
|---|---|---|
| 0 | −75 | −75 |
| 1 | 20 | 60 |
| 2 | 40 | 50 |
| 3 | 70 | 15 |

**第一步：求各自 IRR**（令 NPV = 0，试错/财务计算器求解）

- **投资 A**：−75 + 20/(1+r) + 40/(1+r)^2 + 70/(1+r)^3 = 0 → **IRR_A ≈ 26.79%**
  （验证 r = 26.8% 时 NPV ≈ −0.01，约为 0）
- **投资 B**：−75 + 60/(1+r) + 50/(1+r)^2 + 15/(1+r)^3 = 0 → **IRR_B ≈ 38.54%**
  （验证 r = 38.5% 时 NPV ≈ +0.03，约为 0）

**第二步：求交叉率**——令两项目 NPV 相等，即对“差额现金流 (A − B)”令 NPV = 0。

```
差额现金流(A−B)：年0: 0,  年1: −40,  年2: −10,  年3: +55
方程：−40/(1+r) − 10/(1+r)^2 + 55/(1+r)^3 = 0
令 x = 1/(1+r)，约去 x 后：55x^2 − 10x − 40 = 0
解得 x = [10 + √(100 + 8800)] / 110 = 104.34/110 = 0.94855
1+r = 1/0.94855 = 1.0542  →  r ≈ 5.42%
```

**交叉率 ≈ 5.42%**。（验证：r = 5.42% 时 NPV_A ≈ NPV_B ≈ 39.71，二者相等。）

**第三步：排序冲突的条件**

- 由于 **IRR_B (38.54%) > IRR_A (26.79%)**，IRR 准则**永远偏好 B**。
- NPV 准则：在 r = 0 时 NPV_A = 55 > NPV_B = 50（A 更高）；在交叉率 5.42% 处相等；高于交叉率后 B 更高。
- **结论**：当**要求回报率 < 交叉率（约 5.42%）** 时，NPV 选 A、IRR 选 B，两准则**排序冲突**；当折现率高于 5.42% 时二者一致（均选 B）。

**直觉**：A 的现金流“后置且递增”（20→40→70），对低折现率更敏感，低利率时价值更高；B 的现金流“前置”（60→50→15），回收快、IRR 高。规模相同、现金流时间分布不同 → 才会产生 NPV-IRR 冲突。**互斥项目应以 NPV 为准。**

### Ch16-1　EBIT 与 EPS：盈亏平衡 EBIT

**题目**：BDJ 公司拟进行资本重组，把现有 $80M 债务增至 $125M，利率 9%（不变）。公司现有 1,000 万股，股价 $45。若重组预期能提高 ROE，管理层预期的 EBIT 至少应为多少？（不考虑税）

**解答**

新增债务 $125M − $80M = **$45M**，用于按 $45/股回购股票：
回购股数 = 45,000,000 / 45 = **100 万股** → 重组后股数 = 1,000 − 100 = **900 万股**。

| | 重组前 | 重组后 |
|---|---|---|
| 债务 | $80M | $125M |
| 利息 = 9%×债务 | $7.2M | $11.25M |
| 股数 | 1,000 万 | 900 万 |

无税时 EPS =（EBIT − 利息）/ 股数。令两种结构 EPS 相等求**盈亏平衡 EBIT**：

```
(EBIT − 7.2)/10 = (EBIT − 11.25)/9
9(EBIT − 7.2) = 10(EBIT − 11.25)
9·EBIT − 64.8 = 10·EBIT − 112.5
EBIT = 112.5 − 64.8 = 47.7   （单位：百万美元）
```

**答案**：盈亏平衡 **EBIT = $47.7M**。验证：EPS = (47.7−7.2)/10 = (47.7−11.25)/9 = **4.05**，相等 ✓。

**含义**：只有当 **EBIT > $47.7M** 时，增加财务杠杆才会提高 EPS / ROE。所以管理层必须预期 EBIT **至少为 $47.7M**。

### 股利-2　股票股利（Stock Dividends） [LO3]

**题目**：Alexander International 股东权益如下。(a) 股价 $30、宣告 10% 股票股利，新发多少股？各科目如何变化？(b) 若宣告 25% 股票股利，各科目如何变化？

```
普通股(每股面值 $0.50)   $ 20,000   → 流通股数 = 20,000 / 0.50 = 40,000 股
资本公积(Capital surplus)   285,000
留存收益(Retained earnings) 638,120
股东权益合计              $933,120
```

> **数据提示**：三项相加 = 20,000 + 285,000 + 638,120 = **943,120**，与题中所示合计 933,120 相差 $10,000，疑为教材笔误（留存收益或应为 628,120）。下面按所给各分项计算，**重点在于各科目“如何变动”的方法**，结论不受影响。

**(a) 10% 股票股利**（小额股票股利，按市价入账）

```
新发股数 = 10% × 40,000 = 4,000 股
新股市值 = 4,000 × $30 = $120,000  ← 从留存收益转出
  其中转入普通股(按面值)= 4,000 × $0.50 = $2,000
       转入资本公积      = 4,000 × ($30 − $0.50) = 4,000 × $29.50 = $118,000
```

| 科目 | 变动后 |
|---|---|
| 普通股 | 20,000 + 2,000 = **22,000** |
| 资本公积 | 285,000 + 118,000 = **403,000** |
| 留存收益 | 638,120 − 120,000 = **518,120** |
| **股东权益合计** | **933,120（不变）** |

**答案**：新发 **4,000 股**；权益在内部“搬家”——留存收益减 $120,000，普通股+资本公积增 $120,000，**总权益不变**。

**(b) 25% 股票股利**（按市价入账，与 (a) 同口径）

```
新发股数 = 25% × 40,000 = 10,000 股
新股市值 = 10,000 × $30 = $300,000  ← 从留存收益转出
  其中转入普通股 = 10,000 × $0.50 = $5,000
       转入资本公积 = 10,000 × $29.50 = $295,000
```

| 科目 | 变动后 |
|---|---|
| 普通股 | 20,000 + 5,000 = **25,000** |
| 资本公积 | 285,000 + 295,000 = **580,000** |
| 留存收益 | 638,120 − 300,000 = **338,120** |
| **股东权益合计** | **933,120（不变）** |

**补充说明**：会计准则上，**20%～25% 以上**的股票股利常被视为“大额股票股利”，按**面值**而非市价入账（此时仅转出 10,000 × $0.50 = $5,000 留存收益）。Ross 教材习题通常统一按市价处理，故上表按市价；若你的课程区分大/小额股利，25% 这一档可按面值口径，需向老师确认。无论哪种口径，**股票股利都不改变股东权益总额、不改变公司价值，只是会计科目重分类**。

### 家庭财务-2　净值与人力资本（概念题）

**题目**：你的净值是多少？资产和负债各包含什么？你会把“一生潜在挣钱能力”列为资产还是负债？它与你列出的其他资产相比价值如何？

**作答要点**
- **净值 = 总资产 − 总负债（Net worth = Assets − Liabilities）**。
- **资产**：现金/活期存款、投资（股票、基金）、汽车、房产、个人财物等。
- **负债**：助学贷款、信用卡欠款、车贷、房贷等。
- **人力资本（human capital）= 未来预期收入的现值**，本质上是一项**资产**（不是负债）。但传统个人资产负债表通常**不列示**，因为它**不可流通、不确定性高**。
- **量级对比**：对年轻人而言，人力资本往往**远大于**其全部金融资产——它是大多数人一生中最大的“资产”，尽管它不出现在常规净值表上。这正是“为什么要为人力资本买保险、做规划”的逻辑起点。

### 购车决策-6（概念/分析题）

**题目**：你在考虑买车，请就以下方面分析。

- **a. 满足出行需求的其他方式（替代方案及利弊）**：
  - 公共交通（地铁/公交）——便宜、无养护，但受线路/时刻约束；
  - 网约车/出租——灵活、无固定成本，但单次贵、高频使用累计高；
  - 租赁/分时租车（lease / car-sharing）——前期投入低、可换新，但长期不拥有资产；
  - 骑行/步行——零成本、健康，但受距离与天气限制；
  - 拼车/搭顺风车——分摊成本，但灵活性差。
- **b. 购车的融资方式**：全款（现金）、汽车贷款（银行/信用社/经销商）、融资租赁（lease）、用房屋净值贷款等。
- **c. 至少向 3 家提供方询价**：分别向银行、信用社、经销商金融获取 APR（年化利率）、首付、期限、提前还款条款等条件并对比。
- **d. 决策标准**：**总持有成本（total cost of ownership）**＝车价＋利息＋保险＋养护＋折旧；月供可承受性；首付与期限；到期是否拥有产权（买 vs 租）；折旧速度；以及“需要 vs 想要”。核心是把**全部现金流折现比较**，而非只看月供高低。

### Quick Check 2-14 / 2-15 / 2-16　收益率与名义/实际利率

> 这三题原书已给出答案，下面**复核计算并讲解公式**。

**QC 2-14｜期望收益率与已实现收益率**
股票成本 $50，年内派现 $1，预期年末价 $60。
```
期望收益率 = (现金股利 + 期末价 − 期初价) / 期初价
           = (1 + 60 − 50) / 50 = 11/50 = 22%
若年末实际为 $40：
已实现收益率 = (1 + 40 − 50) / 50 = −9/50 = −18%
```
**要点**：总收益 = 股利收益 + 资本利得；“期望”用预期价，“已实现”用实际价。

**QC 2-15｜实际利率（精确 Fisher 公式）**
名义利率 6%，预期通胀 3%。
```
实际利率 = (名义利率 − 通胀率) / (1 + 通胀率)
         = (0.06 − 0.03) / 1.03 = 0.02913 = 2.913%
```
**要点**：精确式≈近似式（6%−3%=3%）但略低。**国库券名义无风险，但实际收益有风险**：定价时未来真实通胀未知，故实际回报不确定。

**QC 2-16｜由实际利率与通胀求名义利率**
TIPS 实际利率 3.5%，预期通胀 4%。
```
(1 + 名义) = (1 + 实际) × (1 + 通胀) = 1.035 × 1.04 = 1.0764
名义利率 = 7.64%
```
**要点**：Fisher 关系的乘法形式，三者“一拎二”可互推。

### 房地产-5　风险由谁承担（概念题）

**题目**：你投资一个房地产开发项目，总投资 $100,000：自有资金 $20,000，向银行借 $80,000。谁承担这笔投资的风险，为什么？

**作答**
- **股权投资者（你）承担首要/首损风险（first-loss / residual risk）**：作为**剩余索取权人（residual claimant）**，你先吸收损失，直到 $20,000 自有资金被亏光。
- **银行只在损失超过 $20,000（即项目价值跌破 $80,000）后才开始承担风险**——此时其本金可能无法全额收回（尤其在无追索权贷款下）。
- **杠杆效应**：你用 5 倍杠杆（100k/20k），项目价值的小幅波动会被**放大**为你股本回报的大幅波动。因此你既享受放大的收益，也承担放大的风险。这说明了**债权人优先、股权人承担剩余风险**的风险分配机制，以及**财务杠杆放大风险与收益**的本质。

### 现值-3　五种现金流的现值（利率 10%/年）

**题目**：在 10% 年利率下，下列现金流的现值各是多少？

```
a. 5 年后收到 $100：
   PV = 100 / (1.10)^5 = 100 / 1.61051 = $62.09

b. 60 年后收到 $100：
   PV = 100 / (1.10)^60 = 100 / 304.48 = $0.33

c. 普通年金：第 1 年起至第 10 年，每年 $100（共 10 期，期末付）：
   PV = 100 × [1 − (1.10)^(−10)] / 0.10
      = 100 × (1 − 0.385543) / 0.10 = 100 × 6.14457 = $614.46

d. 预付年金：从现在起每年 $100，共 10 年（第 1 笔在今天）：
   PV = 普通年金现值 × (1.10) = 614.46 × 1.10 = $675.90

e. 永续年金：第 1 年起每年 $100，永远持续：
   PV = 100 / 0.10 = $1,000
```

**讲解**
- **(a)(b)** 单笔现值：贴现因子 1/(1+r)^t；可见 60 年后的 $100 现值仅 $0.33——**远期现金流被复利“折”得几乎不值钱**。
- **(c)** 普通年金（ordinary annuity）现值系数 = [1 − (1+r)^(−n)] / r。
- **(d)** 预付年金（annuity due）= 普通年金 ×(1+r)，因为每笔都提前一期，多滚一年利息。
- **(e)** 永续年金（perpetuity）= C/r。提示里说“不用财务计算器、用常识”，即一笔永续等于本金除以利率。

### 储蓄-12　银行 A vs 银行 B

**题目**：祖母给你 $500，4 年后毕业要用。银行 A 一年期利率 7%，银行 B 一年期利率 6%，均按年复利。
(a) 一年后两家各自的终值是多少？哪个更优？
(b) 多数人会怎么选？银行 B 可能作何反应？

**解答**
```
(a) 一年后终值(FV1)：
    银行 A：500 × (1 + 0.07) = $535
    银行 B：500 × (1 + 0.06) = $530
    → 银行 A 更优（多 $5）。
    （若放满 4 年：A = 500×1.07^4 = $655.40，B = 500×1.06^4 = $631.24，A 仍更优。）
```
**(b)** 多数理性储户会选**利率更高的银行 A**。银行 B 若维持 6% 将**流失存款**，因而很可能**上调利率向 7% 靠拢**以争夺存款。这体现了**金融市场的竞争**与**“一价定律 (Law of One Price)”** ——同质金融产品（同期限、同风险存款）的价格（利率）会被竞争拉平。

### 债券-3　零息债券与息票债券

**题目**：观察到无违约风险的零息债券价格如下：

| 期限 | 每 $1 面值价格 | 到期收益率(YTM) |
|---|---|---|
| 1 年 | 0.97 | 3.093% |
| 2 年 | 0.90 | ？ |

(a) 2 年期、6% 年付息票债券的价格应为多少？
(b) 补全表中缺失项（2 年期零息债券的 YTM）。
(c) (a) 中息票债券的 YTM 是多少？
(d) 为什么 (b) 与 (c) 的答案不同？

> 贴现因子（即零息价格）：d₁ = 0.97（1 年），d₂ = 0.90（2 年）。验证 1 年 YTM：1/0.97 − 1 = 3.093% ✓。下面息票债券以面值 $1,000 计。

**(a) 息票债券定价**（用贴现因子逐期折现）
```
现金流：年1 = $60（票息）；年2 = $60 + $1,000 = $1,060
价格 = 60 × d₁ + 1,060 × d₂ = 60 × 0.97 + 1,060 × 0.90
     = 58.20 + 954.00 = $1,012.20   （即每 $1 面值约 1.0122）
```

**(b) 2 年期零息债券 YTM**
```
0.90 = 1 / (1 + y)^2  →  (1 + y)^2 = 1/0.90 = 1.11111
1 + y = √1.11111 = 1.05409  →  y = 5.409%
```
**缺失项 ≈ 5.41%**。

**(c) 息票债券 YTM**（令折现到价 $1,012.20 求单一 y）
```
60/(1+y) + 1,060/(1+y)^2 = 1,012.20
试错求解 → y ≈ 5.34%
（验证 y = 5.34% 时左边 ≈ 1,012.21 ≈ 1,012.20 ✓）
```
**息票债券 YTM ≈ 5.34%**。

**(d) 为什么 (b) ≠ (c)**
- 2 年期**零息**债券只有年 2 一笔现金流，其 YTM 就是 2 年期**即期利率（spot rate）5.409%**。
- 2 年期**息票**债券在**年 1 与年 2 都有**现金流：年 1 的票息按较低的 1 年即期利率（3.093%）折现，年 2 部分按 5.409% 折现。其 YTM 是 1 年和 2 年即期利率按**现金流时间与大小加权**后的“复杂平均”，被年 1 的低利率**拉低**到 5.34%（< 5.409%）。
- **核心结论**：**当收益率曲线不是水平时，YTM 取决于现金流分布（票息率）**——同样 2 年期、票息不同的债券，YTM 不同。**YTM ≠ 即期利率，除非期限结构是平的。**

### DDM-6　股利贴现模型（Gordon 增长模型）

**题目**：DDM 公司刚派现 D₀ = $2/股，历史股利年增 5% 且预期持续，市场资本化率（要求回报率）k = 13%/年。
(a) 用 DDM 估计每股内在价值。
(b) 若实际股价 $20，要“合理化”这一价格，需要把 (i) 股利增长率、(ii) 市场资本化率 分别调整多少？

**(a) 内在价值**（Gordon 模型：V₀ = D₁/(k − g)，D₁ = D₀(1+g)）
```
D₁ = 2 × (1 + 0.05) = $2.10
V₀ = D₁ / (k − g) = 2.10 / (0.13 − 0.05) = 2.10 / 0.08 = $26.25
```
**内在价值 = $26.25/股**。

**(b) 为使价格 = $20，单独调整一个参数**

(i) 调整增长率 g：
```
20 = 2(1 + g) / (0.13 − g)
20(0.13 − g) = 2(1 + g)
2.6 − 20g = 2 + 2g
0.6 = 22g  →  g = 2.727%
```
→ 增长率需从 **5% 降到约 2.73%**。

(ii) 调整市场资本化率 k：
```
20 = 2(1.05) / (k − 0.05) = 2.10 / (k − 0.05)
20(k − 0.05) = 2.10  →  20k − 1 = 2.10  →  k = 15.5%
```
→ 资本化率需从 **13% 升到 15.5%**。

**讲解**：估值 $26.25 高于市价 $20，说明市场对该股的预期比模型更悲观——**要么预期增长更低（g↓），要么要求回报更高（k↑）**，二者都会压低估值，符合直觉。这也展示了 Gordon 模型对 (k − g) 的**高度敏感性**：分母很小，参数微调即引起估值大幅变化。

## 第三部分　风险管理与金融机构（Hull）

> **统一思路（泰勒展开近似）**：组合价值变动
> ΔΠ ≈ Delta×ΔS + ½×Gamma×(ΔS)² + Vega×Δσ + Theta×Δt + …
> 各希腊字母衡量组合对某一风险因子的敏感度。

### 8.1　Delta（一阶价格敏感度）

**题目**：组合对某指数的 Delta = −2,100，指数现为 1,000，升至 1,005。估计组合价值变动。
```
ΔΠ ≈ Delta × Δ指数 = (−2,100) × (1,005 − 1,000) = (−2,100) × 5 = −10,500
```
**答案**：组合价值约**下降 $10,500**。（Delta 为负 → 与指数反向变动，指数上涨则组合亏损。）

### 8.2　Vega（对波动率的敏感度）

**题目**：组合对美元-英镑汇率的 Vega = 200（$/每 1% 波动率），汇率波动率从 12% 升到 14%。估计影响。
```
ΔΠ ≈ Vega × Δσ(以百分点计) = 200 × (14 − 12) = 200 × 2 = +400
```
**答案**：组合价值约**上升 $400**。（Vega 为正 → 波动率上升对组合有利，如净多头期权头寸。）

### 8.3　Gamma（二阶价格敏感度，Delta 中性组合）

**题目**：一个 Delta 中性组合的 Gamma = 30（per $ per $）。标的价格 (a) 突涨 $2、(b) 突跌 $2，估计组合价值变动。
```
组合 Delta 中性 → 一阶项为 0，价值变动由二阶(Gamma)项主导：
ΔΠ ≈ ½ × Gamma × (ΔS)^2 = 0.5 × 30 × (2)^2 = 0.5 × 30 × 4 = +60
(a) 涨 $2：ΔΠ ≈ +$60
(b) 跌 $2：ΔΠ ≈ +$60   （因 (ΔS)^2 与方向无关）
```
**答案**：两种情形组合价值都约**上升 $60**。**正 Gamma → 标的大幅波动（无论涨跌）都对组合有利**；这正是“做多 Gamma/做多波动率”的特征。

### 9.1　银行利率风险：净利息收入

**题目**：某银行有 $5B 一年期贷款、$20B 五年期贷款，由 $15B 一年期存款、$10B 五年期存款融资。若利率在未来三年每年上升 1%，对银行净利息收入有何影响？

**结构分析**
```
总资产 = 5 + 20 = $25B；总负债 = 15 + 10 = $25B（资产负债规模相等）
一年内可重定价(rate-sensitive)：资产 $5B，负债 $15B
→ 一年期重定价缺口 = 5 − 15 = −$10B（负缺口，负债敏感）
五年期贷款/存款利率锁定 5 年，三年内不重定价。
```

**逐年影响**（设利率每年末上调 1%，一年期工具到期后按新利率续作；以利率不变为基准）

| 年份 | 一年期贷款利率变化 | 一年期存款利率变化 | 净利息收入变化 ΔNII |
|---|---|---|---|
| 第 1 年 | 0 | 0 | 约 0 |
| 第 2 年 | +1% × $5B = +$50M | +1% × $15B = +$150M | 50 − 150 = **−$100M** |
| 第 3 年 | +2% × $5B = +$100M | +2% × $15B = +$300M | 100 − 300 = **−$200M** |

**结论**：银行**净利息收入逐年下降**（约 0 → −$100M → −$200M，三年累计约 −$300M）。原因：银行**短期负债（$15B）多于短期资产（$5B）**，呈**负重定价缺口（负债敏感）**——利率上升时，付息端比收息端更快、更多地“被抬价”，利差收窄。这是“**以短期存款为长期固定利率贷款融资**”的典型期限错配/利率风险。
> 说明：具体数额取决于“每年末重定价”的假设；若假设第 1 年即重定价，时间表整体提前一年，但**方向（NII 随升息而下降）不变**。

### 9.2　收益率曲线：长端为何通常高于短端

**题目**：为什么长期利率多数时候高于短期利率？什么情况下长期利率会低于短期利率？

**长端通常更高的原因**
1. **流动性偏好 / 期限溢价（liquidity preference / term premium）**：长期债券锁定资金更久、利率风险（价格波动）更大，投资者要求额外补偿。
2. **预期理论**：若市场预期未来短期利率上升，则长期利率（未来短期利率的平均）高于当前短期利率。
3. **不确定性溢价**：对长期通胀与利率的不确定性要求更高回报。

**长端低于短端（收益率曲线倒挂）的情形**：当市场**预期未来短期利率将下降**时——典型如**预期经济衰退**，或当前短期利率因**紧缩货币政策（抗通胀）而异常高企**、预计随后回落。**收益率曲线倒挂常被视为衰退的领先信号。**

### 10.1　波动率的时间标度（√t 法则）

**题目**：某资产波动率为 2%/天，3 天内百分比价格变化的标准差是多少？
```
波动率按 √时间 标度：SD(3天) = 2% × √3 = 2% × 1.732 = 3.46%
```
**答案**：约 **3.46%**。

### 10.2　由年化波动率求日波动率与置信区间

**题目**：某资产波动率 25%/年。一个交易日的百分比价格变化标准差是多少？假设正态、均值为零，估计一日价格变化的 95% 置信区间。
```
取每年 252 个交易日（Hull 惯例）：
日标准差 = 25% / √252 = 25% / 15.875 = 1.57%/天

95% 置信区间（正态，均值 0）：±1.96 × 日标准差
= ±1.96 × 1.57% = ±3.09%
```
**答案**：日标准差 ≈ **1.57%**；一日价格变化的 95% 置信区间约为 **−3.09% ～ +3.09%**。
> 若课程用 250 个交易日，日波动率 ≈ 25%/√250 = 1.58%，区间 ≈ ±3.10%，差别极小。

### 12.3　VaR 的解读

**题目**：某基金一个月 95% VaR 为组合规模的 6%。你在该基金投资 $100,000，如何解读经理的这一声明？

**解读**：95% VaR = 6% 表示——**在未来一个月内，损失超过组合 6% 的概率只有 5%**。对 $100,000 而言，6% = **$6,000**。即：**有 95% 的把握，一个月内损失不超过 $6,000**；或等价地，**有 5% 的概率损失会超过 $6,000**。
> 注意：VaR **只给出“至少损失多少”的临界值**，并不告诉你超过该临界值后（最坏 5% 里）平均会亏多少——那是 ES 的工作。

### 12.4　期望损失（ES）的解读

**题目**：某基金一个月 95% 期望损失（expected shortfall）为组合的 6%。投资 $100,000，如何解读？

**解读**：95% ES = 6% 表示——**在最坏的 5% 情形里（即损失已超过 95% VaR 的条件下），平均损失为组合的 6%**。对 $100,000 而言为 **$6,000**。即：**一旦进入“坏尾部”（最差 5%），平均会亏 $6,000**。ES 度量的是**尾部的平均严重程度**，比 VaR 更能刻画极端损失。

### 12.5　VaR 与 ES 的次可加性（subadditivity）

**题目**：两项投资各自有 0.9% 概率亏 $10M、99.1% 概率亏 $1M，彼此独立。在 99% 置信水平下求：(a) 单项 VaR；(b) 单项 ES；(c) 组合 VaR；(d) 组合 ES；(e) 说明本例中 VaR 不满足次可加性而 ES 满足。

**(a) 单项 99% VaR**
```
损失分布：P(亏$1M)=99.1%，P(亏$10M)=0.9%
99% 分位：求最小 L 使 P(损失 ≤ L) ≥ 99%
P(损失 ≤ $1M) = 99.1% ≥ 99%  →  VaR = $1M
（$10M 落在最差 0.9% 尾部，尚在 1% 容忍范围内）
```
**单项 99% VaR = $1M**。

**(b) 单项 99% ES**（最差 1% 的平均损失）
```
最差 1% = 0.9% 的 $10M + 0.1% 的 $1M
ES = (0.9%×10 + 0.1%×1) / 1% = (0.09 + 0.001)/0.01 = 0.091/0.01 = $9.1M
```
**单项 99% ES = $9.1M**。

**(c) 组合 99% VaR**（两项独立，列出组合损失分布）
```
两者都亏 $1M：概率 0.991×0.991 = 0.982081，损失 $2M
一亏$10M一亏$1M：概率 2×0.009×0.991 = 0.017838，损失 $11M
两者都亏 $10M：概率 0.009×0.009 = 0.000081，损失 $20M

累计：P(损失 ≤ $2M) = 98.2081% < 99%
      P(损失 ≤ $11M) = 98.2081% + 1.7838% = 99.9919% ≥ 99%
→ 99% VaR = $11M
```
**组合 99% VaR = $11M**。

**(d) 组合 99% ES**（最差 1% 的平均损失）
```
最差 1% = 全部 $20M(0.0081%) + 部分 $11M(补足到 1%，即 0.9919%)
ES = (0.000081×20 + 0.009919×11) / 0.01
   = (0.00162 + 0.109109) / 0.01 = 0.110729/0.01 ≈ $11.07M
```
**组合 99% ES ≈ $11.07M**。

**(e) 次可加性检验**

次可加性要求：风险(组合) ≤ 风险(A) + 风险(B)（“分散化不应增加风险”）。

| 度量 | 单项 A + 单项 B | 组合 | 是否满足次可加性 |
|---|---|---|---|
| **VaR** | 1 + 1 = **$2M** | **$11M** | **否**（11 > 2，违反！）|
| **ES** | 9.1 + 9.1 = **$18.2M** | **$11.07M** | **是**（11.07 < 18.2 ✓）|

**结论**：本例中 **VaR(A+B) = $11M > VaR(A)+VaR(B) = $2M**，VaR **违反次可加性**——分散投资反而使 VaR 增大，说明 **VaR 不是一致性（coherent）风险度量**。而 **ES(A+B) = $11.07M < ES(A)+ES(B) = $18.2M**，ES **满足次可加性**，符合“分散化降低风险”的直觉。这正是监管与学界**偏好用 ES 取代 VaR** 的关键理由之一。
