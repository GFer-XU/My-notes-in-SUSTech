## 2.1 Molecular interactions

## 2.2.1 The compression factor: Z

The ratio of its molar volume, $V _ { m } ,$ to the molar volume of a perfect gas, $V _ { m } { } ^ { o } ;$ , at the same pressure and temperature

$$
Z = \frac { V _ { m } } { { V _ { m } } ^ { o } }
$$

$$
p V _ { m } { } ^ { o } = R T \quad \longrightarrow \quad \quad Z = { \frac { p V _ { \mathrm { m } } } { R T } } = { \frac { p V } { n R T } }
$$

The perfect gases

$$
Z = \frac { p V _ { \mathrm { m } } } { R T } = 1
$$

Real gases

$$
\begin{array} { r } { Z \succ 1 \qquad p V _ { \mathrm { { m } } } \succ R T } \\ { Z \diamond 1 \qquad p V _ { \mathrm { { m } } } \diamond R T } \end{array}
$$

![](images/5f1c0ae356b88aa358c371348432c6d43282952f4c1bdcc487faefcb18df87cc.jpg)

## 2.2.1 The compression factor: Z

At very low pressures, $Z { \approx } 1$

At high pressures, $Z { > } 1$ , a larger molar volume than a perfect gas, repulsive forces dominant

At intermediate pressures, $Z { < } 1$ , the attractive forces reducing the molar volume relative to that of a perfect gas.
