# 模块二 · 深度讲义｜风险与收益（Risk & Return）
### —— 市场只为你"无法逃避"的风险付钱

> **本章的灵魂（先总）**
> 模块一给了你一把丈量**时间**的尺子；模块二要给你一把丈量**恐惧**的尺子。本章的灵魂，是一个认知翻转：**未来不是一条确定的线，而是一把展开的扇子**——风险，就是这把扇子张开的**宽度**。而整个金融学最深刻、最反直觉的洞见，就藏在这一章里：**市场只会为你"无法逃避"的风险付钱，而绝不会为你"本可避开却懒得避开"的风险付一分钱。** 你能用一个组合免费消除的风险（某家公司的工厂失火），市场分文不付；你和所有人共担、无处可逃的风险（经济衰退、一场瘟疫、一个变暖的星球），市场才用"**风险溢价**"补偿你。学懂这一章，你将获得一把能切开任何风险的手术刀：把"**可以免费删除的风险**"和"**必须被付钱才肯承担的风险**"分开。而你会发现，**气候变化，正是后者最纯粹、最极致的形态**——因为你无法靠"买入第二个地球"来对冲一个正在变暖的地球。

---

## 一、第一性原理：风险到底是什么？——"一把展开的扇子"

**先用常识，别用术语。** 我们日常说"有风险"，指的是"可能出坏事"。但金融学要的是更精确的东西。

请你想象抛硬币赌钱：**预期**你不输不赢，但**实际**结果要么 +1 要么 −1。**关键不在那个"平均值 0"，而在结果会"散开"。** 这个"散开"，就是风险的本质。

> **第一性原理：风险 = 未来结果的"离散程度"（dispersion）。** 未来不是一个确定的点，而是一把**扇子**——风险，就是扇子张开多宽。

由此，**任何一项投资，都只有两个根本属性**：

- **期望收益**：这把扇子的**中心**在哪里（平均会赚多少）；
- **风险**：这把扇子**张开多宽**（结果可能偏离平均多远）。

**跨学科锚定**：这恰恰就是气候科学呈现未来的方式。IPCC 的气候预测从来不是"2100 年升温 X 度"这样一条线，而是一**扇**情景路径（不同排放路径 SSP/RCP 下的升温区间）。**"未来是一把扇子"不是金融的比喻，它就是气候科学的语言。** 而且——记住这一点——气候这把扇子，**右侧那条"灾难尾巴"格外长**（后面第九节会回到这个"肥尾"）。

| 一项投资的两个轴 | 通俗说法 | 数学对象 |
|---|---|---|
| 期望收益（Expected Return） | "扇子的中心" | 概率加权平均 |
| 风险（Risk） | "扇子张多宽" | 方差 / 标准差 |

---

## 二、扇子的中心：期望收益

**去术语化**：**期望收益**就是——"如果你能把未来重播一千遍，平均下来每次赚多少。"它是把每种可能结果，按它发生的概率加权平均。

```
期望收益：E(R) = Σ pᵢ × Rᵢ      （pᵢ 是第 i 种情景的概率，Rᵢ 是对应收益）
```

**一个致命的陷阱**：期望值是"平均会发生的"，**不是"实际会发生的"**——你永远拿不到那个"平均数"。抛硬币的期望是 0，但你每一把要么 +1 要么 −1，从来不是 0。

> **跨学科锚定**：气候灾害的"期望损失"也是按各情景概率加权的平均值。但**平均数会掩盖尾巴**：如果有 5% 的概率发生一场抹平 GDP 10% 的灾难，它对"平均损失"贡献不大，却足以让一个国家万劫不复。**只看期望、不看扇子的宽度（尤其右尾），是风险管理的头号死法。**

---

## 三、丈量恐惧：方差与标准差

**去术语化**：扇子张多宽，怎么量？**方差/标准差**回答的就是——"结果**通常**会离平均值多远？"标准差越大，扇子越宽，越没把握。

```
方差：    σ² = Σ pᵢ × (Rᵢ − E(R))²
标准差：  σ  = √σ²        （回到与收益相同的单位，更直观）
```

- 标准差 = 5%：结果大多挤在平均值附近，**很稳**；
- 标准差 = 30%：结果天南海北，**很野**。

> **跨学科锚定**："气候敏感度"（CO₂ 浓度翻倍会带来多少升温）本身就是一个**标准差极大**的量——科学界给的是一个宽区间（约 2.5–4°C，且不能排除更高）。**对一个量的不确定性越大，它的"风险标准差"越大**，越需要为最坏情形预留缓冲。

## 四、天下没有免费的风险：风险溢价

**去术语化**：没有人会白白承担风险。你要让我把钱从"绝对安全"挪到"可能亏"的地方，**就得多给我一点预期回报当补偿**。这个"多出来的预期回报"，就是**风险溢价**——它是"**恐惧的价格**"。

```
风险溢价 = 风险资产的期望收益 − 无风险利率
         Risk Premium = E(R_risky) − R_free
```

| | 无风险资产（Risk-free） | 风险资产（Risky） |
|---|---|---|
| 例子 | 短期国债 | 股票、风电项目股权、绿色 PE |
| 扇子宽度 | ≈ 0（几乎确定） | 宽 |
| 期望收益 | 低（基准） | 高（= 无风险 + 风险溢价） |
| 投资者为何持有 | 求安全 | **为那份溢价而承担风险** |

> **这就是模块一欠下的"那条腿"**：模块一说"折现率 = 无风险利率（时间）+ **风险溢价**（不确定性）"。**风险溢价，正是本章在为它定价。** 风险越大 → 要求的溢价越高 → 折现率越高 → 现值越低。两个模块在此咬合。
> **ESG 场景（且是争议焦点）**：理论上，**转型风险**更高的化石能源资产，应当向投资者提供**更高**的预期回报来补偿（否则没人愿持有）；反之，被认为更"安全"的绿色资产可能接受**更低**的回报——市场上确有"绿色溢价（greenium）"的现象（绿色债券收益率略低于同等普通债券）。但**它是否被正确定价、绿色资产长期是否真的更优**，至今仍是激烈争论的实证问题，不要当成定论。

## 五、唯一的免费午餐：分散化（Diversification）

这是本章的**第一座高峰**。

**去术语化**："别把鸡蛋放一个篮子"人人会说。但**为什么它在数学上真的有效**？因为当一个资产"往下掉"时，另一个常常"往上走"，**两边的颠簸部分抵消**，组合整体就更平稳了。

而决定"能抵消多少"的，是一个核心概念——**相关性**：

**去术语化**：**相关性**问的是——"这两样东西，是**手拉手一起动**，还是**一个涨另一个跌**？"

| 相关系数 ρ | 通俗说法 | 分散化效果 |
|---|---|---|
| ρ = +1（完全正相关） | "手拉手，同涨同跌" | **毫无效果**（风险不降） |
| ρ = 0（不相关） | "各走各的" | **显著降险** |
| ρ = −1（完全负相关） | "一个涨、另一个必跌" | **理论上可把风险降到零** |

**两资产组合的风险公式**（看懂这一行，就懂了整个 Markowitz 组合理论）：

```
组合方差：σ²_p = w₁²σ₁² + w₂²σ₂² + 2·w₁·w₂·ρ₁₂·σ₁·σ₂
                                    └──── 关键就在这一项：ρ<1 时，它把组合风险往下拉 ────┘
```

**用数字感受"免费午餐"**：两个**各自标准差都是 20%**、预期收益相同的资产，按 50/50 组合后：

| 两者相关性 | 组合标准差 | 解读 |
|---|---|---|
| ρ = +1 | **20%** | 没占到任何便宜 |
| ρ = 0 | **≈ 14.1%** | 收益不变，风险白白降了近三成 |
| ρ = −1 | **0%** | 风险被完全抵消 |

> **这就是"免费午餐"的含义**：在**不牺牲一分钱预期收益**的前提下，仅靠把不相关的资产组合起来，风险就下降了。这是金融世界里极其罕见的"白拿"。

**跨学科锚定（杀手级应用）：电网，就是一个投资组合。**
- 单押**太阳能**：标准差极大——夜里全黑、阴天全趴、出力高度同步（高正相关）。
- 但 **太阳能 + 风电 + 水电 + 储能 + 地理分散**：阳光弱时往往有风、白天的光伏配上夜间的风电（**两者常呈负相关**）、东边阴天西边晴……**这些"零和反向的颠簸互相抵消**"，整个电网的供电就变得平稳可靠。
- **这不是比喻——这就是 Markowitz 组合理论原封不动地搬到了电网上。** "光伏中午出力、风电夜间出力"之间的**负相关**，正是电网的那顿免费午餐。一个只懂"多建光伏"的规划者，远不如一个懂"组合相关性"的规划者。

## 六、那把手术刀：系统性风险 vs 特异性风险

这是本章的**思想内核**，也是它与气候议题最深的交点。

**去术语化**：风险其实有两种——
- **"你一个人的倒霉"**：某家公司的 CEO 出丑闻、某座工厂失火、某个油田枯竭。这叫**特异性风险（idiosyncratic / 可分散风险）**。
- **"所有人一起倒霉"**：经济衰退、战争、瘟疫、利率飙升、一个变暖的星球。这叫**系统性风险（systematic / 不可分散风险）**。

| | 特异性风险（Idiosyncratic） | 系统性风险（Systematic） |
|---|---|---|
| 通俗说法 | "你一个人的倒霉" | "所有人一起倒霉" |
| 能否分散掉 | **能**（组合一大就互相抵消） | **不能**（无处可逃） |
| 例子 | 单家公司丑闻、单座电厂事故 | 衰退、瘟疫、加息、**气候变化** |
| 市场付不付溢价 | **不付**（你本可免费避开） | **付**（你别无选择） |

**这里推出全章最重要的一条逻辑链**：

- 特异性风险可以被组合**免费消除** →
- 那么，**承担一个本可免费避开的风险，市场凭什么给你补偿？** →
- 所以**市场只为"无法分散的系统性风险"支付风险溢价** →
- 一项资产值不值得拥有、该要多高回报，**只取决于它带来多少"系统性风险"，与它的"特异性风险"无关。**

> 这条逻辑，就是下一模块 **CAPM** 的灵魂；它告诉你：定价资产时，该盯的是"它和整个市场一起波动多少"（即 β），而不是"它自己抖得多厉害"。

**跨学科锚定（本章的最高潮）：气候变化是系统性风险的"终极形态"。**
- 你无法分散掉一个变暖的星球——**没有"第二个地球"可以对冲**。
- **物理风险**（洪水、热浪、海平面上升）和**转型风险**（碳政策、技术替代、**搁浅资产**）会冲击**整个经济**，而非个别公司。
- 这把气候从一个纯粹的"道德议题"，重新定义为一个**被定价的、不可分散的金融风险**。
- **"搁浅资产（stranded assets）"** 是个绝妙的演化：单座煤电厂被淘汰，本是**特异性**风险；可一旦低碳转型成为全局趋势，**整个化石能源板块同时贬值**——无数个"特异性风险"**聚合成了系统性风险**。看懂这一点，你就理解了为什么越来越多机构投资者把"碳暴露"当作一个需要定价的风险因子。

| 气候系统性风险的两副面孔 | 含义 | 谁会受冲击 |
|---|---|---|
| 物理风险（Physical） | 极端天气、海平面、农业减产 | 沿海地产、农业、保险、供应链 |
| 转型风险（Transition） | 碳定价、技术替代、政策突变 | 化石能源、重工业、高碳资产（→搁浅） |

## 七、当免费午餐消失：相关性奔向 1

分散化有个**致命前提**：风险必须**彼此独立**。可现实中，**最危险的时刻，恰恰是"一切一起崩塌"的时刻**——所有资产的相关性瞬间飙到 +1，那顿免费午餐**正好在你最需要它的时候消失**。

- 2008、2020 年的暴跌里，"分散得很好"的组合一样血流成河——因为**系统性冲击让万物同跌**。

**跨学科锚定（极其传神）：气候正在摧毁保险的根基。**

先用费曼讲清**保险为什么能成立**：

- 一千栋房子投火险，**通常只有零星几栋会着火，彼此独立**。靠**大数定律**，整个"风险池"变得高度可预测，保险公司收的保费足以覆盖少数赔付。**保险的本质，就是把大量"相互独立"的特异性风险汇集起来，让群体变得可预测。**

而气候做了什么？

- 一场**飓风 / 山火**，会**同时**点燃或淹没**整个区域**的所有房子。原本"相互独立"的风险，被气候**变成了高度相关**——"风险池"里的房子开始**手拉手一起出事**。
- **相关性一旦逼近 1，分散化（以及建立在它之上的保险）就彻底失效。** 这正是为什么保险公司纷纷退出加州、佛罗里达——**不是它们算不过来，而是这种"相关化的灾难"在数学上无法被分散、无法被定价。**

> **一句话记住第五到第七节**：**分散化在相关性活着时死去（Diversification dies when correlation lives）。** 而气候变化，正是一台把"独立风险"批量转成"相关风险"的机器。

| | 分散化有效时 | 分散化失效时 |
|---|---|---|
| 风险之间的关系 | 独立 / 低相关 | 高度相关（ρ→1） |
| 典型场景 | 平常年份、独立的火灾/事故 | 系统性危机、区域性气候灾难 |
| 后果 | 风险被抹平、保险可行 | "一起崩"、保险崩溃、无处可逃 |

## 八、有效前沿与 β：通往"定价"的桥

**去术语化**：把所有可能的资产组合画在"风险—收益"图上，**最靠左上角的那条边界线**，叫**有效前沿（efficient frontier）**——它是一份"**最优菜单**"：站在这条线上，**你不可能在不增加风险的情况下再多赚一点**。理性投资者只会在这条线上挑组合。

而要衡量"一项资产给你带来多少**那种无法分散的系统性风险**"，金融用一个数字——**β（贝塔）**：

**去术语化**：**β 衡量的是——"当整个市场抖动时，这项资产会被**放大**还是**减弱**地跟着抖？"**

| β 值 | 含义 | 例子 |
|---|---|---|
| β = 1 | 与市场同步 | 大盘指数 |
| β > 1 | **放大**市场波动 | 高杠杆、强周期行业（含许多高碳重工业） |
| β < 1 | **减弱**市场波动 | 公用事业、必需消费 |
| β = 0 | 与市场无关 | 近似无风险资产 |

> β 度量的，正是第六节那个**唯一被定价的东西——系统性风险**。**它是连接本模块与模块三（资产定价 / CAPM）的桥**：CAPM 会告诉你，一项资产该有的预期回报 = 无风险利率 + β × 市场风险溢价。**只有 β 被付钱，特异性风险分文不值。**
> **前沿议题**：已有研究尝试定义"**气候 β**"——衡量一项资产对气候转型这一系统性因子的暴露程度，并据此定价。这是把本章框架推向气候金融最前沿的尝试。

## 九、认知科学的暗线：人类是糟糕的风险估计器

把镜头转回**你自己的大脑**。金融假设人是冷静的"方差计算器"，但真实的人脑，在风险面前漏洞百出——而这些漏洞，恰好让我们**系统性地误判气候这类风险**。

- **损失厌恶（Loss Aversion，前景理论）**：亏 100 元的痛，约等于赚 200 元的爽——**损失的权重约是收益的两倍**。后果：我们死扛亏损的股票（不愿"认赔"）、过早卖掉赚钱的（锁定快乐），把"扇子"在心里画歪。
- **概率忽视 / 可得性偏差**：我们对**生动、罕见**的风险（坠机、鲨鱼）过度恐惧，对**平淡、常见**的风险（车祸、以及**缓慢的气候变化**）严重低估。**越是"温水煮青蛙"式的风险，越被人脑无视。**
- **过度自信 + 熟悉偏好 / 本土偏好**：人倾向于重仓自己熟悉的、本地的、自家公司的股票——**主动放弃分散化这顿免费午餐**。
- **模糊厌恶（Ambiguity Aversion，Ellsberg 悖论）**：比起"已知的赔率"，人更害怕"未知的赔率"。气候的**深度不确定性**正好踩中这个雷区——可它既可能让人麻痹回避，也可能引发过度恐慌。

| | 理性风险模型（金融假设） | 真实人脑（行为现实） |
|---|---|---|
| 看待盈亏 | 对称（只看方差） | **损失痛感≈收益快感×2** |
| 估计概率 | 客观加权 | 高估生动罕见、**低估平淡常见** |
| 是否分散 | 充分分散 | 本土/熟悉偏好 → **分散不足** |
| 面对未知 | 用概率处理 | **模糊厌恶**：怕未知甚于怕已知 |

**全章的缝合（也呼应模块一）**：

- 人脑天生**高估"生动且即时"的风险、低估"缓慢且系统性"的风险**——而气候恰恰是后者：缓慢、统计意义上的、遥远、模糊、还拖着一条肥尾。**让我们存不下钱的"当下偏误"（模块一），和让我们看不见系统性慢风险的"概率忽视"（模块二），是同一副有缺陷的认知硬件的两种表现。**
- 金融的"方差—协方差"框架，是纠正这些偏差的**理性义肢**。
- **但这把尺子自己也有尽头**——**当扇子的右尾"肥"到一定程度（灾难概率不可忽略、且损失可能极大），"期望值/方差"框架会失灵**：经济学家魏茨曼（Weitzman）的"**悲观定理（dismal theorem）**"指出，在肥尾下，预期损失甚至可能在数学上**发散到无穷**，使标准的成本—收益分析无从下手。这与模块一"折现率是伦理选择"异曲同工：**在极端的、不可逆的风险面前，纯技术模型会把话筒交还给人类的价值判断。**

## 十、本章地图回望（先分后总）

**一句话总纲**：

> **风险，是未来这把扇子张开的宽度；而市场只为你"无法用分散化逃避的那部分宽度（系统性风险）"支付溢价。学会区分"可免费删除的风险"与"必须被付钱才肯承担的风险"，你就掌握了资产定价的钥匙——而气候变化，是后者最极致的样本。**

**公式速览（背下这张表，本章计算全覆盖）**：

| 概念 | 公式 | 一句话 |
|---|---|---|
| 期望收益 | `E(R) = Σ pᵢRᵢ` | 扇子的中心 |
| 方差 / 标准差 | `σ² = Σ pᵢ(Rᵢ−E(R))²` ; `σ=√σ²` | 扇子的宽度 |
| 风险溢价 | `E(R_risky) − R_free` | 恐惧的价格 |
| 组合收益 | `E(Rp)=w₁E(R₁)+w₂E(R₂)` | 加权平均 |
| 组合风险 | `σ²p=w₁²σ₁²+w₂²σ₂²+2w₁w₂ρσ₁σ₂` | ρ<1 时风险下降（免费午餐） |
| β（系统性风险） | `βᵢ = Cov(Rᵢ,Rm)/Var(Rm)` | 唯一被定价的风险 |

**它向何处生长**：β 与"只有系统性风险被定价"这条铁律，将在**模块三（资产定价 / CAPM）** 长成"证券市场线"与预期回报公式；而本章为模块一的折现率，正式补上了"**风险**"那条腿。**至此，时间（模块一）与不确定性（模块二）两条腿俱全——下一步，就是用它们站起来，给万物定价。**
