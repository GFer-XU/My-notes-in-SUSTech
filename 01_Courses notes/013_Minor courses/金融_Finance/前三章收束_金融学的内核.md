# 前三章收束 · 金融学的"内核"
### —— 从两个原语，到一台估值机器：一张图、一个方程、三条暗线

> **一句话先把三章"焊"成一体**
> 如果把前三章压成一句话：**金融学，是人类用"时间"与"不确定性"两块原料，锻造出的一台"为未来定价"的机器；而我们的大脑，天生就是这台机器里一个有缺陷的零件。** 模块一、二、三不是三个并列的知识点，而是**同一台机器的三道工序**——模块一造了"时间"那条腿，模块二造了"风险"那条腿，模块三把两条腿装上、让机器**站起来给万物定价**。
> 这份收束**不再教新东西**，而是带你**退后一步，看清整台机器的结构**。当"一张图 + 一个方程 + 三条暗线"在你脑中合成**一个"超级组块（super-chunk）"** 时，你才算真正把前三章**内化**了——这正是认知科学里专家与新手的分水岭：**新手记住三章，专家记住一台机器。**

## 一、第一性原理总回路：从两个原语到一台引擎

把整套系统**从零再推一遍**，你会发现它惊人地简洁：

- **两个原语**：① **时间**（价值可跨时搬运，但今天≠明天）；② **不确定性**（未来是一把扇子，不是一条线）。
- **一个主方程**（统治整章的脊柱）：

```
              Σ  E[ 未来现金流ₜ ]
   价值  =  ───────────────────────
            t      (1 + r)ᵗ

   折现率 r = 无风险利率(时间)  +  风险溢价(不确定性, 由 β 定)
```

- **三道工序如何造出这台引擎**：

```
 ① 时间价值 ──► 造出分母的"时间腿"：(1+r)^t、年金、永续
 ② 风险与收益 ──► 造出分母的"风险腿"：β、风险溢价；以及分子的"期望"
 ③ 资产定价 ──► CAPM 把两腿合成完整的 r → DCF 组装整台方程 → 给万物定价
              └─ 无套利(一价定律) 保证一致；有效市场假说 追问"价格对不对"
```

> **关键认知**：你学过的**所有公式**（复利、年金、方差、β、DDM、CAPM……），本质都只是在**改动这一个方程的某一块**。记住方程，其余都是它的变奏。

## 三、三条贯穿始终的"暗线"（收束的真正价值所在）

整合的意义，不在重复三章，而在看清**那些横穿三章、把它们缝成一体的线**。一共三条：

### 暗线 A｜主方程是唯一的脊柱：所有概念都在改动它的某一块

| 模块 | 代表概念 | 它在主方程里改动了什么 |
|---|---|---|
| ① | 复利 / 折现 / 年金 / 永续 | 分母 `(1+r)^t` 的**时间**维度，与现金流的**时点** |
| ① | Fisher（名义/实际） | 折现率 r 的**口径**（含不含通胀，须与现金流一致） |
| ② | 风险溢价 | 折现率 r 里的**风险**加项 |
| ② | β（系统性风险） | 决定风险溢价的**大小**（唯一被定价的风险） |
| ② | 分散化 / 相关性 | 削掉分子里**不被定价的特异性风险** |
| ③ | CAPM | **算出完整的 r**（把①②两条腿合一） |
| ③ | DCF / DDM / 债券定价 | **组装整个方程**给不同资产定价 |
| ③ | 无套利 / EMH | **检验**方程算出的价格能否成立、是否被市场认账 |

> 一句话：**模块一、二在"造折现率 r"，模块三在"用 r 定价并检验价格"。**

### 暗线 B｜气候/ESG：同一个问题，被三章层层深化

整个气候金融，是**同一道题在三个模块里的三次升级**——这也是为什么我让它贯穿始终：

| 模块 | 气候之问 | 核心机制 | 标志性案例 |
|---|---|---|---|
| ① 时间 | **我们有多在乎未来？** | 折现率为远期灾害定价；率越低、越在乎后代 | Stern(1.4%) vs Nordhaus(5%)；LCOE |
| ② 风险 | **气候风险能分散掉吗？** | **不能**——终极系统性风险，无第二个地球 | 电网即组合；保险因相关性崩溃 |
| ③ 定价 | **市场为"碳泡沫"定对价了吗？** | 取决于市场是否有效（EMH） | 碳溢价、搁浅资产、气候 alpha |

> 三问连起来就是一句话：**我们用一个折现率（①）为一个无法分散的系统性风险（②）定价，而这个价对不对，取决于市场是否有效、以及人类是否看穿自己（③）。**

### 暗线 C｜人脑的认知缺陷：在三章里"层层叠加"成一套理论

这是最精妙的一条线。**让我们犯错的，是同一副有缺陷的认知硬件，它在三章里以三种面貌出现，叠加成一个完整的失灵机制**：

| 模块 | 认知偏差 | 直接后果 | 投射到气候上 |
|---|---|---|---|
| ① | **当下偏误 / 双曲贴现** | 对未来贴现"过头" | 个人不储蓄、社会不减排 |
| ② | **概率忽视 + 损失厌恶** | 无视"缓慢的系统性风险" | 低估温水煮青蛙式的气候威胁 |
| ③ | **叙事偏差 + 套利极限** | 错价能**长期存活** | "化石=财富"故事黏住、碳泡沫难被套利消除 |
| **合计** | **三者叠加** | — | **一套"市场为何可能系统性错误定价气候"的完整理论** |

> **诚实的边界（"地图不是领土"贯穿三章）**：①折现率本质是伦理选择，非纯技术；②极端肥尾下"期望/方差"框架会失灵（魏茨曼悲观定理）；③连 CAPM 的 β 都不能完全解释真实回报（多因子修正即证据）。**三章的模型都是强大的参照系，但没有一个是终极真理——一个成熟的金融人，用模型立纪律，也警惕它的裂缝。**

## 四、全部公式 · 一页速查（三章合并）

| 模块 | 概念 | 公式 |
|---|---|---|
| ① | 终值 / 现值 | `FV=PV(1+r)^n` ; `PV=FV/(1+r)^n` |
| ① | 普通年金现值 | `C·[1−(1+r)^(−n)]/r` |
| ① | 预付年金现值 | `普通年金 ×(1+r)` |
| ① | 永续 / 增长永续 | `C/r` ; `C₁/(r−g)` |
| ① | Fisher 关系 | `(1+名义)=(1+实际)(1+通胀)` |
| ② | 期望收益 | `E(R)=Σ pᵢRᵢ` |
| ② | 方差 / 标准差 | `σ²=Σ pᵢ(Rᵢ−E(R))²` ; `σ=√σ²` |
| ② | 风险溢价 | `E(R_risky)−R_f` |
| ② | 组合收益 / 风险 | `w₁E(R₁)+w₂E(R₂)` ; `w₁²σ₁²+w₂²σ₂²+2w₁w₂ρσ₁σ₂` |
| ② | β | `Cov(Rᵢ,R_m)/Var(R_m)` |
| ③ | DCF | `V=Σ E(CFₜ)/(1+r)^t` |
| ③ | 债券定价 | `P=Σ Cₜ·dₜ + F·d_T` |
| ③ | 股票 DDM | `V=D₁/(k−g)` |
| ③ | CAPM | `E(R)=R_f+β[E(R_m)−R_f]` |

## 五、最易混淆的"对照清单"（考前扫雷）

| 易混对 | 一句话辨析 |
|---|---|
| 单利 vs 复利 | 单利"钱在加"（线性）；复利"钱在乘"（指数）——长期天壤之别 |
| 现值 vs 终值 | 现值往回拉（÷）、终值往前滚（×）；**估值靠现值** |
| 名义 vs 实际利率 | 名义是"标价"；实际是"扣掉通胀后的真实购买力增长"。**口径必须与现金流一致** |
| 系统性 vs 特异性风险 | 前者"所有人一起倒霉"（不可分散、**被定价**）；后者"你一个人倒霉"（可分散、**不被定价**） |
| 套利 vs 投机 | 套利"同物两价、稳赚"（无需预测）；投机"赌方向"（有风险） |
| YTM vs 即期利率 | 零息债 YTM=即期利率；**息票债 YTM 是各期即期利率的加权平均**，曲线非平时两者不同 |
| 有效市场 vs 行为金融 | 前者"价格总对、错价转瞬即逝"；后者"错价可长期存活（套利有极限）" |
| 期望值 vs 实际结果 | 期望是"重播千遍的平均"，**你永远拿不到那个平均数**；尾巴才致命 |

## 六、整合自测（测"连接"，而非"单点"）

> 这些题**故意跨模块**——能流畅串起来，才算把三章焊成了一台机器。先口头作答，再回看对应章节。

1. **【一条折现率的诞生】** 用一条逻辑链说明：模块一的"无风险利率"、模块二的"β 与风险溢价"、模块三的"CAPM"，是如何最终**汇成 DCF 里那个唯一的折现率 r** 的？
2. **【r 上升的三副面孔】** "折现率 r 上升"这**一件事**，会同时如何影响：(a) 模块一里一笔远期现金流的现值、(b) 模块二里一项资产被要求的回报、(c) 模块三里一只股票的 DDM 估值？为什么说它们是**同一件事的三个侧面**？
3. **【气候错价的因果链】** 把"市场系统性低估气候风险"这一命题，用三个模块的认知偏差（**当下偏误 → 概率忽视 → 套利极限**）串成一条**完整因果链**；再指出：这条链在**哪一环**最容易被"市场有效"的反方论证攻破？
4. **【两条腿缺一不可】** 为什么仅靠模块一（时间）**无法**给一座煤矿正确定价？仅靠模块二（风险）又**为什么不够**？必须等到模块三的哪个动作，定价才真正完成？
5. **【同一案例的三次升级】** 仅用"气候"这一个案例，依次说出它在模块一、二、三里分别变成了**哪一个具体问题**，并各配一个标志性场景。

## 七、你现在拥有了什么？——以及通往模块四的桥

读完前三章，你已经**握住了金融学的内核**：

- 你能把**任何资产**剥成"一束未来现金流"；
- 你能用**时间 + 风险**两条腿，合成一个折现率 r；
- 你能用 DCF / DDM / CAPM **给它定价**，并用无套利与 EMH **检验这个价**；
- 你还能看穿：价格不只是数字，更是**集体的故事**，而人脑的偏差会让它**系统性地偏离**——尤其在气候这种慢性、系统性、叙事浓厚的领域。

> **一句话内核**：**前三章教你"看懂价格"。**

**桥**：**模块四（公司财务）** 要做的，是把这台估值引擎**掉转枪口、对内使用**——一家真实企业该投哪些项目（只投 **NPV>0**，而 NPV 正是用本章的 r 算出来的）、该用债还是用股融资、该如何把现金还给股东，以及当"出钱的人"与"花钱的人"不是同一群人时如何对齐激励（代理问题）。

> **下一程的内核预告**：**从"看懂价格"，走向"创造价值"。**
