# 模块四 · 深度讲义｜公司财务（Corporate Finance）
### —— 把估值引擎掉转对内：企业，究竟为谁而存在？

> **本章的灵魂（先总）**
> 模块一、二、三教你"看懂价格"；模块四，把这台估值引擎**掉转枪口、对内使用**。本章的灵魂在于：**企业，本质上是一台"把资本变成更多资本"的价值转换机器；而它的全部工作，可以收敛成一条近乎残酷的简单法则——只投资那些"值回来的钱多过花出去的钱"的项目（NPV>0）。** 但这台干净的机器，运转在一个肮脏的现实之上：**开机器的人（管理层），不是拥有机器的人（股东）；而对机器主人有利的事，未必对这颗星球、对整个社会有利。** 于是公司财务，其实是叠在同一块地基上的三个问题——**投什么（资本预算）、怎么筹钱（资本结构）、利润怎么办（股利政策）**，全部由 **NPV>0** 统辖——外加一个第四的、属于人性的问题：**当代理人与委托人不是同一群人，你如何让前者真心替后者卖命？** 而一道最深的现代裂缝，正贯穿这台机器的立身之本：**企业，究竟只为它的股东而存在，还是为它的决策所触及的每一个人——包括一个正在变暖的世界？ESG 不是公司财务的脚注，它是对这门学科founding 前提的正面挑战。**

---

## 一、第一性原理：企业是一台"价值转换机器"

**先用常识，别用术语。** 忘掉"公司、企业、法人"这些名字。剥到只剩骨头，**一家公司就是一台机器：投入资本（钱），努力把它变成更多的钱**（靠生产人们愿意付钱买的东西）。

- 这台机器的**价值** = 它的资产未来能产出的全部现金流的现值——**正是模块三的 DCF，套用在整家公司上**。
- 这台机器的**唯一使命**：**创造价值**——让产出大于投入。

| 朴素问题 | 公司财务的术语 |
|---|---|
| 该买哪些"会下蛋的鸡"？ | **资本预算**（投资决策） |
| 买鸡的钱从哪来？ | **资本结构**（融资决策） |
| 鸡下的蛋怎么分？ | **股利政策**（分配决策） |
| 养鸡的人会不会偷蛋？ | **代理问题**（公司治理） |

> **跨学科锚定**：一家可再生能源开发商，是一台把资本变成"未来 25 年售电现金流"的机器；一家煤炭公司，是一台把资本变成煤炭收入的机器——**但它的产出，可能在转型中变得一文不值**（模块二的"搁浅资产"在此重现）。

## 二、脊柱：只投资 NPV > 0 的项目

**去术语化**：**净现值（NPV）** = "**这个项目值多少钱（它未来现金流的现值）—— 减去 —— 它要花多少钱**"。正数 = 创造价值（值得做）；负数 = 摧毁价值（别碰）。就这么简单。

```
NPV = −初始投资 C₀ + Σ E(CFₜ) / (1+r)ᵗ
                    └──── 这正是模块三的 DCF ────┘
```

- **去术语化"折现率 r"**：它就是**资本成本**，也叫**"门槛收益率（hurdle rate）"**——项目必须**跨过的最低回报**。为什么是门槛？因为这是投资者把同等风险的钱投到别处能赚到的回报（**机会成本**）。
- **关键的链条**：这个 r **来自模块三的 CAPM**！即 **CAPM → 资本成本 → NPV**。模块三造的折现率，在这里被用来给企业的项目"打分"。

**IRR 与它的陷阱**（接上你作业里的 IRR / 交叉率题）：

**去术语化"内含报酬率（IRR）"**：项目"自带"的回报率——经验法则是 IRR > 门槛就做。但它有坑：

| | NPV（净现值） | IRR（内含报酬率） |
|---|---|---|
| 衡量 | 创造了**多少**价值（金额） | 项目**自带的回报率**（百分比） |
| 互斥项目 | **可靠**，直接选 NPV 最大 | 可能与 NPV **打架**（你作业里的"交叉率"现象） |
| 非常规现金流 | 稳健 | 可能出现**多个 IRR 或无解** |
| 结论 | **黄金准则** | 直觉好用，但**互斥决策须以 NPV 为准** |

> **跨学科锚定（本章最深的种子）**：一座风电场的 NPV，对折现率**极度敏感**（资本前置、现金流后置——呼应模块一）。但更要命的是一道裂缝：**私人 NPV（企业看到的）≠ 社会 NPV（计入碳排放外部性的）。** 一座煤电厂可能私人 NPV 为正、社会 NPV 为负。这道"私人—社会"的楔子，是整章气候叙事的核心，第三、八节会反复回到它。

## 三、门槛本身从哪来：资本成本与 WACC

**去术语化**：那个"门槛收益率"到底怎么定？它是**公司这笔钱的综合成本**。公司从两处筹钱——**债主（债务）** 和 **股东（股权）**，两边都索要回报。**WACC（加权平均资本成本）** 就是这两种成本按比例的加权平均。

```
WACC = (E/V)·r_E + (D/V)·r_D·(1 − 税率)
        └股权占比·股权成本┘  └债务占比·债务成本·税盾┘
```

- **r_E（股权成本）来自模块三的 CAPM**；**r_D（债务成本）来自模块三的债券市场**。
- **门槛洞察**：一个项目必须**赚得比 WACC 多**，才创造价值。

> **跨学科锚定（资本市场如何驱动能源转型）**：**化石公司的 WACC，是否高于绿色公司？** 如果投资者与债主把转型风险定价进去（更高的 β、更高的违约风险），化石公司的资金成本就上升——**门槛抬高 → 更少的化石项目能跨过 → 资本被重新配置到绿色**。这就是**资本市场（不）驱动转型的精确金融机制**。

**用数字感受**（设两家公司都 60% 股权 / 40% 债务，税率 25%）：

| | 绿色公司（低风险） | 化石公司（高转型风险） |
|---|---|---|
| 股权成本 r_E（由 β 决定） | 8% | 12% |
| 债务成本 r_D | 4% | 7% |
| **WACC** | 0.6×8% + 0.4×4%×0.75 = **6.0%** | 0.6×12% + 0.4×7%×0.75 = **9.3%** |

> 化石公司的"门槛"（9.3%）远高于绿色公司（6.0%），于是它**更少的项目能过关**。这就是 β（模块二）经由 CAPM（模块三）、化作资本成本、最终重塑实体投资的全链条。**注意中立**：化石公司是否**真的**普遍面临更高 WACC，与"碳溢价"一样是**争论中的实证问题**；上表展示的是**机制**（"若市场如此定价，则……"）。此外，一些公司主动在资本预算里加一个**"影子碳价（shadow carbon price）"**，把外部性内部化——这是企业层面对那道"私人—社会楔子"的自我修正。

## 四、怎么切这块饼：资本结构与杠杆

**去术语化**：知道了**投什么**，接着是**怎么付钱**——是**借钱（债务）**，还是**卖一部分所有权（股权）**？这个"债 / 股"比例，就是**资本结构**。

| | 债务（Debt） | 股权（Equity） |
|---|---|---|
| 出资人身份 | 债主（先受偿） | 股东（剩余索取） |
| 回报 | 固定利息（须还） | 不固定的分红/增值 |
| 对企业的约束 | 强（不还就破产） | 弱 |
| 税收 | **利息可抵税（税盾）** | 股利不可抵税 |
| 风险归属 | 风险低、靠前 | **承担剩余风险**（呼应模块二房地产案例） |

**去术语化"财务杠杆（leverage）"**：用借来的钱**放大回报**（也放大风险）——双刃剑（接上你作业的 EBIT/EPS、盈亏平衡 EBIT 题：只有当 EBIT 高于盈亏平衡点，加杠杆才抬高 EPS/ROE）。

> **跨学科锚定**：一家化石公司**以可能搁浅的储量为抵押大举借债**，杠杆会**放大搁浅风险** → 煤炭/石油企业的破产潮。反过来，可再生能源的**项目融资**（以 PPA 锁定的现金流做无追索权抵押）——正因现金流像债券一样稳定，才能**安全地承受高杠杆**。

## 五、切法到底重不重要？Modigliani–Miller 定理

这是资本结构的**思想拱顶石**。

**去术语化**：MM 给出一个惊人的论断——**在一个完美、无摩擦的世界里，你怎么切这块饼，并不改变饼的大小**。**企业的价值来自它的资产/项目（资产负债表左侧），而非你如何为它融资（右侧）。** 一张披萨切成 4 块还是 8 块，并不会让你多出披萨来。

- **MM 命题一（无税）**：企业价值与资本结构无关。
- **然后，放松假设**——现实世界有摩擦，使切法重新变得重要：

| | MM 完美世界 | 真实世界（有摩擦） |
|---|---|---|
| 资本结构是否影响价值 | **不影响** | **影响** |
| 税收 | 无 | **利息抵税 → 债务"税盾" → 适度举债增值** |
| 破产成本 | 无 | 债太多 → 代价高昂的财务困境 |
| 代理成本 | 无 | 债务能**约束管理层**（少了挥霍的闲钱），但也制造冲突 |
| 结论 | 切法无关 | **权衡理论：最优杠杆 = 税盾收益 vs 困境成本的平衡** |

> **回扣你的作业**：16.1 题特意说"**忽略税**"——那正是 **MM 无税世界**，所以杠杆的作用纯粹体现在 EPS 的**分配**（盈亏平衡 EBIT）上，而**不改变企业价值**。看懂这一点，你就懂了那道题的"潜台词"。
> **跨学科锚定**：税盾鼓励举债——但对化石公司，**以搁浅资产为抵押的债务会让"困境成本"陡增**，于是权衡的天平向"高转型风险公司应少用杠杆"倾斜。而**可持续挂钩贷款（达成 ESG 目标则利率下调）**，是融资菜单上的新花样。

## 六、当你没有好项目可投：股利政策

**去术语化**：公司赚了钱，然后呢？两条路：**再投资**（仅当存在 NPV>0 的项目）或**还给股东**（派现金股利 / 回购股票）。法则极简：**如果你跨不过门槛收益率，就把钱还回去，别糟蹋它。**

- **现金股利 vs 股票回购**（接上你作业的"股票股利"题）：注意股票股利**不改变企业价值**，只是会计科目重分类（你作业里的关键点）。
- **MM 股利无关论**：在完美世界，股利政策同样**不影响价值**（你想要现金，自己卖点股票就行，等价于"自制股利"）。
- **现实里为何仍重要**：信号（派息传递管理层的信心）、税收、以及**代理**（强制把现金吐出来，能约束管理层乱花）。

> **跨学科锚定（绝佳应用）：化石巨头该"采收"还是"扩张"？** 一家成熟的化石公司，需求在萎缩，又**没有有吸引力的低碳 NPV>0 项目**——它该**继续把利润砸进更多油气产能**（在转型中这些项目 NPV 多半为负或边际），还是**把现金还给股东**（即"**采收 / 融化 / 有序退出**"策略）？这是"**没有好项目 → 把钱还回去**"的教科书级应用。不少投资者主张：石油巨头应被当作"**现金回报机器**"经营，而非追求增长与勘探扩张。这是一场真实的辩论，**它的本质就是股利政策**。

## 七、机器里的人性裂缝：代理问题

这是本章的**行为内核**，也接上你作业里的"代理问题"第 7 题。

**去术语化**：公司**归股东所有，却由管理层经营**。这是两群利益不同的人。管理层是被雇来替"主人（委托人）"干活的"**代理人**"——但代理人有自己的小算盘（保住饭碗、在职消费、扩张帝国、拿到短期奖金）。这道**主人与代理人之间的缝隙**，就是**代理问题**。

- **代理成本** = 监督成本 + 因决策错位而损失的价值。
- **最深的原理："你奖励什么，就会得到什么。"** —— 这是**机制设计 / 激励对齐**。治理工具：董事会监督、绩效薪酬（股票/期权）、债务约束、并购威胁、激进投资者。

| | 委托人（股东） | 代理人（管理层） |
|---|---|---|
| 想要什么 | 长期股东价值最大化 | 饭碗、薪酬、声望、轻松、帝国 |
| 时间视野 | 较长 | **常被季度业绩、短期奖金绑架（偏短）** |
| 对风险的态度 | 充分分散，理性承担 | 可能过度避险（保职位）或过度冒险（赌翻身） |

> **跨学科锚定（本节大锚 + 直通模块一）：管理层的"短期主义"，就是气候问题。** 管理层被季度盈利和短周期奖金激励，会**系统性地少投资于长周期价值——包括气候转型与韧性**。**这正是模块一的"当下偏误"，在组织层面的翻版。** 此外：
> - **"漂绿（greenwashing）"** 本质是一种**代理/信号问题**——管理层为讨好投资者而**宣称 ESG 美德、却无实质**。
> - **生动的治理案例**：2021 年小型激进基金 **Engine No. 1** 在埃克森美孚的代理权之争中**赢得董事席位**，逼迫公司直面气候战略——这是激进投资者**用公司治理这把工具，把"代理人（管理层）"重新对齐到一个长期、气候感知的使命上**。一个完美的"代理 × 气候"故事。

## 八、立身之本被重新打开：股东 vs 利益相关者（ESG 的断层线）

这是本章的**思想高潮**，也是最深的 ESG 之问。

**去术语化**：**这家公司，到底是"为谁"存在的？** 传统答案（自弗里德曼 1970 年起）：企业的存在是为了**最大化股东价值**——"企业的本分就是经营赚钱"。挑战者（**利益相关者资本主义 / ESG**）：企业服务于一张网——股东，也包括**员工、客户、社区与环境**。

**两种立场，都请认真、公允地对待**（这是一个真实存在分歧的问题）：

| | 股东至上（Friedman） | 利益相关者资本主义（ESG） |
|---|---|---|
| 企业为谁 | 主要为股东 | 为所有利益相关者（含地球） |
| 核心理由 | **目标单一 → 问责清晰**；避免管理层借"利益相关者"之名行私利之实（这本身是代理问题！） | **市场不为外部性定价**，纯股东价值最大化会系统性伤害社会/星球 |
| 对长期的看法 | 弗里德曼的本意是"**在法律与伦理规则之内**"最大化**长期**价值——长期赚钱本就要善待员工与环境 | 长期价值与利益相关者福祉**本就交织** |
| 主要风险/批评 | 短视化、忽视未被定价的外部性 | "利益相关者"易成管理层模糊问责、自我开脱的挡箭牌 |

> **一个分析上更有用的收束（而非选边站）**：这场争论，往往可以**坍缩成两个变量——时间视野 与 外部性**。
> - **在足够长的视野下、且外部性被正确定价时**，"股东价值"与"利益相关者福祉"会**趋于一致**（你无法长期赚钱的同时摧毁你的员工和星球）。
> - **分歧，来自两件事**：**短视的时间视野**（第七节的代理 / 当下偏误）和**未被定价的外部性**（第二节那道"私人—社会 NPV 楔子"）。
> 换句话说——**这一节，正是第二节的"楔子"与第七节的"代理"在哲学层面的汇合。** 至于哪一方更对，这是一道**价值判断题**，不同立场的严肃学者各执一词；本讲义负责把两边的最强论证摆清，把判断交还给你。

## 九、认知科学的暗线：公司也有"大脑"，而它同样有偏差

把镜头转回**做决策的人脑**——公司的每个决定，都由携带全套认知 bug 的人类管理者做出，外加几个组织层面的新 bug。

- **管理层过度自信 / 傲慢假说（Roll）**：在并购中**出价过高**、盲目扩张帝国。
- **短期主义 / 当下偏误**：季度资本主义，**少投长期**（直通模块一）。
- **沉没成本谬误 / 承诺升级**：**为已花掉的钱继续砸钱**（明知项目要黄，却因"已经投了这么多"而死扛）——这恰恰**违背了"只有未来现金流才相关"的铁律**。
- **心理账户（股利）**：投资者**非理性地偏好现金股利**，胜过经济上等价的股票回购（Shefrin–Statman）。

| | 理性公司（NPV 机器） | 行为公司（有偏差的人） |
|---|---|---|
| 投资依据 | 严格 NPV>0 | 过度自信、帝国扩张、沉没成本 |
| 时间视野 | 由资本成本客观决定 | **被季度业绩压成短视** |
| 看待已投入的钱 | 沉没成本**与决策无关** | 死扛、加倉、承诺升级 |
| 分配 | 现金股利与回购等价 | 非理性偏好现金股利 |

**四大模块的总缝合（认知主线在此闭环）**：**同一种"时间近视"，在每一个层面复制出现**——

- **模块一**：个人对未来贴现过头 → **不储蓄**；
- **模块二**：市场低估缓慢的系统性风险 → **无视慢性气候威胁**；
- **模块三**：价格能长期错下去（叙事 + 套利极限）→ **碳泡沫难消**；
- **模块四**：管理层少投长期（短期主义 + 代理）→ **企业不为气候转型买单**。
- **合起来就是一句话**：**人类的"时间视野近视"，在个人、市场、企业每一层反复上演，系统性地低配长远未来——而气候，是这种近视最大的受害者。代理问题，归根结底是一个"时间视野与激励错位"的问题。**

> **诚实的边界（"地图不是领土"延续到第四章）**："**股东价值最大化**"本身是一个**规范性的价值选择，而非客观事实**（第八节）；而 NPV 依赖的现金流预测，深度不确定。**模型给你纪律，但终极目标的选择，仍属于人类的价值判断。**

## 十、本章地图回望，与四大模块的合龙（先分后总）

**一句话总纲**：

> **公司财务，是把模块三的估值引擎掉转对内：用 CAPM 算出的资本成本当门槛，只投 NPV>0 的项目（投资）；权衡税盾与困境成本来切债/股的饼（融资，MM）；没好项目就把现金还给股东（分配）；并用治理机制让代理人对齐委托人（代理）。而它最深的裂缝——企业为谁而存在——坍缩为"时间视野"与"外部性"两个变量，气候正落在二者的交点。**

**公式速览（背下这张表，本章计算全覆盖）**：

| 概念 | 公式 | 一句话 |
|---|---|---|
| 净现值 NPV | `−C₀ + Σ E(CFₜ)/(1+r)ᵗ` | 脊柱：>0 才做（= DCF − 成本） |
| 资本成本/门槛 | r（来自 CAPM） | 项目必须跨过的最低回报 |
| WACC | `(E/V)r_E + (D/V)r_D(1−T)` | 公司这笔钱的综合成本 |
| MM 命题一(无税) | `V_L = V_U` | 切法不改变饼的大小 |
| MM(含税) | `V_L = V_U + T·D` | 税盾让适度举债增值 |
| 私人 vs 社会 NPV | `社会NPV = 私人NPV − 外部成本现值` | 碳定价/碳价填平这道楔子 |

**四大模块合龙图**：

```
[① 时间] + [② 风险β] ──CAPM──► 折现率 r ──┬─► [③ 资产定价] 给万物定价（看懂价格）
                                            │
                                            └─► [④ 公司财务] 用 r 当门槛：
                                                 投(NPV>0) / 融(MM) / 配(股利) / 代理治理
                                                 → 把"看懂价格"变成"创造价值"
   暗线贯穿四章：时间近视(当下偏误)→ 个人不存钱、市场低估慢风险、价格长期错、企业不投长期
```

**它向何处生长**：模块四里，企业**决定**了要投资、要融资——**但它到底去哪儿弄到这笔钱？储蓄者又把闲钱放进了哪里？** 这就是**金融体系的管道**——**模块五（金融市场与中介）**：市场与银行如何把资本从"过剩处"输送到"需要处"，以及信息不对称如何阻碍这一流动。

> **下一程内核预告**：从"一家企业如何创造价值"，走向"**整个经济如何让资本流动起来**"。
