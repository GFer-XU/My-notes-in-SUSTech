# 模块一 · 深度讲义｜货币的时间价值（Time Value of Money）
### —— 我们到底有多在乎未来？这是一道算术题，更是一道伦理题

> **本章的灵魂（先总）**
> 如果整个金融学是一座大厦，本章就是浇筑地基用的那把**尺子**。货币时间价值要解决的，本质上只有一件事：**今天的一块钱，和未来的一块钱，根本不是同一种东西——我们需要一个"汇率"，把不同时点的价值换算到同一时刻，才能比较、相加、做决策。** 这个"时间汇率"就是**折现率**，它是"**时间的价格**"。它听起来很技术，却其实是人类最古老、也最深刻的问题之一：*我们究竟有多在乎未来？*——而这恰恰是今天气候政策争论的正中心。当一位经济学家说"用 7% 的折现率评估一个减排项目"时，他不只是在做算术；他是在用一个数字，悄悄地为"一百年后的子孙"标价。学懂这一章，你不仅会算复利——你会看懂：为什么面对**同样的气候科学数据**，有人主张不惜代价立刻行动、有人却主张从容渐进；他们的分歧常常不在科学，而藏在这一章的一个数字里。

---

## 一、第一性原理：为什么"今天的一块钱"贵过"明天的一块钱"？

**先用常识，别用术语。** 我问你一个问题：你愿意现在就拿到一块**已经装好、正在发电的太阳能板**，还是要一张"十年后给你装一块"的承诺书？

几乎所有人都选现在。为什么？把这个直觉拆开，背后藏着三股力量——这就是时间价值的全部根源：

- **① 机会成本（钱能生钱）**：今天到手的板子，这十年里一直在发电、在赚钱；那张承诺书十年里寸功未立。今天的资源可以**被投入使用、产生回报**，所以它天然更值钱。
- **② 时间偏好 / 不耐（人天生想早点享受）**：人就是更想"现在就要"，让我们等，就得给补偿。
- **③ 不确定性与通胀（未来会缩水）**：十年后承诺书可能违约，钱也可能被通胀稀释。**未来本身就打折**。

| 时间价值的三个根源 | 通俗说法 | 它给折现率贡献了什么 |
|---|---|---|
| 机会成本 | "钱不该闲着" | 真实回报率（实际利率） |
| 时间偏好/不耐 | "我现在就想要" | 纯时间偏好溢价 |
| 不确定性 + 通胀 | "未来会缩水、会违约" | 风险溢价 + 通胀补偿 |

> **这一节的种子，会长成整章**：把这三股力量加总，就得到一个数字——**折现率**。它衡量的，正是"未来要打多大的折，才换得回今天的等价物"。

## 二、折现率到底是什么？——"时间的汇率"

**去术语化（费曼）**：你出国旅行，要把人民币换成日元，靠的是**汇率**。**折现率，就是"时间汇率"**——它把"未来元"兑换成"现在元"。

- 1 美元（明天） × "时间汇率" = ？美元（今天）
- 跨国汇率衡量"地理上的距离"；折现率衡量"**时间上的距离**"。

一旦你接受"折现率＝时间汇率"这个比喻，本章所有公式都只是同一件事的两个方向：

- **往未来走**（今天的钱 → 未来值多少）＝ **复利 / 终值**；
- **往今天拉**（未来的钱 → 今天值多少）＝ **折现 / 现值**。

```
   过去 ───────────── 今天(t=0) ───────────── 未来(t=n)
                         │                      │
            复利(向前滚)  └──────── × (1+r)^n ───┘
            折现(往回拉)  ┌──────── ÷ (1+r)^n ───┐
                         │                      │
                       现值 PV  ←————————————  终值 FV
```

## 三、两个互逆的动作：复利（向前滚）与折现（往回拉）

### 复利：被低估的"指数引擎"

**去术语化**：**复利**就是"**利滚利**"——本金生出的利息，下一期又一起生息。像滚雪球：雪球越大，沾上的雪越多，越滚越快。

它和"**单利**"（只有本金生息）的差别，短期看不出来，长期是天壤之别：

| | 单利（Simple Interest） | 复利（Compound Interest） |
|---|---|---|
| 谁在生息 | 只有本金 | 本金 **+** 已累积的利息 |
| 增长形态 | 直线（线性） | 曲线（**指数**） |
| 短期差异 | 几乎一样 | 几乎一样 |
| 长期差异 | 小 | **爆炸性** |
| 一句话 | "钱在加" | "钱在乘" |

**跨学科锚定（关键洞察）**：复利的数学，和**大气中 CO₂ 浓度累积、人口增长、传染病扩散**是**同一个数学**——都是**指数增长**。一笔钱以 7% 复利增长，约 **10 年翻一倍**（"72 法则"：72 ÷ 利率 ≈ 翻倍年数）。这正是为什么气候科学家对"看似温和的年增长率"如此警惕：**2% 的年排放增速，35 年就让排放翻倍**。理解了复利，你就同时理解了"为什么爱因斯坦称之为世界第八大奇迹"，以及"为什么指数级的环境问题，人脑（习惯线性思考）总是反应太慢"。

> 例：一个寿命 30 年的光伏项目里投入的 1,000 元，按 7% 复利，30 年后 = 1,000 × 1.07³⁰ ≈ **7,612 元**（翻了约 7.6 倍）；若按 10%，则 ≈ 1.10³⁰ × 1,000 ≈ **17,449 元**。利率每动一点，长期结果天差地别——记住这个"杠杆感"，下一节它会变成一把伦理的刀。

### 折现：复利的"倒带"

**折现**就是把复利反过来放——已知未来的钱，问"它在今天值多少"。

| | 终值 FV（Future Value） | 现值 PV（Present Value） |
|---|---|---|
| 问的问题 | 今天的钱，未来会变多少？ | 未来的钱，今天身价几何？ |
| 方向 | 向前（× (1+r)ⁿ） | 向后（÷ (1+r)ⁿ） |
| 公式 | `FV = PV × (1+r)^n` | `PV = FV / (1+r)^n` |
| 用途 | 储蓄/投资增值 | **估值**（万物定价的起点） |

> **现值是整个金融学最重要的概念，没有之一。** 因为"任何资产 = 一束未来现金流"，而给它定价，就是把这束现金流逐一折现、再加总。本章其余内容，都是现值的变奏。

## 四、现值的"暴政"：为什么折现率能决定我们是否在乎未来？

这是本章的**思想核心**，也是它与气候议题最尖锐的交点。

**去术语化**：折现率越高，未来的钱在今天就越不值钱；而且越远的未来，被"折"得越狠——因为分母 `(1+r)^n` 是**指数**放大的。

下面这张表，请你**慢慢看**。它计算的是：**第 N 年发生的 100 万元气候灾害损失，在今天值多少钱**（`PV = 100万 / (1+r)^N`）：

| 灾害发生时点 | 折现率 1%（"很在乎未来"） | 折现率 3%（"中性"） | 折现率 7%（"按市场回报"） |
|---|---|---|---|
| 第 50 年 | ≈ 60.8 万 | ≈ 22.8 万 | ≈ 3.4 万 |
| 第 100 年 | ≈ 37.0 万 | ≈ 5.2 万 | **≈ 1,152 元** |
| 第 200 年 | ≈ 13.7 万 | ≈ 2,707 元 | **≈ 1.3 元** |

**读懂这张表，你就读懂了半个气候经济学**：

- 用 **7%** 折现率，一百年后高达 100 万的灾害，今天只"值" **1,152 元**——几乎是个**舍入误差**。于是模型会告诉你："为了避免它，今天花一千多块以上就不划算了。"
- 用 **1%** 折现率，同一场灾害今天"值" **37 万**——一笔巨款。于是模型会告诉你："砸钱去避免它，非常值得。"

> **同样的灾害、同样的科学，仅仅因为折现率从 1% 换成 7%，结论就从"必须不惜代价"翻转为"不必当回事"。** 这就是"折现率的暴政"：一个看似中立的技术参数，**实质上在为未来世代的福祉定价**。这把刀，下一节我们正面拿起。

## 五、把"一串现金流"一次算清：年金与永续年金

现实里的现金流往往不是一笔，而是**一连串**：光伏电站每年的售电收入、绿色债券每年的票息、退休后每月的养老金。逐笔折现太累，金融给了我们两把"快捷公式"。

### 年金（Annuity）

**去术语化**：**年金**就是"**每期一笔、金额固定、连续若干期**"的现金流——比如固定月供的房贷、一座电站连续 25 年每年 100 万的稳定收入。

按"什么时候付"，又分两种：

| | 普通年金（Ordinary Annuity） | 预付年金（Annuity Due） |
|---|---|---|
| 付款时点 | 每期**期末** | 每期**期初** |
| 例子 | 大多数贷款、债券票息 | 房租、保险费、订阅费 |
| 现值关系 | `PV = C·[1−(1+r)^(−n)] / r` | `PV(预付) = PV(普通) × (1+r)` |
| 直觉 | 标准款 | 每笔都早收/早付一期，**多滚一年利息**，所以更值钱 |

> **ESG 应用**：一座光伏电站预计 25 年、每年净收入 100 万元，折现率 6%。它今天的价值 = 100万 × [1−1.06⁻²⁵]/0.06 ≈ 100万 × 12.78 ≈ **1,278 万元**——**而不是** 100万 × 25 = 2,500 万。时间价值把它**几乎砍掉一半**。这正是为什么"未来很多年的稳定收益"听起来诱人，真折算到今天却要打很大折扣。

### 永续年金（Perpetuity）

**去术语化**：**永续年金**就是"**永远收下去、不停止**"的固定现金流。听起来像童话，却有真实对应物：一片被**可持续经营的森林**每年产出的稳定收益、历史上英国发行的"永续公债（consol）"、或一只理论上的永久绿色债券。

公式美得惊人地简单：

```
永续年金现值：PV = C / r
增长型永续：  PV = C₁ / (r − g)     （现金流每年按 g 增长，需 r > g）
```

> 例：一片可持续林场每年稳定产出 5 万元收益，折现率 5%，则其今天价值 = 50,000 / 0.05 = **100 万元**。注意：增长型永续 `C/(r−g)` 正是下一模块"股票估值（Gordon 模型）"的原型——本章的种子，会在模块三开花。

| | 年金 | 永续年金 |
|---|---|---|
| 期限 | 有限（n 期） | 无限（永远） |
| 现值公式 | `C·[1−(1+r)^(−n)]/r` | `C/r` |
| 典型对应 | 房贷、电站 25 年售电、债券 | 永续公债、可持续林场、增长永续→股票 |

### 一个让 ESG"可比"的杀手级应用：平准化度电成本（LCOE）

**去术语化**：你怎么公平比较"前期烧钱、后期几乎零成本"的**光伏**，和"前期便宜、但要烧 30 年燃料"的**燃气电站**？直接比总花费不公平，因为钱花在不同时点。

**LCOE（Levelized Cost of Energy，平准化度电成本）** 就是答案：它把**项目全生命周期的所有成本**都折现到今天，再除以**全生命周期发电量的现值**，得到一个"每度电的真实平均成本"。

```
LCOE = ( Σ 各年成本ₜ / (1+r)^t ) / ( Σ 各年发电量ₜ / (1+r)^t )
```

**这里藏着一个深刻的时间价值洞察**：
- **高折现率**会**重罚"前期资本密集"**的技术（光伏、风电、核电——钱都花在第 0 年），因为它们的成本无法被未来稀释；
- **高折现率**会**优待"燃料密集、成本后置"**的技术（燃气——成本摊在未来 30 年，被狠狠折现变小）。
- **结论**：**折现率的高低，会悄悄地把能源转型的天平，向化石能源或清洁能源倾斜**。一个技术官僚选定的折现率，就这样左右了一个国家的能源未来。

## 六、折现率不是事实，而是一道伦理选择题：Stern vs Nordhaus

现在，我们正面拿起那把刀。**经济学史上最重要的争论之一，几乎完全是这一章的内容。**

两位顶尖经济学家，看着**同样的气候科学**，得出了几乎相反的政策建议——分歧的核心，就是**该用多大的折现率**：

- **尼古拉斯·斯特恩（Stern Review, 2006）**：主张用**极低**的折现率（约 **1.4%**，其中"纯时间偏好"只设 0.1%）。他的伦理立场是——**仅仅因为一个人晚出生几十年，就给他的痛苦打折，是不道德的**（这一立场可追溯到经济学家拉姆齐，称纯时间贴现"在伦理上站不住脚"）。低折现率 → 未来灾害的现值很高 → 结论：**今天就应不惜重金、立刻大规模减排**。
- **威廉·诺德豪斯（DICE 模型，2018 年诺奖）**：主张用**更高**的、贴近**市场真实回报**的折现率（约 **4%–5%**）。他的逻辑是——资本有真实的机会成本，如果用人为压低的折现率，可能把资源错配到减排上，而**挤占了同样能造福后代的其他投资**（消除贫困、医疗、教育）。较高折现率 → 结论：**采取"政策爬坡"，先温和、再逐步加码**。
> 必须澄清：诺德豪斯**绝非**不在乎气候（他正因气候经济学获诺奖）。两人的分歧**不是"要不要行动"，而是"如何为时间定价、以多快的节奏行动"。** 这是一场严肃的、双方都有强论据的争论。

| | 低折现率（如 Stern ~1.4%） | 高折现率（如 Nordhaus ~4–5%） |
|---|---|---|
| 隐含的伦理立场 | 未来世代≈当代，几乎同等重要 | 按市场机会成本对待未来 |
| 远期灾害的现值 | **很高** | **很低** |
| 政策含义 | 现在就大力减排、不惜代价 | 渐进"政策爬坡"，避免资源错配 |
| 最有力的支持论据 | 给后代福祉打折在伦理上难以辩护 | 资本机会成本真实存在；钱也能投向其他造福后代之事 |
| 风险/批评 | 可能过度投资、忽视当下穷人需求 | 可能系统性低估灾难、为不作为提供借口 |

> **本节的元教训**：折现率**披着技术参数的外衣，内核却是一道价值判断题**——"我们这一代，愿意为子孙的世界，牺牲多少今天的享受？"金融模型不能替你回答这个问题；它只能诚实地告诉你：**你选的那个数字，正在替你回答。** 一个成熟的金融人，要能看穿数字背后的假设，而不是被数字催眠。

## 七、别被"标价"骗了：名义利率 vs 实际利率

**去术语化**：银行招牌上写的利率，是**名义利率**——它是"**标价**"。但通货膨胀像个**小偷**，每年悄悄偷走一部分购买力。扣掉这个小偷之后，你的钱**真正能多买多少东西**的增长，才是**实际利率**。

- 你存款名义涨了 7%，但物价涨了 3%，你实际"变富"的程度远不到 7%。

**费雪关系（Fisher Equation）**——三者的精确换算：

```
精确式：(1 + 名义利率) = (1 + 实际利率) × (1 + 通胀率)
       实际利率 = (1 + 名义) / (1 + 通胀) − 1
近似式：实际利率 ≈ 名义利率 − 通胀率
```

| | 名义利率（Nominal） | 实际利率（Real） |
|---|---|---|
| 是什么 | 招牌上的"标价" | 扣除通胀后的**真实购买力增长** |
| 包含通胀吗 | 含 | **不含** |
| 例子 | 银行报价 7% | (1.07/1.03)−1 ≈ **3.88%** |
| 何时用 | 折现**名义**（含通胀的）现金流 | 折现**实际**（不变价）现金流 |

> **铁律：一致性原则。** 评估一个 30 年期的光伏购电协议（PPA）时——如果你的现金流预测**含通胀**（未来电价随物价上涨），就用**名义利率**折现；如果你用的是**不变价**（实际）现金流，就必须用**实际利率**。混用是新手最常见、也最致命的错误，会让长期项目的估值彻底失真。
> **ESG 场景**：名义利率 7%、长期通胀预期 3% 时，评估一个用"今天价格"表述的 30 年减排项目，应使用实际利率 ≈ **3.88%**（≈ 4%），而非 7%——否则你会严重低估这个长期项目的真实价值。

## 八、认知科学的暗线：人脑天生是"未来的贪污犯"

现在把镜头转向**你自己的大脑**——这是本章把所有线索缝合起来的地方。

**去术语化**：金融假设人用**固定**的折现率对待未来（每多等一年，打一样的折），这叫**指数贴现（理性、时间一致）**。但真实的人脑不是这样——我们对**眼前**的诱惑极度看重，对**稍远**的未来急剧贬值，但对"遥远"和"更遥远"反而**没那么在意差别**。这叫**双曲贴现（hyperbolic discounting）**，又称**当下偏误（present bias）**。

经典证据——**偏好反转**：
- 大多数人**宁要今天的 100 元，也不要明天的 110 元**（眼前太诱人）；
- 但同样这些人，**宁要 366 天后的 110 元，也不要 365 天后的 100 元**（都很远，多等一天无所谓）。
- **同样是"多等一天换 10%"，两次却做出相反选择**——这就是不一致。它意味着"现在的我"会系统性地**剥削"未来的我"**：拖延、透支、不储蓄、不锻炼。

| | 指数贴现（金融模型/理性人） | 双曲贴现（真实人脑） |
|---|---|---|
| 折现方式 | 每期折扣率**恒定** | 近期折得狠、远期折得缓 |
| 是否时间一致 | 是（今天和明天的偏好一致） | **否（偏好会反转）** |
| 行为后果 | 自洽的长期规划 | 拖延、当下偏误、**对未来投入不足** |
| 对治之道 | —— | 自动储蓄、承诺机制、制度约束 |

**这条暗线，照亮了整章，也照亮了气候问题**：

- 人脑**天生**就给未来"打过头的折扣"——这正是为什么**气候变化**这种"成本在眼前、收益在远期"的问题，让人类在**心理上**如此难以认真对待。我们不是不知道，而是大脑**天生贪污未来**。
- 更微妙的是：第六节那场 Stern–Nordhaus 之争，争的也正是"**社会层面**该用多大折现率对待未来"。**个人的'存不下钱'，和全社会的'减不了排'，在心理机制上同根同源**——都是"当下偏误"在作祟，只是一个发生在个人储蓄账户，一个发生在地球的碳预算上。
- 而金融这把"指数贴现"的尺子，既可以是**纠正**这种偏误的理性义肢，也可能（当折现率被设得过高时）反过来**放大并合理化**我们对未来的漠视。**用好它还是用坏它，取决于你是否看穿了它。**

## 九、本章地图回望（先分后总）

把这一章收回成**一句话总纲**：

> **货币时间价值，就是给"时间"标一个价（折现率），从而能把任何时点、任何一串现金流，公平地换算到今天来比较——而你为时间标的那个价，本质上是在回答"我们有多在乎未来"。**

**公式速览（背下这张表，本章计算全覆盖）**：

| 概念 | 公式 | 一句话 |
|---|---|---|
| 终值 | `FV = PV·(1+r)^n` | 今天的钱滚到未来 |
| 现值 | `PV = FV/(1+r)^n` | 未来的钱拉回今天（估值之本） |
| 普通年金现值 | `C·[1−(1+r)^(−n)]/r` | 每期固定、有限期 |
| 预付年金现值 | `普通年金 ×(1+r)` | 每笔早一期，多滚一年息 |
| 永续年金 | `C/r` | 永远收下去 |
| 增长型永续 | `C₁/(r−g)` | 现金流年增 g（→股票估值原型） |
| 费雪关系 | `(1+名义)=(1+实际)(1+通胀)` | 名义、实际、通胀三者互换 |

**它向何处生长**：现值思想 + 增长型永续，将在**模块三（资产定价）**长成债券与股票的估值公式；而"折现率里那条'风险'腿"，正是**模块二（风险与收益）**要回答的问题。本章是标尺，后面是用尺子去丈量万物。
