# 环境监测 · 仪器方法与原理 · 速记手册

> 核心策略：不按"水/气/土"分章死背，而是**抓住6条原理主线**，每条线串一族方法和一批污染物。你真正需要记的"原理"只有6个，剩下的都是"谁用了这个原理"的排列组合。

---

## 第一层：先记住6条原理主线

所有分析方法归根到底就6条路：

| # | 原理主线 | 一句话 | 你在做什么 |
|---|---------|-------|----------|
| ① | **光被吸了多少** | 物质吸收特定波长的光，吸得越多浓度越高 | 让光穿过样品，看"少了多少" |
| ② | **光被发了多少** | 物质被激发后发出特征光，发得越亮浓度越高 | 把样品加热/激发，看"亮了多少" |
| ③ | **谁跑得快谁跑得慢** | 混合物在两相间分配速度不同而分离 | 让混合物赛跑，按到达终点的先后辨认 |
| ④ | **电信号变了多少** | 物质引起电位/电流/电量变化，变化量∝浓度 | 把样品放进电化学池，看电表读数 |
| ⑤ | **重了多少/少了多少** | 直接称量反应前后的质量差 | 秤和天平是核心工具 |
| ⑥ | **微生物吃了多少** | 微生物降解有机物时消耗的O₂量∝有机物量 | 给微生物"喂"样品，看O₂掉了多少 |

> **记忆口诀：吸-发-跑-电-称-吃。** 考试遇到任何方法，先问自己"它属于哪条线"，就不会混淆。

## 第二层：6条线展开——每条线的"方法家族"

### ━━ 主线①：光被吸了多少（吸收光谱族）━━

这条线出的方法最多，核心公式只有一个——**朗伯-比尔定律 A = Kbc**。但"谁在吸光"决定了具体方法名：

#### 1A. 分子吸光 → 分光光度法

**原理讲清楚：** 把待测物转化成有色化合物（显色反应），让单色光穿过溶液，测特定波长处的吸光度A。A = Kbc，A与浓度c成正比，用标准曲线定量。

**本质：分子整体在吸收光。** 不同显色反应生成不同颜色→在不同波长处有最大吸收峰。

**涉及的具体方法和对应污染物：**

| 具体方法名 | 显色反应是什么 | 测什么污染物 | 特征波长 |
|-----------|-------------|-----------|---------|
| 甲醛吸收-副玫瑰苯胺法 | SO₂与甲醛生成加成物，释放后与副玫瑰苯胺→紫红色 | **空气SO₂** | **577 nm** |
| 盐酸萘乙二胺法 | NO₂→亚硝酸→重氮化→偶合→玫瑰红偶氮染料 | **空气NOₓ** | **540 nm** |
| 纳氏试剂法 | NH₃与碘化汞钾→黄棕色络合物 | **水中氨氮** | 420 nm |
| 钼酸铵法 | 磷酸盐与钼酸铵→磷钼蓝 | **水中总磷/磷酸盐** | 700 nm |
| 4-氨基安替吡林法 | 酚与4-氨基安替吡林→红色安替吡林染料 | **水中挥发酚** | 510 nm |
| 亚甲基蓝法 | 硫化物与对氨基二甲基苯胺→亚甲蓝 | **水中硫化物** | 665 nm |
| 异烟酸-吡唑啉酮法 | 氰化物→氯化氰→与吡唑啉酮显色 | **水中氰化物** | 638 nm |
| 二苯碳酰二肼法 | Cr⁶⁺与二苯碳酰二肼→紫红色 | **六价铬** | 540 nm |
| 双硫腙法 | 金属离子与双硫腙→有色螯合物 | **Hg、Pb、Cd、Zn** | 因金属而异 |
| 硼酸碘化钾法 | O₃氧化I⁻→I₂→与淀粉显色 | **空气O₃** | — |

> **速记技巧：** 看到"分光光度法"三个字，脑子里蹦出的画面应该是——"把无色样品变成有色→比色→查标准曲线"。不同方法只是"加了不同的显色剂"。

#### 1B. 原子吸光 → 原子吸收光谱法（AAS）

**原理讲清楚：** 先把样品原子化（火焰或石墨炉加热→溶液中的金属盐分解→变成基态原子蒸气），然后让空心阴极灯发出该元素的特征共振线穿过原子蒸气。基态原子吸收特征波长的光→吸光度A∝原子浓度。

**本质：基态原子在吸收光。** 跟分光光度法的区别在于——分光光度法是分子吸收，AAS是原子吸收。

**两种原子化方式：**
- **火焰AAS**：用火焰（乙炔-空气焰）把溶液喷入火焰原子化，适合mg/L级别。
- **石墨炉AAS**：用石墨管电加热原子化，无火焰，灵敏度高100倍，适合μg/L级别痕量金属。

**仪器构造关键词：** 光源（空心阴极灯）→ 原子化系统（火焰/石墨炉）→ 分光系统 → 检测系统（光电倍增管）。

**测什么：** 几乎所有微量/痕量金属——**Cd、Pb、Cu、Zn、Cr（总铬）、Ni**等。每种元素对应一个特征波长和一根专用空心阴极灯。

#### 1C. 冷原子吸收/冷原子荧光 → 测汞专用

**原理讲清楚：** 汞的特殊性在于它**常温下就能变成原子蒸气**（汞沸点低、易挥发）。用SnCl₂把Hg²⁺还原成单质Hg⁰，吹入氮气/空气→汞蒸气被带入吸收池→测253.7 nm处的吸光度。

不需要火焰、不需要石墨炉，所以叫"冷"原子。

**冷原子荧光**原理类似：汞原子吸收253.7 nm的光被激发→回到基态时发出荧光→测荧光强度。荧光法灵敏度更高。

> **记忆锚点：看到253.7 nm就想到汞，看到SnCl₂还原就想到冷原子法。**

#### 1D. 非分散红外吸收法（NDIR）

**原理讲清楚：** 气体分子对红外光有特征吸收（分子振动-转动吸收）。CO分子在4.7 μm附近有强吸收带。让红外光穿过含CO的气室→CO浓度越高→红外光被吸收越多→检测器收到的光越弱。

"非分散"＝不用光栅分光，而是用**气体滤波**或**双气室对比**的方式选择性检测。

**测什么：空气中CO**（最经典应用）；也用于TOC测定中CO₂的检测。

> **记忆锚点：NDIR ↔ CO，仪器可连续自动监测。**

### ━━ 主线②：光被发了多少（发射光谱族）━━

#### 2A. ICP-OES / ICP-AES（电感耦合等离子体发射光谱）

**原理讲清楚：** 样品溶液被雾化后由氩气载入**ICP等离子体炬**（温度6000-8000 K），在这个超高温中：
1. 溶剂蒸发 → 2. 盐分解 → 3. 原子化 → 4. 电离 → 5. 激发
激发态原子/离子回到基态时**发射出特征波长的光**。不同元素发射不同波长的光→**波长定性，强度定量**。

定量关系：**I = aC^b**（I为发射强度，C为浓度，a和b为系数）。

**跟AAS的根本区别：**
- AAS = 让原子"吸"光 → 测吸了多少（吸收光谱）
- ICP-OES = 让原子"发"光 → 测发了多少（发射光谱）

**最大优势：可以同时测定几十种元素。** 一次进样出所有金属结果。

**测什么：** Al、Fe、Cd、Cr、As、Ba、Be、Ca、Co、Cu、Mn、Ni、Pb、Sr、Ti、V、Zn…全部金属和类金属。

#### 2B. 化学发光法

**原理讲清楚：** 某些化学反应释放能量以光的形式发射出来。O₃与乙烯/鲁米诺反应→发光强度∝O₃浓度。

**测什么：空气O₃。**

### ━━ 主线③：谁跑得快谁跑得慢（色谱族）━━

**色谱法的统一原理：** 样品随流动相（气体或液体）流过固定相（色谱柱），不同组分在两相间的分配系数不同→保留时间不同→先后出柱→被检测器检测。

#### 3A. 气相色谱 GC

**适用对象：** 沸点低、热稳定、能气化的有机物。

**GC的核心不在色谱柱（分离），而在检测器（识别）。** 4种检测器是高频考点：

| 检测器 | 全称 | 原理一句话 | 类型 | 测什么 | 不能测什么 |
|-------|------|----------|------|-------|----------|
| **FID** | 火焰离子化检测器 | 有机物在氢焰中燃烧→碎片离子→产生电流→电流∝有机物量 | 质量型、破坏性、**通用** | 几乎所有有机物 | 惰性气体、空气、H₂O、CO、CO₂、CS₂、NO、SO₂、H₂S |
| **ECD** | 电子捕获检测器 | β放射源产生电子流→电负性组分进入→捕获电子→基流↓→出峰 | 浓度型、非破坏性、**高选择性** | 卤代烃、有机氯农药、多氯联苯（含N/O/S杂原子的也有响应） | 不能捕获电子的物质 |
| **TCD** | 热导检测器 | 载气与组分的热导率不同→热丝温度变→电阻变→电桥不平衡→信号 | 浓度型、非破坏性、**通用** | 任何组分（但灵敏度低→常量分析） | 无特殊限制，但灵敏度最低 |
| **FPD** | 火焰光度检测器 | 含S/P化合物在富氢焰中燃烧→激发→回到基态发出特征波长光 | 质量型、**选择性** | 含**S**（394 nm）和含**P**（526 nm）化合物 | 不含S/P的化合物 |

> **速记口诀："FID啥都测就是不测无机小分子，ECD专抓电子贼（卤/氯/农药），TCD老好人什么都行就是不灵敏，FPD只认硫磷两兄弟（394/526）"。**

**GC测什么污染物：**
- CO → GC-FID（经镍催化转化为CH₄再检测）
- 烃类（甲烷/非甲烷烃）→ GC-FID
- 有机氯农药（六六六/DDT）→ GC-**ECD**
- 挥发性卤代烃 → 顶空GC-**ECD**
- VOCs → 吹扫捕集-GC-FID / GC-MS

#### 3B. HPLC（高效液相色谱）

**与GC的区别：** 流动相是液体而非气体。适合**高沸点、热不稳定、不能气化**的大分子有机物。

**测什么：** 多环芳烃（PAHs）、苯并(a)芘。

#### 3C. GC-MS（气质联用）

**本质：** GC负责分离 + MS负责鉴定（按质荷比m/z分离离子）。定性定量兼备，痕量有机物的"终极武器"。

**测什么：** PAHs、VOCs、各种特定有机物的确证分析。

#### 3D. 离子色谱 IC

**原理：** 离子交换分离 + 电导检测。一次进样可连续测定多种离子。

**测什么：** F⁻、Cl⁻、SO₄²⁻、NO₃⁻等阴离子。

### ━━ 主线④：电信号变了多少（电化学族）━━

| 方法 | 测的电信号 | 原理一句话 | 测什么 |
|------|----------|----------|-------|
| 离子选择电极 | 电位 | 特定离子透过选择性膜→膜电位∝离子活度→能斯特方程 | **F⁻**（氟电极）、**pH**（玻璃电极） |
| 氧电极（Clark电极） | 扩散电流 | O₂穿透膜→在阴极还原→扩散电流I∝DO | **溶解氧DO** |
| 阳极溶出伏安法 | 溶出电流 | 先在汞电极上电解富集金属→再反向扫描溶出→溶出峰高∝浓度 | 痕量重金属（**Cd、Pb、Cu、Zn**） |
| 库仑滴定 | 电量 | 用电解产生的试剂来滴定→法拉第定律W=ItM/(96500n) | **COD、SO₂** |
| 电导率 | 电导 | 溶液离子浓度越高→电导率越大 | 矿化度、降水电导率 |

> **记忆锚点：** 电化学≠一种方法，而是"用电信号量浓度"的一族方法。每种方法测的电信号不同。

### ━━ 主线⑤：重了多少/少了多少（重量法/滴定法）━━

这是最"朴素"的方法——靠天平和标准溶液。

#### 5A. 重量法（称重差）

| 对象 | 操作原理 | 测什么 |
|------|---------|-------|
| TSP/PM₁₀ | 恒重滤膜→采样→再称重→质量差÷体积=浓度 | **空气颗粒物浓度** |
| 降尘 | 集尘缸收集→称重 | **空气降尘量** |
| 硫酸盐化速率 | 碱片/PbO₂挂片暴露→称重或IC测SO₄²⁻增量 | **大气硫酸盐化速率** |
| 矿化度 | 水样蒸干→称残渣 | **水中矿化度** |
| 油类 | 萃取→蒸干→称重 | **水中油类**（也可红外法） |

#### 5B. 滴定法（标准溶液消耗量）

| 方法 | 反应原理 | 测什么 | 核心试剂 |
|------|---------|-------|---------|
| **碘量法** | DO"固定"为MnO(OH)₂→酸化释放I₂→Na₂S₂O₃滴定I₂ | **溶解氧DO** | MnSO₄ + 碱性KI + Na₂S₂O₃ |
| **重铬酸钾法** | K₂Cr₂O₇在酸性条件下氧化水中还原性物质→余量用硫酸亚铁铵回滴 | **COD** | K₂Cr₂O₇ + H₂SO₄ + AgSO₄(催化) + HgSO₄(掩蔽Cl⁻) |
| 硝酸银滴定 | Ag⁺与CN⁻/Cl⁻反应→终点变色 | **氰化物、氯离子** | AgNO₃ |

### ━━ 主线⑥：微生物吃了多少（生物法）━━

| 方法 | 原理 | 测什么 |
|------|------|-------|
| **BOD₅五天培养法** | 20±1℃暗处培养5天，微生物分解有机物消耗的DO量 = BOD₅ | **生化需氧量** |
| 微生物电极法 | 微生物膜+氧电极→微生物耗氧速率∝有机物浓度 | 快速BOD |
| LD₅₀试验 | 给实验动物不同剂量→找到致死50%的剂量 | 固废**急性毒性** |

## 第三层：反过来记——典型污染物→该选哪个方法

> 考试经常反着问："某污染物用什么方法测？"用下面这张表快速查。

### 水质篇

| 污染物 | ⭐首选方法 | 原理主线 | 关键记忆点 |
|-------|----------|---------|----------|
| **DO** | 碘量法（修正碘量法） | ⑤滴定 | 反应链：Mn²⁺→Mn(OH)₂→MnO(OH)₂→Mn⁴⁺+I₂→Na₂S₂O₃滴定 |
| | 氧电极法 | ④电化学 | Clark电极，现场连续测 |
| **COD** | 重铬酸钾法 | ⑤滴定 | 公式COD=(V₀-V₁)×c×8×1000/V样；氧化率≈90% |
| | 库仑滴定 | ④电化学 | 法拉第定律，仪器化 |
| **BOD₅** | 五天培养法 | ⑥生物 | 20℃/5天/暗处；稀释水BOD<0.2；耗氧>2且剩余DO>1 |
| **TOC** | 燃烧氧化-NDIR | ①吸收 | 高温燃烧→CO₂→红外检测；TC-IC=TOC |
| **氨氮** | 纳氏试剂分光光度法 | ①吸收 | 碘化汞钾显色 |
| **总磷** | 钼酸铵分光光度法 | ①吸收 | 磷钼蓝 |
| **汞Hg** | 冷原子吸收法 | ①吸收 | SnCl₂还原→Hg⁰蒸气→**253.7 nm** |
| **镉Cd** | AAS（石墨炉） | ①吸收 | 痕量→石墨炉；也可双硫腙法/ICP-OES |
| **铅Pb** | AAS | ①吸收 | 火焰或石墨炉；也可双硫腙/ICP/阳极溶出 |
| **铬Cr⁶⁺** | 二苯碳酰二肼分光光度法 | ①吸收 | 紫红色络合物 |
| **铬（总）** | 火焰AAS | ①吸收 | 需先氧化全部Cr为Cr⁶⁺再还原 |
| **氟化物F⁻** | 离子选择电极法 | ④电化学 | 氟电极，直接快速 |
| **氰化物** | 异烟酸-吡唑啉酮分光光度法 | ①吸收 | 也可硝酸银滴定 |
| **挥发酚** | 4-氨基安替吡林分光光度法 | ①吸收 | 红色染料 |
| **VOCs** | 吹扫捕集-GC / 顶空GC-MS | ③色谱 | 先富集再分离检测 |
| **卤代烃** | 顶空GC-**ECD** | ③色谱 | ECD专测电负性物 |
| **PAHs/苯并(a)芘** | HPLC / GC-MS | ③色谱 | 高沸点→HPLC优先 |
| **油类** | 重量法 / 红外分光光度法 | ⑤/① | 萃取后称重或红外测 |
| **多种金属同时** | ICP-OES | ②发射 | 一次出所有金属结果 |

| **VOCs** | GC-FID/GC-MS | ③色谱 | 吹扫捕集预处理 |

### 土壤篇

| 污染物 | ⭐首选方法 | 关键记忆点 |
|-------|----------|----------|
| 重金属 | AAS / ICP-OES | 先消解（混合酸/碱熔/高压/微波）再测 |
| 有机氯农药 | GC-ECD | 索氏提取→净化→GC |
| 苯并(a)芘 | HPLC / GC-MS | 索氏提取 |
| 多元素同测 | XRF（X射线荧光） | 固体直接测，无需消解 |

## 第四层：高频混淆点——"这俩到底有什么区别"

### AAS vs ICP-OES（最容易搞混）

| 比较项 | AAS | ICP-OES |
|-------|-----|---------|
| 原理 | 基态原子**吸收**特征光 | 激发态原子**发射**特征光 |
| 光源 | 空心阴极灯（**每种元素一根灯**） | ICP等离子炬（6000-8000K） |
| 能否同时多元素 | **不能**（换灯换条件） | **能**（最大优势） |
| 灵敏度 | 石墨炉很高 | 高，但不及石墨炉AAS |
| 记忆画面 | "灯照→原子吸→看少了多少" | "火烧→原子发→看亮了多少" |

### COD vs 高锰酸盐指数

| | COD（重铬酸钾法） | 高锰酸盐指数 |
|---|---|---|
| 氧化剂 | K₂Cr₂O₇ | KMnO₄ |
| 氧化率 | ≈**90%**（氧化能力强） | ≈**50%** |
| 适用 | 废水、污水 | 地表水（较清洁的水） |
| 关系 | 两者无固定换算比 | |

### BOD vs COD vs TOC

| | BOD | COD | TOC |
|---|---|---|---|
| 测的是 | 微生物**能降解**的有机物耗氧 | 化学氧化剂**能氧化**的还原性物质耗氧 | 燃烧法测**全部有机碳** |
| 方法 | 生物培养 | 化学滴定 | 仪器（燃烧+NDIR） |
| 覆盖范围 | 最窄（只测可生化部分） | 较宽（含部分无机还原物） | 最全（所有有机碳） |
| BOD/COD>0.5 | → 可生化性好 | | |

### 碘量法测DO——反应链要会写

这是最经典的"反应链"型考题：

```
第1步（固定DO）：    MnSO₄ + 2NaOH → Mn(OH)₂↓（白色）
第2步（氧化）：      2Mn(OH)₂ + O₂ → 2MnO(OH)₂（棕色）←"固定"了溶解氧
第3步（酸化释放I₂）：MnO(OH)₂ + 2H₂SO₄ → Mn(SO₄)₂ + 3H₂O
                    Mn(SO₄)₂ + 2KI → MnSO₄ + I₂ + K₂SO₄
第4步（滴定）：      I₂ + 2Na₂S₂O₃ → 2NaI + Na₂S₄O₆
```

**修正法的逻辑：** 当有干扰物存在时——
- 亚硝酸盐干扰 → 加**叠氮化钠**（NaN₃）消除
- Fe²⁺干扰 → 加**高锰酸钾**消除

## 第五层：数字速记墙

| 数字 | 对应什么 |
|------|---------|
| **253.7 nm** | 冷原子吸收/荧光测**汞**的特征波长 |
| **577 nm** | SO₂甲醛-副玫瑰苯胺法最大吸收波长 |
| **540 nm** | NOₓ盐酸萘乙二胺法最大吸收波长 |
| **394 nm / 526 nm** | FPD检测器：S特征394 / P特征526 |
| **6000-8000 K** | ICP等离子炬温度 |
| **90% / 50%** | 重铬酸钾 / 高锰酸钾氧化率 |
| **A = Kbc** | 朗伯-比尔定律（分光光度法基础） |
| **I = aC^b** | ICP-OES定量关系 |
| **W = ItM/(96500n)** | 法拉第定律（库仑滴定） |
| 400-780 nm | 可见光波长范围 |

## 终极速记框架图

```
                    ┌─ 分光光度法 ─── SO₂(577) / NOₓ(540) / 氨氮 / 总磷 / 酚 / 氰 / Cr⁶⁺ / Hg(双硫腙)
                    │
         ①吸收 ────┤─ AAS ───────── Cd / Pb / Cu / Zn / Cr(总) / Ni  [火焰or石墨炉]
         (光少了)   │
                    ├─ 冷原子吸收 ──── Hg  [253.7nm, SnCl₂还原]
                    │
                    └─ NDIR ─────── CO(空气) / CO₂(TOC测定中)

         ②发射 ────── ICP-OES ────── 多元素同测(Al/Fe/Cd/Cr/As/Pb/Cu/Zn…)  [6000-8000K]
         (光亮了)     化学发光 ─────── O₃

                    ┌─ GC-FID ───── 烃类/CO(转化后)        [通用有机物]
                    │  GC-ECD ───── 有机氯农药/卤代烃/PCBs  [电负性物]
         ③色谱 ────┤  GC-FPD ───── 含S/P化合物            [S:394, P:526]
         (谁跑得快)  │  GC-TCD ───── 常量气体分析            [通用低灵敏]
                    ├─ HPLC ────── PAHs/苯并(a)芘          [高沸点]
                    ├─ GC-MS ───── VOCs/PAHs确证分析       [定性+定量]
                    └─ IC ─────── F⁻/Cl⁻/SO₄²⁻/NO₃⁻      [多离子同测]

                    ┌─ 离子选择电极 ── F⁻ / pH
         ④电化学 ──┤─ 氧电极 ────── DO（现场连续）
         (电变了)   ├─ 阳极溶出伏安 ── Cd/Pb/Cu/Zn（痕量）
                    └─ 库仑滴定 ──── COD / SO₂

         ⑤称量 ────┬─ 重量法 ────── TSP/PM₁₀/降尘/硫酸盐化速率/矿化度/油类
         (重了多少)  └─ 滴定法 ────── DO(碘量法) / COD(重铬酸钾法) / CN⁻(硝酸银)

         ⑥生物 ────── BOD₅培养法 ── BOD₅
         (吃了多少)   LD₅₀试验 ──── 固废急性毒性
```
