## 三、已固化的提取协议

### 3.1 Tier 分级（45 列 schema 的核心）

```
Tier-A 基准库：野外成熟（≥5 yr 或 DBH ≥5 cm）+ 原位 + 无胁迫
              + 标化算法明示 + 报告 SD/SE/n + 活体测量
Tier-B 补充库：温室/盆栽长期培养 / 城市绿化稳定栽植 / 方法学有小缺项但数据合理
Tier-C 胁迫修正库：任何明示的胁迫处理组
Tier-D 拒收：剪枝未恢复立测 / 关键元数据缺失 / 明显方法学失误
```

**实践经验**：到目前为止，Tier-B 主要触发条件是 **缺 SD/SE/n** 或 **剪枝室内法**。

### 3.2 EF_value 字段的状态语义（无 Detection_Status 列时的字符串约定）

|状态|EF_value 写法|
|---|---|
|检出且定量|具体数值（如 `8.939`）|
|检出但未定量|`detected_unquantified`|
|未检出|`n.d.` 或 `n.d. (<LOD)`|
|歧义零（实测/未测无法区分）|`0` + Notes 标注歧义|
|文本只说">阈值"|`>45` 字符串|

### 3.3 Std_Algorithm 标注

**规则**：原文未明示 → 一律记 `unspecified`，**不做"推断后缀"**。 即使可据 Eq. 形式或引用文献推断为 G93，主字段仍记 unspecified，推断证据写入 Notes 作审计线索。

### 3.4 Lat/Lon 缺失约定

采样具体经纬度未报时 → 填位点行政区/研究范围的近似中心点 + Notes 注明"approximate; specific site not reported"。

### 3.5 自测 vs 二手汇编值的取舍

**原则**：只提取本论文实际测量的物种，**不提取作者从其他文献汇编/属内补位的值**——回溯到原始文献单独建条。

**操作**：

- Bao 2025 → 仅提取 3 个 2022 自测物种
- Wang 2003 → 通过注脚反推 + EF 值唯一性判断
- Ghirardo Table S5B → 整表归入辅助文件，不入主库

### 3.6 OVOCs "0" 值的歧义处理

Bao Table A.1 / Ghirardo TableS5A 中 "0" 可能含义为：实测为零 / 未测量 / 未报告。 **处理**：保留 EF_value=0，Notes 注明歧义，阶段 3 定量合成时用 Notes 关键词排除。

### 3.7 化合物分辨率 Compound_Resolution 受控词表

|值|含义|
|---|---|
|`speciated (ISO)` / `speciated (α-pinene)` 等|单体明确|
|`lumped_MT` / `lumped_SQT` / `lumped_OVOC`|化学大类合并|
|`lumped_cMT_de_novo` / `lumped_cMT_storage` / `lumped_sMT`|Ghirardo 引入的 c/s 拆分|
|`lumped_other_alkenes`|Jing 引入|
|`lumped_BZ` / `lumped_GLV`|Ghirardo 引入（sBVOC 类）|
|`lumped_total_BVOC`|Wu 引入（仅给总量时）|
