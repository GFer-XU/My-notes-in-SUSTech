# 第一部分　污染物治理总结（原理 + 反应）

> 本部分把讲义里散见的"治理/去除"方法系统归类。每条给出**原理**和**关键反应式**，并标注章页。

## A. 水污染物治理

### A1. 重金属——化学沉淀法（硫化物 / 氢氧化物沉淀）
（Ch.6 p5–6；Ch.4 p31；Ch.20 in-situ p29）

**原理**：重金属多为"亲硫元素 (sulfur seekers)"，在还原/厌氧条件下与 S²⁻ 生成极难溶硫化物；或在碱性条件下生成氢氧化物沉淀而被去除。这是 pE/pH 控制溶解度的直接应用——**低 pE（厌氧）下硫化物稳定，高 pE（氧化）下以氧化物/碳酸盐存在**（Ch.4 p31 的金属形态表）。

**反应（硫化物沉淀）**：
- 微生物先把 SO₄²⁻ 还原产生 H₂S：2{CH₂O} + SO₄²⁻ + 2H⁺ → 2CO₂ + H₂S + 2H₂O
- 镉沉淀：Cd²⁺ + H₂S → CdS(s)↓ + 2H⁺；海水中 CdCl⁺ + HS⁻ → CdS(s) + H⁺ + Cl⁻（Ch.6 p5）
- 通式：Pb²⁺ + HS⁻ → PbS(s)↓ + H⁺（Ch.19 p27）

**反应（氢氧化物沉淀）**：M²⁺ + 2OH⁻ → M(OH)₂(s)↓（如 Co²⁺ + 2OH⁻ → Co(OH)₂(s)，Ch.19 p26）。

**配套要点**：螯合剂（NTA、EDTA、腐殖质）会显著提高重金属溶解度、阻碍其沉淀去除（Ch.2 p45–52）——治理时要注意水中是否有螯合剂。

### A2. Cr(VI) 的还原沉淀法
（配对题 19 出现过：2CrO₄²⁻ + 3SO₂ + 4H⁺ → Cr₂(SO₄)₃ + …）

**原理**：Cr(VI)（如 CrO₄²⁻、Cr₂O₇²⁻）剧毒、致癌、迁移性强；先用还原剂（SO₂、亚硫酸盐、Fe²⁺）把 **Cr(VI) → Cr(III)**，Cr(III) 毒性低且在中性条件下生成 Cr(OH)₃ 沉淀去除。
**反应**：2CrO₄²⁻ + 3SO₂ + 4H⁺ → Cr₂(SO₄)₃ + H₂O（还原）；随后 Cr³⁺ + 3OH⁻ → Cr(OH)₃(s)↓。
> 注意：**Fenton 反应不能用于处理 Cr(VI)**（见 A4 末尾解释）。

### A3. 难降解有机物——活性炭吸附 / 物理法
（Ch.6 p54）

**原理**：生物难降解 (biorefractory) 有机物（氯代烃、苯、氯仿、四氯乙烯、PFAS 等）不能被生物处理有效去除，需用**物理方法如活性炭吸附**截留。
**要点**：吸附量符合分配系数 K_d = C_s/C_w 或 Freundlich 经验式 C_s = K_F·C_w^(1/n)（Ch.4 p9）。

### A4. 有机污染物——Fenton 高级氧化（重点，对应论述题/简答）
（Ch.3 p49–51）

**原理**：H₂O₂ 在 Fe(II) 催化下产生强氧化性的**羟基自由基 (hydroxyl radical, •OH)**，•OH 几乎无选择地氧化有机污染物，最终矿化为 CO₂ 和 H₂O。
**核心反应（Fenton 反应）**：
$$\text{Fe}^{2+} + \text{H}_2\text{O}_2 \rightarrow \text{Fe}^{3+} + \text{OH}^- + {}^{\bullet}\text{OH}$$
**对苯甲酸 (benzoic acid)、苯酚 (phenol) 的去除**：•OH 进攻芳环→羟基化→开环→逐步氧化为小分子羧酸→最终 CO₂ + H₂O。例如苯酚被 •OH 加成生成邻/对苯二酚，再被氧化为醌、开环，直至完全矿化。
**能否处理 Cr(VI)？——不能**：Fenton 是**氧化**过程，而 Cr(VI) 已是高氧化态，需要的是**还原**才能转化为低毒 Cr(III)。Fenton 不仅无法还原 Cr(VI)，体系中的 Fe²⁺ 反而会被 Cr(VI) 氧化。因此 Fenton 用于氧化有机物，对 Cr(VI) 这类需还原去除的污染物无效。

### A5. 有机污染物——光催化（TiO₂）
（Ch.3 p51–52）

**原理**：TiO₂ 在 < ~388 nm 紫外光下激发产生电子–空穴对 (e⁻/h⁺)；空穴氧化、电子还原，在表面引发氧化还原反应降解有机物、NOₓ、NH₃、SO₂ 等。
**过程**：TiO₂ + hν → e⁻(CB) + h⁺(VB)；h⁺ + H₂O → •OH + H⁺；•OH 氧化有机物 → CO₂、H₂O；e⁻ + O₂ → O₂•⁻。
**改性**：金属/非金属掺杂、负载于 C、CNT、石墨烯、g-C₃N₄ 等可拓展可见光响应。

### A6. 富营养化与氮磷去除——生物脱氮 + 化学除磷
（Ch.5 p30；Ch.6 p15）

**生物脱氮（硝化 + 反硝化）**：
- 硝化 (nitrification)：NH₄⁺ + 2O₂ → NO₃⁻ + 2H⁺ + H₂O（由亚硝化单胞菌 *Nitrosomonas*、硝化杆菌 *Nitrobacter* 介导）。
- 反硝化 (denitrification)：4NO₃⁻ + 5{CH₂O} + 4H⁺ → 2N₂(g)↑ + 5CO₂ + 7H₂O，把氮以 N₂ 形式返回大气。
**化学除磷**：投加 Ca²⁺/Al³⁺/Fe³⁺ 生成难溶磷酸盐沉淀，如 5Ca²⁺ + 3PO₄³⁻ + OH⁻ → Ca₅(OH)(PO₄)₃(s)↓（羟基磷灰石，Ch.4 p7）。

### A7. 酸性矿山废水——中和
（Ch.5 p35；Ch.13 p55）

**成因**：黄铁矿 FeS₂ 被细菌氧化产酸：2FeS₂(s) + 7O₂ + 2H₂O → 4H⁺ + 4SO₄²⁻ + 2Fe²⁺；4Fe²⁺ + O₂ + 4H⁺ → 4Fe³⁺ + 2H₂O。
**治理（中和）**：加石灰石/石灰中和酸：2H⁺ + CaCO₃ → Ca²⁺ + CO₂↑ + H₂O；Fe³⁺ 随后水解沉淀 Fe³⁺ + 3H₂O → Fe(OH)₃(s)↓ + 3H⁺ 而被去除。

### A8. 悬浮颗粒/胶体——混凝 (coagulation) 与絮凝 (flocculation)
（Ch.4 p24–25）

**原理**：天然胶体（pH 7 多带负电）靠表面电荷相互排斥而稳定。
- **混凝 (coagulation)**：投加电解质压缩双电层、中和表面电荷，使颗粒可碰撞聚集。
- **絮凝 (flocculation)**：加入"桥联"高分子（聚电解质/聚丙烯酰胺等），化学键连接胶粒形成绒状絮体 (floc) 而沉降。
**应用**：废水生物处理中大量有机碳以细菌絮体形式被去除。

### A9. 硬度去除——石灰软化
（Ch.6 p14 硬度；戴树桂相关）

**原理**：硬度主要由 Ca²⁺、Mg²⁺ 引起；加石灰使其转化为 CaCO₃、Mg(OH)₂ 沉淀。
**反应**：Ca²⁺ + 2HCO₃⁻ + Ca(OH)₂ → 2CaCO₃(s)↓ + 2H₂O。

### A10. 投加除氧剂去除溶解氧（保护管道）
（Ch.6 p13）

**原理**：亚硫酸盐作为氧清除剂 (O₂ scavenger)：2SO₃²⁻ + O₂ → 2SO₄²⁻。

## B. 大气污染物治理

### B1. 颗粒物控制（四类方法）
（Ch.9 p25–27）

| 方法 | 原理 |
|---|---|
| 沉降 Sedimentation | 靠重力使较大颗粒沉降 |
| 惯性/过滤 Filtration（袋式除尘 baghouse） | 含尘气体过织物袋，颗粒被截留，定期振打回收 |
| 洗涤 Scrubber（文丘里洗涤器 Venturi scrubber） | 用液体冲洗气流中的颗粒 |
| 静电除尘 Electrostatic precipitator | 3万–5万伏高压使颗粒带电，被接地极板收集 |

### B2. SO₂ 控制（燃烧中脱硫 + 烟气脱硫）
（Ch.10 p11–13）

**燃烧前/中**：物理分选除黄铁矿；**流化床燃烧 (fluidized bed combustion)**——在含 CaCO₃ 的颗粒床中燃烧固硫：
CaCO₃ → CaO + CO₂；CaO + SO₂ → CaSO₃（可进一步氧化为 CaSO₄）。
**烟气脱硫（主要系统，Ch.10 p12）**：

| 工艺 | 关键反应 | 特点 |
|---|---|---|
| 石灰浆洗涤 Lime slurry | Ca(OH)₂ + SO₂ → CaSO₃ + H₂O | 每吨煤需~200 kg 石灰，废渣量大 |
| 石灰石浆洗涤 Limestone slurry | CaCO₃ + SO₂ → CaSO₃ + CO₂↑ | 碱性弱于石灰，效率略低 |
| 氧化镁洗涤 MgO | Mg(OH)₂ + SO₂ → MgSO₃ + H₂O | 吸收剂可再生 |
| 钠碱洗涤 Sodium-base | Na₂SO₃ + H₂O + SO₂ → 2NaHSO₃；加热再生 2NaHSO₃ → Na₂SO₃ + H₂O + SO₂ | 可再生 |
| 双碱法 Double alkali | 2NaOH + SO₂ → Na₂SO₃；Ca(OH)₂ + Na₂SO₃ → CaSO₃(s) + 2NaOH（NaOH 再生） | 用廉价石灰再生贵的钠碱 |

CaSO₃ 经氧化可得石膏 CaSO₄·2H₂O（可利用为副产品）。

### B3. NOₓ 控制
（Ch.10 p22）

**(1) 抑制生成**：低过量空气燃烧（限制 O₂）、降低燃烧温度（抑制 N₂ + O₂ → 2NO）。
**(2) 尾气去除**：因 N 氧化物酸性弱，碱吸收效果差；最常用**催化还原**——用还原剂把 NOₓ 还原为 N₂。汽车尾气催化剂用少量过量 CO/HC 还原 NOₓ。生物滤池 (biofilter) 为实验性方法。

### B4. 汽车尾气——三元催化转化器 (three-way catalytic converter)
（Ch.12 p9）

**原理**：单一催化单元同时处理 HC、CO、NOₓ 三类污染物：
- 氧化：CO + ½O₂ → CO₂；HC + O₂ → CO₂ + H₂O
- 还原：CO + NO → ½N₂ + CO₂
**配合**：计算机控制点火正时、空燃比 (air/fuel ratio)，使排放最小。

### B5. HF 的处理与急救（HF 极危险，对应 HF 简答题）
（Ch.10 p26–27）

**危害**：HF 极毒，能腐蚀玻璃（SiO₂ + 6HF → H₂SiF₆ + 2H₂O），可穿透皮肤深入骨骼。
**急救/处理原理**：F⁻ 与体内 Ca²⁺、Mg²⁺ 强烈结合，造成低钙血、深部组织和骨损伤；故用**葡萄糖酸钙凝胶 (calcium gluconate)** 补 Ca²⁺ 把游离 F⁻ 固定为难溶 CaF₂。

> 大气污染物控制更多体现在"机理 + 末端治理"，论述题常考 SO₂/NOₓ/烟雾的形成与控制，务必能写出上面关键反应。

# 第二部分　主要污染物的环境化学行为

> 框架（即环境化学的定义本身，Ch.1 p34）：**来源 origin → 迁移/转化 transport & transformation → 反应 reactions → 效应 effects → 归趋 fates**。论述题、简答题（如第20题"汞、铅、HF"）就按这个框架答。

## 2.1 汞 Mercury (Hg)（重点，简答题常考）
（Ch.1 p35–36；Ch.6 p6；Ch.23 p47）

- **来源 Origin**：燃煤、金属冶炼、含汞工业废水、氯碱工业。
- **迁移/转化 Transport**：无机汞 Hg²⁺ 进入水体/沉积物后，被**厌氧细菌甲基化**（通过甲基钴胺素 methylcobalamin）生成**甲基汞 CH₃Hg⁺ 和二甲基汞 (CH₃)₂Hg**：HgCl₂ → CH₃HgCl + Cl⁻。甲基汞脂溶性强，沿食物链**生物放大 (biomagnification)**，鱼体内浓度极高。气态 Hg⁰ 还可远距离传输。
- **反应 Reactions**：Hg²⁺ ⇌ Hg⁰ ⇌ (CH₃)Hg 之间的氧化还原与甲基化/去甲基化循环（讲义汞循环图）。
- **效应 Effects**：**水俣病 (Minamata disease)**——中枢神经系统疾病（1953–1960 日本水俣湾事件）；金属汞蒸气、无机盐、有机汞均剧毒，损害中枢神经。
- **归趋 Fates**：在沉积物中累积，可被再甲基化释放；经食物链富集于鱼类和人体脂肪/神经组织。

## 2.2 铅 Lead (Pb)
（Ch.6 p6；Ch.4 p39 沉积记录；Ch.23 p47）

- **来源**：过去广泛使用——管道（铅管、焊条）、**四乙基铅 Pb(C₂H₅)₄ 汽油抗爆剂**、含铅涂料、冶炼。
- **迁移/转化**：四乙基铅脂溶、易进入人体；水中 Pb²⁺ 多以 PbCO₃ 存在，可被螯合剂（NTA/EDTA）溶解迁移（Ch.2 p45–52）。沉积物岩芯铅含量随含铅汽油兴衰而变（Ch.4 p39，经典环境记录）。
- **反应**：Pb²⁺ + CO₃²⁻ → PbCO₃(s)；与 NTA：Pb²⁺ + T³⁻ → PbT⁻（增溶）。
- **效应**：**抑制血红蛋白合成、损害神经系统**（尤其影响儿童智力）。
- **归趋**：吸附沉积、生物累积；含铅汽油淘汰后环境铅负荷下降。

## 2.3 镉 Cadmium (Cd)
（Ch.6 p5；Ch.1 p38；Ch.23 p47）

- **来源**：采矿、工业废水（尤其**电镀 metal plating**）。
- **迁移/转化**：化学性质与锌相似，可在酶中替代 Zn；厌氧条件下生成 CdS 沉淀固定。
- **反应**：Cd²⁺ + H₂S → CdS(s) + 2H⁺。
- **效应**：剧毒，**痛痛病 (Itai-Itai disease)**；影响酶、致肺炎。
- **归趋**：低 pE 下以 CdS 稳定，高 pE 下以 CdCO₃ 存在（Ch.4 p31）。

## 2.4 砷 Arsenic (As)（类金属 metalloid）
（Ch.6 p7；Ch.14 p25；Ch.23 p47）

- **来源**：燃煤、铜/金/铅冶炼副产品、旧农药 [Pb₃(AsO₄)₂、Na₃AsO₃]、天然地下水。
- **迁移/转化**：常与磷酸盐矿物伴生；在还原条件下，铁氧化物 FeO(OH) 还原溶解会**释放吸附态 As 进入地下水**：FeO(OH)(As)(s) + {CH₂O} → Fe²⁺(aq) + As(aq)。**孟加拉国管井砷中毒**影响数百万人。
- **反应**：氧化态 As(III)/As(V) 互变；微生物可氧化/还原/甲基化。
- **效应**：剧毒（>100 mg 摄入急性中毒），**凝固蛋白、干扰代谢、致癌**；抑制酶活性与 DNA 修复。
- **归趋**：随地下水迁移污染饮用水、灌溉水、土壤、作物。

## 2.5 铬 Chromium (Cr)
（Ch.6 p4；Ch.23 p47；配对题 19）

- **来源**：**电镀 metal plating**、制革、颜料。
- **迁移/转化**：Cr(III) 是必需微量元素、毒性低、易沉淀；**Cr(VI)（CrO₄²⁻）剧毒、致癌、迁移性强**。治理需先还原 Cr(VI)→Cr(III) 再沉淀（见第一部分 A2）。
- **反应**：2CrO₄²⁻ + 3SO₂ + 4H⁺ → Cr₂(SO₄)₃ + H₂O。
- **效应**：Cr(VI) 致癌、铬疮（皮肤溃疡）。
- **归趋**：Cr(III) 在中性条件沉淀为 Cr(OH)₃ 而固定。

## 2.6 一氧化碳 CO
（Ch.10 p2–4）

- **来源**：化石燃料**不完全燃烧**（城市机动车尾气为主）；叶绿素降解、植物/海洋生物释放；也是 CH₄ 被 •OH 氧化的中间体。
- **迁移/转化**：大气停留期 36–110 天。
- **反应（归趋）**：主要被羟基自由基氧化 CO + •OH → CO₂ + H（再 O₂ + H + M → HOO• + M）；土壤微生物可代谢 CO（土壤是 CO 的汇 sink）。
- **效应**：与血红蛋白 (hemoglobin) 结合 O₂Hb + CO ⇌ COHb + O₂，使组织缺氧→昏迷→死亡。

## 2.7 二氧化硫 SO₂（重点）
（Ch.10 p5–13；Ch.8 p39）

- **来源**：含硫化石燃料燃烧（主要）；火山 H₂S/SO₂；海洋微生物释放的二甲基硫 (CH₃)₂S 是最大天然硫源。
- **迁移/转化**：H₂S 在大气中迅速被氧化为 SO₂。
- **反应**：被氧化成硫酸/硫酸盐——光化学条件下很快；液滴中、催化表面上也可发生：
  - HO• + SO₂ → HOSO₂•（继而生成 H₂SO₄）
  - SO₂ 与 O₃、H₂O₂ 在液滴中：SO₂(aq) + H₂O₂(aq) → H₂SO₄
  - 2SO₂ + O₂ → 2SO₃；SO₃ + H₂O → H₂SO₄
- **效应**：刺激呼吸道（哮喘）、刺激黏液分泌；植物叶片黄化 (chlorosis)；侵蚀石材（白云石）；是**酸雨**主因之一。
- **归趋**：以 H₂SO₄ 及硫酸盐气溶胶随干/湿沉降回到地表。

## 2.8 氮氧化物 NOₓ（NO、NO₂）（重点）
（Ch.10 p15–22；Ch.8 p43）

- **来源**：高温燃烧（尤其内燃机）N₂ + O₂ → 2NO；NO₂ 多为 NO 二次氧化生成；NO₃ 自由基为二次污染物（夜间重要）。N₂O 多来自微生物过程。
- **迁移/转化**：NO ⇌ NO₂ ⇌ HNO₃/硝酸盐/有机硝酸酯/PAN。
- **反应**：
  - NO₂ + hν (λ<398 nm) → NO + O（光化学烟雾引发反应）
  - O₃ + NO → NO₂ + O₂；HOO• + NO → NO₂ + •OH；ROO• + NO → NO₂ + RO•
  - NO₂ + •OH → HNO₃（去除/终止）；N₂O₅ + H₂O → 2HNO₃
- **效应**：NO₂ 损害肺组织（50–100 ppm 肺炎；500 ppm 致死）；生成腐蚀性 HNO₃ 与硝酸盐；参与**光化学烟雾**和**臭氧消耗**（NO + O₃ → NO₂ + O₂；NO₂ + O → NO + O₂，净 O₃ + O → 2O₂）。
- **归趋**：转化为 HNO₃/硝酸盐随降水洗脱。

## 2.9 氢氟酸 HF（简答题常考）
（Ch.10 p26–27；Ch.23 p48）

- **来源**：磷矿加工 Ca₅F(PO₄)₃ + 5H₂SO₄ + 10H₂O → 5(CaSO₄·2H₂O) + HF + 3H₃PO₄；萤石 + 硅酸盐：2CaF₂ + 3SiO₂ → 2CaSiO₃ + SiF₄。
- **迁移/转化**：气态 HF/F₂ 为稀有但极毒的大气污染物。
- **反应（特性）**：**能腐蚀玻璃** SiO₂ + 6HF → H₂SiF₆ + 2H₂O（其它常见无机酸不能腐蚀玻璃，这是 HF 的标志性反应）。
- **效应**：ppt 级蒸气即可致命；F⁻ 强烈结合体内 Ca²⁺/Mg²⁺，造成**深部灼伤、低钙血、骨损伤**，灼伤可能延迟出现且疼痛不明显，极危险。
- **急救（归趋于体内）**：用葡萄糖酸钙凝胶补 Ca²⁺ 把 F⁻ 固定为 CaF₂。

## 2.10 持久性有机污染物 POPs（重点，简答题常考"为何北极有 POPs"）
（Ch.6 p54；Ch.11 p3–4）

- **来源**：氯代烃类农药/工业品——多氯联苯 PCB、氯丹 chlordane、六氯苯 hexachlorobenzene、DDT、PFAS 等。
- **特征（A–E，Ch.11 p3）**：(A) 在环境中存留多年（难降解）；(B) 广泛分布全球；(C) 在脂肪组织富集，营养级越高浓度越高（生物放大）；(D) 对人和野生动物有毒；(E) 挥发性决定沉降地。
- **迁移/转化——"全球蒸馏/分馏 (global distillation & fractionation)"**：赤道/温带较高温使 POPs 挥发进入大气→随大气向高纬度/高海拔传输→在**寒冷的极地/高山冷凝沉降**。挥发性低者沉降在源附近，中等者沉积于中纬度，较高者蒸馏至极地。
- **效应**：致癌、内分泌干扰、生殖发育毒性。
- **归趋**：极地虽无本地排放源（源在数千英里之外），但通过"全球蒸馏"在极地累积——这就是**为什么相对原始的北极地区也能检出 POPs**（第21题标准答案）。

# 第三部分　重要名词概念详解（中英对照 + 章页 + 讲解）

> 这是配对题、单选题、简答题的"名词库"。每条都讲清"是什么 + 为什么/怎么用"，不是只给定义。

## 3.1 总论与五大圈层（Ch.1）

- **环境化学 Environmental Chemistry**（Ch.1 p34）：研究化学物种在地球系统中的**来源 (origin)、迁移 (transport)、反应 (reactions)、效应 (effects)、归趋 (fates)** 的化学分支。记住这五个词——它是所有"分析某污染物"题的答题框架。
- **五大圈层 Five Spheres**（Ch.1 p15）：水圈 Hydrosphere（水）、大气圈 Atmosphere（空气）、岩石圈/地圈 Geosphere（岩石、矿物、土壤）、生物圈 Biosphere（生物）、**人类圈 Anthrosphere**（人类制造与活动的环境）。能量与物质在五圈层间强烈交换。
- **两大流体 Two great fluids**（Ch.1 p17）：地表水（尤其海洋、河流）和大气——两大循环交换物质和能量的流体。
- **生物地球化学循环 Biogeochemical cycles**（Ch.1 p22–27）：C、N、P、S 等元素在五圈层间的循环。
  - 氮循环：大气大量 N₂ → 微生物/工业**固氮**为含氮化合物 → 植物营养 → **反硝化 (denitrification)** 释放回大气。
  - 磷循环：无明显大气环节，磷是核酸等生物分子必需元素，水中过量导致**富营养化**。
  - 硫循环：大气中 SO₂、硫酸盐气溶胶；细菌作用于硫化合物。
- **斯特藩–玻尔兹曼定律 Stefan–Boltzmann law**（Ch.1 p28）：E = σT⁴，黑体单位面积辐射功率与温度四次方成正比。
- **维恩位移定律 Wien's displacement law**（Ch.1 p31）：λ_peak·T = b（b=2.898×10⁻³ m·K），温度越高峰值波长越短。
- 光能与能量：E = hν = hc/λ；E(eV)=1240/λ(nm)（Ch.1 p29–30）。

## 3.2 水化学核心名词（Ch.2，⭐高频）

- **氢键 Hydrogen bond**（Ch.2 p7–8）：水分子间通过 O–H···O 形成的弱键；赋予水高介电常数、高表面张力、高比热、高熔化/汽化热，以及 4 ℃ 密度最大、冰浮于水等"反常"性质。
- **配位键 Coordination bond**（Ch.2 p28–29）：配体 (ligand) 的孤对电子充入金属空轨道形成的键（路易斯酸碱反应）。金属=路易斯酸（受电子），配体=路易斯碱（给电子）。
- **自养/异养 Autotrophic / Heterotrophic**（Ch.2 p12）：自养生物用太阳能/化学能、由 CO₂ 等无机物合成生物质（如光合藻类=生产者 producer）；异养生物代谢有机物（如分解者 decomposer，细菌真菌）。
- **富营养化 Eutrophication**（Ch.2 p12；Ch.6 p15）：希腊语"营养充足"。水体营养（尤其 N、P）过剩 → 生物质（藻类）大量繁殖 → 死亡分解 → 耗尽溶解氧、产生臭味。**磷常为限制性营养元素 (limiting nutrient)**。
- **湖泊分层 Lake stratification**（Ch.2 p13）：上层 **变温层 Epilimnion**（溶解氧高、物种氧化态）、中间 **温跃层 Thermocline**、下层 **均温层/滞水层 Hypolimnion**（溶解氧低、物种还原态、与沉积物交换）。
- **溶解氧 DO (Dissolved Oxygen)**（Ch.2 p13；Ch.6 p17）：水中溶解的氧。
- **生化需氧量 BOD (Biochemical Oxygen Demand)**（Ch.6 p18，⭐简答常考）：水中**可生物降解有机物**被微生物氧化所消耗的氧量；通常以 5 天测定（BOD₅）。是衡量有机污染、水质好坏的关键指标。
- **化学需氧量 COD (Chemical Oxygen Demand)**（Ch.6 p18）：用化学氧化剂测得的可被氧化物质的耗氧量（包含不可生物降解部分）。
- **总有机碳 TOC (Total Organic Carbon)**（Ch.6 p20）：仪器测定的有机碳总量，含不可生物降解有机物，常替代 BOD。
- **亨利定律 Henry's law**（Ch.2 p15）：恒温下气体在液体中的溶解度正比于其分压。[X(aq)] = K_H·p_X。温度升高，气体溶解度下降。
- **酸度 Acidity / 碱度 Alkalinity**（Ch.2 p21, 26，⭐高频）：
  - **酸度 Acidity**=中和 OH⁻ 的能力；**碱度 Alkalinity**=中和 H⁺ 的能力。
  - 注意区分：**pH 是强度因子 (intensity factor)，碱度是容量因子 (capacity factor)**。
  - 总碱度公式：[alk] = [HCO₃⁻] + 2[CO₃²⁻] + [OH⁻] − [H⁺]（CO₃²⁻ 系数为 2，因每个可中和 2 个 H⁺）。
  - 酚酞碱度 (pH 8.3)、甲基橙/总碱度 (pH 4.3)（戴树桂 P154–157）。
- **配位/络合 Complexation（络合）**（Ch.2 p30）：单个配体以**一个**配位键与金属结合。
- **螯合 Chelation（螯合）**（Ch.2 p30）：一个配体以**多个**配位键与金属结合（多齿配体）。
- **单齿/多齿配体 Monodentate / Polydentate ligand**（Ch.2 p31–32）：配体含 1 个/≥2 个给电子原子。如 NH₃、CN⁻ 单齿；乙二胺 (en)、草酸根、EDTA 多齿。
- **配位数 Coordination number (CN) / 配位球 Coordination sphere**（Ch.2 p33）：中心金属周围给电子原子的数目 / 金属周围原子构成的壳层。
- **稳定常数/形成常数 Formation constant**（Ch.2 p39）：络合物稳定性的量度；分**逐级形成常数**（配体逐个加上）和**总形成常数**（一次加多个，β=K₁K₂…）。
- **腐殖质 Humic substances**（Ch.2 p55）：植物生物质降解后残留的抗降解物。强碱提取、酸化后：不可提取残渣=**胡敏素 humin**；酸化沉淀=**胡敏酸/腐殖酸 humic acid**；仍溶于酸液=**富里酸 fulvic acid**。能螯合金属、影响水色（与铁结合成 gelbstoffe）、是氯化消毒生成三卤甲烷的前体。
- **分配系数 Distribution coefficient K_d**（Ch.4 p9）：K_d = C_s/C_w，固相与液相平衡浓度之比，衡量物质在固/水间分配。

## 3.3 氧化还原与 pE（Ch.3，⭐高频）

- **氧化数 Oxidation number**（Ch.3 p2）：氧化=氧化数升高，还原=氧化数降低。
- **半反应 Half-reaction**（Ch.3 p7）：把氧化还原拆成氧化半反应和还原半反应。
- **电子活度与 pE Electron activity & pE**（Ch.3 p15）：pE = −log(a_e⁻)，类比于 pH = −log(a_H⁺)。**pE 高=氧化性强（如氯化水），pE 低=还原性强（如污水厌氧消化池）**。游离电子/H⁺ 不单独存在，总与溶剂/溶质结合。
- **标准电极电位 / 电极电位 E°、E**（Ch.3 p13–14）：标准氢电极 SHE 规定 E°=0.00 V。
- **能斯特方程 Nernst equation**（Ch.3 p17–19）：E = E° − (RT/nF)·lnQ；转换得 pE = pE° + (1/n)·log(Q_ox/Q_red)。
- **pE 与吉布斯自由能 / 平衡常数**（Ch.3 p25–28）：ΔG° = −2.303nRT(pE°)；redox 反应平衡常数 **log K = n·pE°**；写成"单电子摩尔"(n=1) 时 log K = pE°。
- **单电子摩尔 One electron-mole**（Ch.3 p27）：转移恰好 1 mol 电子写出的反应，便于比较不同反应的自由能。
- **pE–pH 图 pE–pH diagram**（Ch.3 p37–48，⭐论述重点）：表示各物种稳定区与边界线。**水的稳定区上下界**：氧化上限 pE = 20.75 − pH（O₂/H₂O）；还原下限 pE = −pH（H₂/H₂O）。（详见第四部分推导）
- **自由基 Free radical**（Ch.3 p49；Ch.8 p17）：含未成对电子的高活性物种，用 • 表示，如超氧离子 O₂•⁻、•OH。
- **Fenton 反应**（Ch.3 p50）：Fe²⁺ + H₂O₂ → Fe³⁺ + OH⁻ + •OH，生成强氧化性 •OH 降解有机物。
- **光催化 Photocatalysis**（Ch.3 p51）：TiO₂ 等半导体光激发产生 e⁻/h⁺ 引发表面氧化还原。
- **腐蚀 Corrosion**（Ch.3 p53）：金属表面形成电化学电池：阳极 M → M²⁺ + 2e⁻；阴极如 O₂ + 2H₂O + 4e⁻ → 4OH⁻。

## 3.4 相互作用与沉积物（Ch.4，高频）

- **沉积物 Sediment**（Ch.4 p6）：水体底部细分散物质（黏土、粉砂、砂、有机质、生物、污染物的混合）。
- **黑碳 Black carbon**（Ch.4 p9）：化石燃料/生物质燃烧残留的小碳粒，强烈吸附有机污染物。
- **胶体颗粒 Colloidal particles**（Ch.4 p16）：1 nm–1 μm；丁达尔效应 (Tyndall effect)、高比表面积、高表面电荷密度。分亲水 (hydrophilic)、疏水 (hydrophobic)、缔合 (association) 胶体。
- **双电层 Electrical double layer**（Ch.4 p17）：带电胶粒表面及周围反离子构成。
- **零电荷点 Zero point of charge (ZPC)**（Ch.4 p20）：表面正负电荷位点数相等时的 pH。
- **胶束 Micelle**（Ch.4 p18）：表面活性剂/肥皂分子聚集成的球形结构，可包裹油污。
- **混凝 Coagulation / 絮凝 Flocculation**（Ch.4 p24）：见第一部分 A8。
- **阳离子交换容量 CEC (Cation Exchange Capacity)**（Ch.4 p28；Ch.14 p13，⭐简答常考）：沉积物/土壤/黏土吸附阳离子的能力，以每 100 g 干样交换的毫克当量数 (meq/100 g) 表示。**测定**：用铵盐使所有交换位被 NH₄⁺ 占据 → 用 NaCl 置换 NH₄⁺ → 测被置换的 NH₄⁺ 量。黏土的负电荷来自 **Al(III) 取代 Si(IV)** 等"同晶取代"。**使 CEC 降低的情形**（简答）：黏土/有机质（腐殖质）含量减少、pH 降低（可变电荷位点质子化、负电荷减少）、矿物风化使层状硅酸盐结构破坏等（详见第四部分）。
- **可交换阳离子程度 ECS (Exchangeable Cation Status)**（Ch.4 p29）：单位沉积物上各特定离子的吸附量。
- **生物可利用性 Bioavailability**（Ch.4 p35）：物质被生物吸收进体内的程度。
- **孔隙水/间隙水 Interstitial / Pore water**（Ch.4 p36）：沉积物孔隙中的水，几乎无 O₂，反映沉积物的化学/生化状况。

## 3.5 水生微生物（Ch.5，高频）

- **微生物 Microorganisms**（Ch.5 p2）：细菌 Bacteria、原生动物 Protozoa、真菌 Fungi、藻类 Algae——水土化学过程的活催化剂。
- **藻类学 Phycology**（Ch.5 p7）：研究藻类的学科。
- **地衣 Lichen**（Ch.5 p9，单选考过）：藻类与真菌的**共生 (symbiotic)** 体，参与岩石风化。
- **蓝细菌 Cyanobacteria**（Ch.5 p3）：早期产生大气全部 O₂ 的生物。
- **微生物分类（按能源/碳源）**：化能异养 Chemoheterotrophs、光能异养 Photoheterotrophs、化能自养 Chemoautotrophs、光能自养 Photoautotrophs（Ch.5 p6）。
- **生长曲线 Population curve**（Ch.5 p16）：延滞期 Lag → 对数期 Log（dN/dt=kN）→ 稳定期 Stationary → 衰亡期 Death。
- **代谢 Metabolism**（Ch.5 p17）：合成代谢 Anabolism（建大分子）、分解代谢 Catabolism（分解大分子）。有氧呼吸以 O₂ 为终端电子受体，厌氧以 SO₄²⁻、NO₃⁻、HCO₃⁻ 等为受体。
- **关键微生物转化反应**（Ch.5 p20–33，必记）：
  - **硝化 Nitrification**：NH₄⁺ + 2O₂ → NO₃⁻ + 2H⁺ + H₂O（氨/铵氧化为亚硝酸/硝酸，单选第17题答案）。
  - **反硝化 Denitrification**：4NO₃⁻ + 5{CH₂O} + 4H⁺ → 2N₂↑ + 5CO₂ + 7H₂O。
  - **硝酸盐还原 Nitrate reduction**：2NO₃⁻ + {CH₂O} → 2NO₂⁻ + H₂O + CO₂。
  - **固氮 Nitrogen fixation**：3{CH₂O} + 2N₂ + 3H₂O + 4H⁺ → 3CO₂ + 4NH₄⁺（根瘤菌 *Rhizobium*）。
  - **发酵/甲烷化 Fermentation/Methanogenesis**：2{CH₂O} → CO₂ + CH₄。
  - **硫酸盐还原 Sulfate reduction**：SO₄²⁻ + 2{CH₂O} + 2H⁺ → H₂S + 2CO₂ + 2H₂O（脱硫弧菌 *Desulfovibrio*）。
  - **β-氧化 Beta-oxidation**（单选第10题）：烃链每次脱去 2 个碳，如 CH₃(CH₂)₃CO₂H + 3O₂ → CH₃CH₂CO₂H + 2CO₂ + 2H₂O；季碳支链抑制降解。
  - **水解 Hydrolysis**：如马拉硫磷的酯键水解。
  - **脱卤 Dehalogenation / 脱烷基 Dealkylation / 环氧化 Epoxidation / 羟基化 Hydroxylation**。
  - **共代谢 Cometabolism**（Ch.5 p33）：微生物在代谢其它底物时顺带转化某污染物。
- **生物降解 Biodegradation**（Ch.5 p26）：农药、石油等有机物被微生物分解。
- **酸性矿山废水 Acid mine water**（Ch.5 p35）：见第一部分 A7（FeS₂ 氧化产酸）。

## 3.6 水污染物（Ch.6，⭐高频）

- **水污染生物标志物 Biomarkers of water pollution**（Ch.6 p3）：能指示污染的生物（如食物链顶端的鱼鹰 osprey、累积污染物的鱼脂）。
- **重金属 Heavy metals / 类金属 Metalloids**（Ch.6 p4）：多为亲硫元素；类金属如 As、Se、Sb。
- **有机金属 Organically bound metals**（Ch.6 p5）：金属–碳键（如四乙基铅、有机锡）。σ 键=轨道端对端重叠；π 键=侧对侧重叠。
- **氰化物 Cyanide (HCN, CN⁻)**（Ch.6 p12）：弱酸、剧毒。
- **氧垂曲线 Oxygen sag curve**（Ch.6 p19，⭐简答）：可氧化污染物排入河流后，沿程溶解氧先下降（分解区/腐败区）后恢复（恢复区）的曲线，反映自净过程。
- **生物富集系数 BCF (Bioconcentration factor)**（Ch.6 p21）：BCF = 生物体内浓度 / 水中浓度。
- **生物积累系数 BAF (Bioaccumulation factor)**（Ch.6 p21）：同 BCF，但考虑生物及其食物长期同样暴露。
- **生物放大 Biomagnification**：污染物沿食物链营养级升高而浓度递增（鱼不可食用现象的本质，第27题）。
- **多氯联苯 PCBs**（Ch.6 p48）：化学/热/生物稳定性极高，曾用于电气设备，高度持久，现已禁用。
- **持久性有机污染物 POPs**（Ch.6 p54；见 2.10）。
- **农药分类**（Ch.6 p31）：杀虫剂 insecticide、除草剂 herbicide、杀菌剂 fungicide 等。有机氯（DDT，持久）、有机磷（乙酰胆碱酯酶抑制剂）、氨基甲酸酯 (carbamate)、拟除虫菊酯 (pyrethroid)、新烟碱 (neonicotinoid)。
- **放射性核素 Radionuclides**（Ch.6 p55）：产生 α、β、γ 电离辐射。**半衰期 Half-life**：t½ = 0.693/λ，一级动力学 A = A₀e^(−λt)。健康关注：⁹⁰Sr（替代骨中钙）、¹³¹I（影响甲状腺）、¹³⁷Cs（替代钠）。
- **三种辐射特征**（Ch.6 p56）：α(⁴₂He, +2, 质量数−4、原子序数−2)；β(⁰₋₁e, −1, 原子序数+1)；γ(0, 质量与原子序数都不变)。

## 3.7 大气化学核心名词（Ch.8–13，⭐高频）

- **大气组成 Atmosphere composition**（Ch.8 p2）：干空气 78.1% N₂、21.0% O₂、0.9% Ar、~0.04% CO₂，及微量稀有气体和痕量气体。
- **大气分层 Stratification**（Ch.8 p5–8，必记顺序与温度变化）：
  - **对流层 Troposphere**（地表~10–16 km，−56 ℃）：天气、光化学反应、水汽循环；温度随高度下降。
  - **平流层 Stratosphere**（~50 km，升至约 −2 ℃）：**臭氧层**所在，温度随高度上升（O₃ 吸收 UV 放热）。
  - **中间层 Mesosphere**（~85 km，−92 ℃）：温度随高度下降。
  - **热层 Thermosphere**（>500 km，可达 1200 ℃）：高能 UV 电离。
  - 气压随高度按 P_h = P₀·e^(−Mgh/RT) 下降。
- **太阳常数 Solar constant**（Ch.8 p10）：大气顶垂直入射太阳辐射 ~1340 W/m²。
- **光化学反应 Photochemical reaction**（Ch.8 p15）：分子吸收光子（多在 UV 区）发生的反应。能量 E=hν=hc/λ。
- **激发态 Excited state**（Ch.8 p16）：被光电子激发的物种，用 * 表示（如 O₃ + hν → O* + O₂）。
- **第三体 Third body (M)**（Ch.8 p17）：吸收新生/激发分子多余能量、防其解离的能量吸收体（通常 N₂、O₂），如 O* + O₂ + M → O₃ + M。
- **羟基自由基 Hydroxyl radical (•OH)**（Ch.8 p33，⭐最重要的大气自由基）：控制大气中痕量气体浓度（清除 CO、CH₄ 等）。生成：O₃ + hν(λ<315 nm) → O* + O₂；O* + H₂O → 2•OH。
- **臭氧形成 Ozone formation**（Ch.8 p8, 41）：平流层 O₂ + hν(λ<242 nm) → 2O；O + O₂ + M → O₃ + M。O₃ 吸收 220–330 nm UV 保护地表。
- **CFCs（氟氯烃 chlorofluorocarbons）**（Ch.8 p46；Ch.13 p57–61，⭐臭氧层破坏，简答第28题）：极稳定，升入平流层被 UV 分解产生 Cl•，催化破坏臭氧（见第四部分机理）。
- **温室气体 Greenhouse gases**（Ch.8 p45；Ch.13 p44）：CO₂、CH₄、N₂O、HFCs、PFCs、SF₆、NF₃（京都议定书控制对象）。
- **全球变暖潜势 GWP (Global Warming Potential)**（Ch.8 p13）：各温室气体相对 CO₂ 捕获热量的能力（CO₂=1，CH₄≈21–25，N₂O≈310，SF₆≈23900）。

## 3.8 大气颗粒物（Ch.9，高频）

- **气溶胶 Aerosol**（Ch.9 p4）：< 100 μm 的胶体级大气颗粒。**凝结气溶胶 condensation aerosol**（由气/蒸气生成，较小 <1 μm，更易吸入更有害）；**分散气溶胶 dispersion aerosol**（研磨/分散生成，较大 >1 μm）。
- **雾 Fog / 霾 Haze / 薄雾 Mist / 烟 Smoke**（Ch.9 p4）：雾=水滴多；霾=颗粒致能见度下降；薄雾=液滴；烟=含碳燃料不完全燃烧产物。
- **一次颗粒 / 二次颗粒 Primary / Secondary particles**（Ch.9 p2–3）：直接排放（沙、海盐、花粉）/由气体在大气中转化生成（H₂SO₄、铵盐、光化学烟雾）。
- **PM2.5**（Ch.9 p20）：< 2.5 μm 可吸入颗粒，深入肺部，健康危害大。
- **多环芳烃 PAH (Polycyclic Aromatic Hydrocarbon)**（Ch.9 p12）：稠合芳环分子（如苯并[a]芘 benzo[a]pyrene），由**高温热解 pyrolysis** 与**高温合成 pyrosynthesis** 生成；可被代谢为致癌物。生成倾向：芳香>环烯>烯烃>烷烃。
- **飞灰 Fly ash**（Ch.9 p17）：高灰分化石燃料燃烧产生的氧化物等。
- **石棉 Asbestos**（Ch.9 p17）：纤维状硅酸盐矿物，吸入致癌（石棉肺、间皮瘤）。
- **六大优先控制污染物 6 Priority Pollutants（US EPA）**（Ch.9 p18）：SO₂、CO、O₃、NO₂、大气颗粒物 (PM)、Pb。

## 3.9 光化学烟雾与全球大气（Ch.11–13，⭐论述重点）

- **光化学烟雾 Photochemical smog**（Ch.12，⭐论述第29题=洛杉矶烟雾）：氧化型烟雾，特征为眼刺激、低能见度、含 O₃ 等氧化剂。**三要素**：① 紫外光 UV；② 碳氢化合物 hydrocarbons；③ 氮氧化物 NOₓ。
- **过氧乙酰硝酸酯 PAN (Peroxyacetyl nitrate)**（Ch.11 p28；Ch.12 p16）：光化学烟雾标志性二次污染物，强烈刺激眼和呼吸道、伤害植物。结构 CH₃C(O)OONO₂。
- **光化学氧化剂 Photochemical oxidant**（Ch.12 p16）：主要是 O₃，还有 H₂O₂、过氧化物、有机氢过氧化物、PAN。
- **一次/二次污染物 Primary / Secondary pollutant**（Ch.11 p1）：直接排放/由大气反应生成（光化学烟雾、O₃、HNO₃、硫酸盐均为二次）。
- **干/湿沉降 Dry / Wet deposition**（Ch.11 p2）：干沉降=颗粒/气体直接沉降；湿沉降=溶于降水被洗脱。
- **二次有机气溶胶 SOA (Secondary Organic Aerosol)**（Ch.11 p6）：萜烯等挥发性有机物氧化生成的细颗粒。
- **全球变暖 Global warming**（Ch.13 p43）：CO₂、H₂O 汽、CH₄ 等重新吸收地表向外的红外辐射（最大强度~10 μm）造成增温。
- **酸雨 Acid rain**（Ch.10 p23；Ch.13 p54，⭐高频）：比 CO₂ 强的酸在降水中——主要 H₂SO₄（来自 SO₂）、HNO₃（来自 NOₓ）、HCl。**酸沉降 acid deposition** 是更广义概念（含酸性气体 SO₂、酸性盐 NH₄HSO₄）。危害：直接植物毒性、水体/土壤酸化、间接释放土壤中 Al³⁺ 毒害、腐蚀金属与石材（2H⁺ + CaCO₃ → Ca²⁺ + CO₂ + H₂O）。
- **平流层臭氧破坏 Stratospheric ozone destruction**（Ch.13 p57–61，⭐简答第28题）：CFC 释放 Cl• 催化破坏 O₃；**南极臭氧洞 (Antarctic ozone hole, 1985 发现)**；**蒙特利尔议定书 (Montreal Protocol, 1986)** 禁产 CFC。
- **大气棕色云 Atmospheric brown clouds / 城市气溶胶 Urban aerosol / 黄沙 Yellow dust**（Ch.13 p62–65）：低效燃烧、光化学烟雾、风沙形成。
- **核冬天 Nuclear winter**（Ch.13 p66）：核战产生的烟尘升入平流层，反射阳光致剧烈降温。

## 3.10 地圈与土壤（Ch.14–15，一般）

- **矿物 Mineral / 晶体结构 Crystal structure**（Ch.14 p4）：矿物=确定化学组成 + 特定晶体结构。地壳最丰富为硅酸盐。

- **土壤 Soil / 土壤学 Pedology**（Ch.15 p1, 3）：岩石风化最终产物（矿物+有机质+水）；研究土壤的学科。

## 4.1 水分子结构与性质（Ch.2 p6–11）

水是**极性、氢键缔合**分子：O–H 键约 0.96–1.0 Å，H–O–H 角约 104.5°，氧上两对孤对电子使分子呈角形。
**异常性质来源于极性 + 氢键**：高介电常数（溶解离子能力强）、高表面张力、高比热/熔化热/汽化热（稳定温度）、4 ℃ 密度最大（冰浮于水，分层水体垂直循环受限）、对可见光和长波 UV 透明（允许藻类光合）。
> 单选常考"河水中 H–O 键长" → 约 **0.91–1.0 Å**（1 Å=0.1 nm），即第15题选 0.91 Å。

## 4.2 主要水化学过程（Ch.2 p14；Ch.1 p36–37，配对常考）

| 过程 | 例子 |
|---|---|
| 酸碱 Acid-base | CO₂ + H₂O ⇌ H⁺ + HCO₃⁻ |
| 溶解/沉淀 Dissolution/Precipitation | CaCO₃(s) + CO₂ + H₂O ⇌ Ca²⁺ + 2HCO₃⁻ |
| 氧化还原 Redox | 2{CH₂O} + SO₄²⁻ + 2H⁺ → H₂S(g) + 2H₂O + 2CO₂ |
| 络合/螯合 Complexation | Fe²⁺ + {FA} → Fe{FA}(gelbstoff) + 2H⁺ |
| 光合 Photosynthesis | 2HCO₃⁻ + hν → {CH₂O} + O₂ + CO₃²⁻ |
| 气体交换 Gas exchange | O₂、CO₂ 在水气间交换 |

配对题（第19题类型）要会对应：
- 酸碱中和 Acid/base neutralization：Ca(OH)₂ + H₂SO₄ → CaSO₄ + 2H₂O
- 化学沉淀 Chemical precipitation：Cd²⁺ + HS⁻ → CdS(s) + H⁺
- 氧化还原 Redox：2CrO₄²⁻ + 3SO₂ + 4H⁺ → Cr₂(SO₄)₃ + H₂O
- 阳离子交换 Cation exchange：2H⁺-{交换剂} + Cd²⁺ → Cd²⁺-{交换剂}₂ + 2H⁺

## 4.3 亨利定律与气体溶解度（Ch.2 p15–20，计算高频）

K_H = C_aq/p（单位常用 mol·L⁻¹·atm⁻¹）。
**例题（讲义原题）**：25 ℃，水蒸气分压 0.0313 atm，干空气含 O₂ 20.95%，K_H(O₂)=1.3×10⁻³ mol·L⁻¹·atm⁻¹。求水中 [O₂]。
解：p(O₂)=(1.0000−0.0313)×20.95%=0.2029 atm；[O₂]=1.3×10⁻³×0.2029=2.6×10⁻⁴ mol/L=2.6×10⁻⁴×32 g/L≈**8.32 mg/L**。
> 8.32 mg O₂ 只能氧化约 7.8 mg 生物质 {CH₂O}（{CH₂O} + O₂ → CO₂ + H₂O）——说明天然水溶解氧有限、易被有机物耗尽（BOD 概念由此而来）。

**温度依赖（Clausius-Clapeyron）**：log(C₂/C₁) = (ΔH/2.303R)·(1/T₁ − 1/T₂)。气体溶解度随温度升高而下降。

## 4.4 酸度、碱度与计算（Ch.2 p21, 26）

- 酸度=中和 OH⁻ 能力；碱度=中和 H⁺ 能力。
- **总碱度 [alk] = [HCO₃⁻] + 2[CO₃²⁻] + [OH⁻] − [H⁺]**。
- 强度因子 pH ≠ 容量因子碱度：两瓶水可能 pH 相同但碱度差很多。
- **大气 CO₂ 升高对天然水碱度的影响（简答第26题）**：CO₂ 增加使 [H⁺]、[HCO₃⁻] 升高，但**碱度 [alk] 基本不变**——因为溶解 CO₂ 本身既不引入也不消耗净的质子受体（CO₂ 是中性分子，溶解后 CO₂ + H₂O ⇌ H⁺ + HCO₃⁻ 同时产生等量 H⁺ 和 HCO₃⁻，对 [alk]=[HCO₃⁻]+2[CO₃²⁻]+[OH⁻]−[H⁺] 的净贡献为零）。只是 **pH 下降**（水酸化）。但若体系中有 CaCO₃(s) 可溶解，则 CO₂↑ 会溶解更多碳酸盐、使碱度升高（开放体系/有矿物时）。考试按"无固相时碱度不变、pH 下降"作答即可，并说明有 CaCO₃ 时可升高。

## 4.5 CO₂–碳酸盐平衡与分布分数（Ch.2 p22–25，计算高频）

水中无机碳三态：CO₂(aq)、HCO₃⁻、CO₃²⁻。
- K_a1：CO₂(aq) + H₂O ⇌ H⁺ + HCO₃⁻，K_a1=4.45×10⁻⁷，pK_a1=6.35
- K_a2：HCO₃⁻ ⇌ H⁺ + CO₃²⁻，K_a2=4.69×10⁻¹¹，pK_a2=10.33

**分布分数 α**（α_CO₂ + α_HCO₃ + α_CO₃ = 1）：
- α_CO₂ = [H⁺]² / ([H⁺]² + K_a1[H⁺] + K_a1K_a2)
- α_HCO₃ = K_a1[H⁺] / (同分母)
- α_CO₃ = K_a1K_a2 / (同分母)
规律：pH ≪ pK_a1 时 CO₂ 占优；pH=pK_a1 时 α_CO₂=α_HCO₃；pH≈½(pK_a1+pK_a2)=8.34 时 HCO₃⁻ 最大(0.98)；pH ≫ pK_a2 时 CO₃²⁻ 占优。

**例题1（雨水 pH，讲义原题）**：400 ppm CO₂ 下 [CO₂(aq)]=1.309×10⁻⁵ mol/L。纯净雨水 pH？
解：解离产生 [H⁺]=[HCO₃⁻]，K_a1=[H⁺]²/[CO₂]→[H⁺]=√(K_a1·[CO₂])=√(4.45×10⁻⁷×1.309×10⁻⁵)=2.41×10⁻⁶，**pH=5.61**。说明清洁雨水因 CO₂ 本就微酸（约 5.6）。

**例题2（与 CaCO₃ 平衡的水，讲义原题）**：400 ppm CO₂ 且与 CaCO₃(s) 平衡。
用 CaCO₃ + CO₂ + H₂O ⇌ Ca²⁺ + 2HCO₃⁻，结合 K_a1、K_a2、K_sp(CaCO₃)=4.47×10⁻⁹，可解得 [Ca²⁺]=5.18×10⁻⁴、[HCO₃⁻]=1.04×10⁻³、**pH≈8.25**。说明含石灰岩的天然水偏弱碱性。

## 4.6 配位/螯合与 pH 依赖（Ch.2 p36–52，理解为主，可考计算）

- 金属在水中以**水合离子**存在，高价水合离子失 H⁺ 显酸性（见 4.7）。
- 螯合剂（NTA、EDTA、腐殖质）增大重金属溶解度与迁移性，是污染隐患。
- **EDTA-Cu 例题（讲义）**：pH 11、过量 EDTA(Y⁴⁻)、K_f(CuY²⁻)=6.3×10¹⁸。络合比 [CuY²⁻]/[Cu²⁺]=K_f·[Y⁴⁻]=6.3×10¹⁸×5.4×10⁻⁴≈3.3×10¹⁵（极大）→ 铜几乎全以 CuY²⁻ 存在，游离 [Cu²⁺]≈2.3×10⁻²⁰ M（极低）。
- **NTA 溶解 Pb 例题（讲义）**：pH 8 时 Pb(OH)₂(s) + HT²⁻ ⇌ PbT⁻ + OH⁻ + H₂O，K=K_sp·K_f/(K_a3·K_w)=2.07×10⁻⁵；[PbT⁻]/[HT²⁻]=K/[OH⁻]=2.07×10⁻⁵/1.0×10⁻⁶=20.7 → NTA 几乎全把 Pb 溶解为 PbT⁻。
- **Ca²⁺ 竞争的影响（讲义）**：存在 1.0×10⁻³ M Ca²⁺ 时，约 1/3 NTA 与 Pb 结合、2/3 与 Ca 结合 → 过量 Ca²⁺ 显著抑制 NTA 溶解铅。

## 4.7 水合金属离子的酸性——解释"Al 离子产生中等酸性"（Ch.2 p21, 27；简答第24题）

**陈述**：铝离子的溶解会产生中等酸性环境。
**化学方程式与解释**：高价金属阳离子在水中以水合形式存在，其配位水分子的 O–H 因金属正电荷极化而易解离出 H⁺（**水解 hydrolysis**）：
$$\text{Al}(\text{H}_2\text{O})_6^{3+} \rightleftharpoons \text{Al}(\text{H}_2\text{O})_5(\text{OH})^{2+} + \text{H}^+$$
进一步：Al(H₂O)₅(OH)²⁺ ⇌ Al(H₂O)₄(OH)₂⁺ + H⁺ … 直至 Al(OH)₃(s)。
+3 价水合离子（Al³⁺、Fe³⁺）酸性较强，故 Al³⁺ 溶解使水显酸性。这也解释了**酸雨/酸性土壤中 Al³⁺ 被活化、产生间接植物毒性**（Ch.13 p55；Ch.15 p10）。简写：Al³⁺ + 3H₂O ⇌ Al(OH)₃ + 3H⁺。

## 4.8 pE、能斯特方程与平衡（Ch.3 p15–28）

- pE = pE° + (1/n)·log(Q_ox/Q_red)；pE° = E°/0.0591（25 ℃）。
- redox 平衡：**log K = n·pE°**（单电子摩尔时 log K = pE°）。
- 例：Fe³⁺ + e⁻ ⇌ Fe²⁺，E°=0.77 V，pE°=13.2；pE = 13.2 + log([Fe³⁺]/[Fe²⁺])。Fe³⁺ 越多 pE 越高。
- **自然水 pE（讲义例）**：pH 7、与大气 O₂(0.21 atm) 平衡：¼O₂ + H⁺ + e⁻ ⇌ ½H₂O，pE=20.75 + log(p_O₂^¼·[H⁺])=**13.58**（氧化性氧化水 oxic water）。厌氧产甲烷水：pH 7、p(CH₄)=p(CO₂)，pE≈−4.13（强还原），对应 p(O₂) 低至 ~3×10⁻⁷² atm。

## 4.9 ⭐铁的 pE–pH 图：完整构建与讨论（Ch.3 p37–48；论述第30题）

**已知数据**：
- 水氧化上限：¼O₂ + H⁺ + e⁻ ⇌ ½H₂O，pE°=+20.75
- 水还原下限：H⁺ + e⁻ ⇌ ½H₂，pE°=0
- Fe³⁺ + e⁻ ⇌ Fe²⁺，pE°=+13.2
- Fe(OH)₃(s) + 3H⁺ ⇌ Fe³⁺ + 3H₂O，K₁=[Fe³⁺]/[H⁺]³=9.1×10³
- Fe(OH)₂(s) + 2H⁺ ⇌ Fe²⁺ + 2H₂O，K₂=[Fe²⁺]/[H⁺]²=8.0×10¹²
- 水中铁最大浓度取 [Fe]=1.0×10⁻⁵ M

**逐条推导边界线**：

**① 水的稳定区（上下界）**
- 氧化上限：pE = pE° + log(p_O₂^¼·[H⁺]) ，取 p_O₂=1 atm → **pE = 20.75 − pH**
- 还原下限：pE = pE° + log[H⁺]（p_H₂=1）→ **pE = −pH**
- 铁的所有边界都应落在这两条线之间。

**② Fe³⁺ / Fe²⁺ 边界（水平线）**
pE = 13.2 + log([Fe³⁺]/[Fe²⁺])，两者相等时 → **pE = 13.2**（适用于 Fe³⁺ 尚未沉淀的低 pH 区）。

**③ Fe³⁺ / Fe(OH)₃ 边界（竖直线，高 pE 区）**
由 K₁=[Fe³⁺]/[H⁺]³，令 [Fe³⁺]=1.0×10⁻⁵：
[H⁺]³ = 1.0×10⁻⁵ / 9.1×10³ = 1.10×10⁻⁹ → [H⁺]=1.03×10⁻³ → **pH = 2.99（≈3.0）**。

**④ Fe²⁺ / Fe(OH)₂ 边界（竖直线，低 pE 区）**
由 K₂=[Fe²⁺]/[H⁺]²，令 [Fe²⁺]=1.0×10⁻⁵：
[H⁺]² = 1.0×10⁻⁵ / 8.0×10¹² = 1.25×10⁻¹⁸ → [H⁺]=1.12×10⁻⁹ → **pH = 8.95**。

**⑤ Fe²⁺ / Fe(OH)₃ 边界（斜线，pE 随 pH 下降）**
反应 Fe(OH)₃(s) + 3H⁺ + e⁻ ⇌ Fe²⁺ + 3H₂O：
pE = 13.2 + log([Fe³⁺]/[Fe²⁺])，代入 [Fe³⁺]=K₁[H⁺]³、[Fe²⁺]=1.0×10⁻⁵：
pE = 13.2 + log K₁ + 3log[H⁺] − log(10⁻⁵) = 13.2 + 3.96 − 3pH + 5 → **pE = 22.2 − 3pH**。

**⑥ Fe(OH)₂ / Fe(OH)₃ 边界（斜线，高 pH 区）**
净反应 Fe(OH)₃(s) + H⁺ + e⁻ ⇌ Fe(OH)₂(s) + H₂O：
pE = 13.2 + log([Fe³⁺]/[Fe²⁺])，代入 [Fe³⁺]=K₁[H⁺]³、[Fe²⁺]=K₂[H⁺]²：
pE = 13.2 + log(K₁/K₂) + log[H⁺] = 13.2 + log(9.1×10³/8.0×10¹²) − pH = 13.2 − 8.94 − pH → **pE = 4.3 − pH**。

**边界汇总**：

| 边界 | 方程 |
|---|---|
| O₂ / H₂O（上界） | pE = 20.75 − pH |
| H₂ / H₂O（下界） | pE = −pH |
| Fe³⁺ / Fe²⁺ | pE = 13.2 |
| Fe³⁺ / Fe(OH)₃ | pH = 2.99 |
| Fe²⁺ / Fe(OH)₂ | pH = 8.95 |
| Fe²⁺ / Fe(OH)₃ | pE = 22.2 − 3pH |
| Fe(OH)₂ / Fe(OH)₃ | pE = 4.3 − pH |

**图的形貌（文字描述）**：横轴 pH(0–14)、纵轴 pE(−15~20)。左上小区为 **Fe³⁺**（高 pE、低 pH，pH<2.99）；左中至中部大区为 **Fe²⁺**（pH 2.99~8.95、较低 pE）；右上大片为 **Fe(OH)₃(s)**；右下小区为 **Fe(OH)₂(s)**。各区用上面边界线分隔，整体夹在 pE=20.75−pH 与 pE=−pH 两线之间。

**讨论（论述要点，Ch.3 p45–48）**：
1. **Fe³⁺** 仅在**高 pE、低 pH**的小区稳定——如与大气接触的酸性矿山废水。
2. **Fe²⁺** 在较宽 pH 和较低 pE 区稳定——常见于地下水和水体底部缺氧水；一旦与大气接触（pE 升高）就会氧化沉淀为 Fe(OH)₃。
3. 固体 **Fe(OH)₃** 占据很大区域，反映铁(III)氢氧化物溶解度极低。
4. 固体 **Fe(OH)₂** 稳定区有限；多数水体该区实际是 FeS 或 FeCO₃。
5. **金属铁不稳定**：½Fe²⁺ + e⁻ ⇌ ½Fe，pE°=−7.45；在 [Fe²⁺]=1.0×10⁻⁵ 水中 pE=−7.45+½log[Fe²⁺]=−9.95，说明金属铁与水接触在热力学上不稳定，会还原水放 H₂ 并以 Fe²⁺ 溶入水中（即铁的腐蚀）。

## 4.10 Fenton 反应及应用（Ch.3 p50；见第一部分 A4）

Fe²⁺ + H₂O₂ → Fe³⁺ + OH⁻ + •OH；•OH 强氧化降解苯甲酸、苯酚等有机物；**不能处理 Cr(VI)**（需还原而非氧化）。光化学还可产生 O₂•⁻、H₂O₂ 再经 Fenton 生成 •OH（自然水中腐殖质受光激发驱动）。

## 4.11 ⭐光化学烟雾：洛杉矶烟雾机理（Ch.12；论述第29题）

**名称**：氧化型**光化学烟雾 (Photochemical smog)**——1944 年首先在洛杉矶 (Los Angeles) 被识别。
**三要素**：紫外光 (UV) + 碳氢化合物 (hydrocarbons) + 氮氧化物 (NOₓ)，加上停滞气团和强日照。
**关键反应（分三步默写）**：

**(1) 引发反应（产生 O₃）**
- NO₂ + hν (λ<398 nm) → NO + O
- O + O₂ + M → O₃ + M
- O₃ + NO → NO₂ + O₂　（此步通常把 O₃ 消耗掉，使 O₃ 维持低水平）

**(2) 自由基传递反应（碳氢化合物的关键作用）**
- RH + •OH → R• + H₂O　（脱氢/消去）
- R• + O₂ → ROO•　（生成过氧自由基）
- **ROO• + NO → RO• + NO₂**　（关键！过氧自由基把 NO 氧化为 NO₂，**不消耗 O₃**）
- 醛类生成：RO• + O₂ → R'CHO + HOO•；HOO• + NO → •OH + NO₂
- O、•OH、O₃ 进攻烃生成更多活性烃自由基（链增长）

> **核心机理一句话**：正常情况下 O₃ + NO → NO₂ 会把 O₃ 消耗掉；但碳氢化合物氧化产生的 ROO•/HOO• 自由基**抢先把 NO 氧化成 NO₂**（且不消耗 O₃），打破了 O₃–NO 平衡，于是 **O₃ 不断积累**，同时 NO₂ 再光解又产生 O 生成更多 O₃，形成恶性循环。

**(3) 终止反应（生成二次污染物）**
- •OH + NO₂ → HNO₃
- RC(O)OO• + NO₂ → RC(O)OONO₂（**PAN，过氧乙酰硝酸酯**）

**产物/危害**：O₃、PAN、醛类、HNO₃、硝酸盐、硫酸盐、有机气溶胶；刺激眼和呼吸道、伤害植物、腐蚀橡胶（O₃ 使橡胶开裂）、降低能见度。
**一天内物种变化（Ch.12 p17）**：清晨 NO、烃升高 → 上午 NO 转为 NO₂、醛类升高 → 中午前后 O₃/氧化剂达峰。
> 注意区分**伦敦烟雾**（还原型/硫酸型 smog，SO₂+煤烟+雾，1952 年伦敦事件 5 天多死约 4000 人，Ch.9 p20）与**洛杉矶光化学烟雾**（氧化型）。

## 4.12 ⭐臭氧层破坏：CFC 催化机理（Ch.8 p46；Ch.13 p57–61；简答第28题）

**平流层臭氧的正常平衡**：O₂ + hν(λ<242 nm) → 2O；O + O₂ + M → O₃ + M；O₃ + hν(220–330 nm) → O₂ + O（吸收有害 UV-B）。
**CFC 催化破坏 O₃ 的光化学反应**：
- CFC 极稳定，升入平流层被高能 UV 分解释放 Cl 原子（自由基）：
  $$\text{CF}_2\text{Cl}_2 + h\nu \rightarrow \text{Cl}^{\bullet} + {}^{\bullet}\text{CF}_2\text{Cl}$$
- **催化循环**：
  - Cl• + O₃ → ClO• + O₂
  - ClO• + O → Cl• + O₂
  - **净反应：O₃ + O → 2O₂**（Cl• 被再生，可重复破坏多达 ~10⁴ 个 O₃ 分子）
**南极臭氧洞 (1985)**：极地平流层云上 ClONO₂ + HCl → Cl₂ + HNO₃；春季 UV 照射 Cl₂ + hν → 2Cl•，集中破坏臭氧。
**对策**：1987(1986) **蒙特利尔议定书**禁产 CFC；替代品 HCFC（含 H，对流层即被 •OH 破坏）、HFC（无 Cl 但是温室气体）等。
**危害**：UV-B 增强 → 皮肤癌、白内障增多、损害作物和海洋浮游植物。

## 4.13 酸雨的形成与危害（Ch.10 p23；Ch.13 p54–56）

**形成**：
- 硫酸：FeS₂ 氧化或燃硫产生 SO₂ → 2SO₂ + O₂ → 2SO₃；SO₃ + H₂O → H₂SO₄（或液滴中 SO₂ + H₂O₂ → H₂SO₄）。
- 硝酸：NOₓ → NO₂ + •OH → HNO₃；N₂O₅ + H₂O → 2HNO₃。
- HCl：含氯有机聚合物燃烧。
**危害**：植物直接毒害、水体/土壤酸化、活化土壤 Al³⁺ 间接毒害、破坏敏感森林、腐蚀金属与石材（2H⁺ + CaCO₃ → Ca²⁺ + CO₂ + H₂O）、呼吸道影响。

## 4.14 温室效应与全球变暖（Ch.13 p43–51）

**机理**：入射太阳辐射以可见光为主（峰值~500 nm）；地表以红外（峰值~10 μm）向外辐射；CO₂、H₂O 汽、CH₄、N₂O 等**重新吸收向外的红外**→增温。
**主要温室气体**（京都议定书）：CO₂、CH₄、N₂O、HFCs、PFCs、SF₆、NF₃。CH₄ 单分子辐射强迫约为 CO₂ 的 25 倍。
**缓解（绿色科技）**：减少 CO₂ 排放（非碳能源、可再生/核电、氢能、提高能效、**碳封存**、碳税/碳交易）。

## 4.15 微生物介导反应的"次序"（Ch.5 p22–23，理解电子受体顺序）

有机物过量时（水含 O₂、NO₃⁻、SO₄²⁻、HCO₃⁻），微生物按**自由能从大到小**依次利用电子受体：
有氧呼吸 (O₂) → 反硝化 (NO₃⁻→N₂) → 硝酸盐还原 → 发酵 → 硫酸盐还原 (SO₄²⁻→H₂S) → 产甲烷 (CO₂→CH₄) → 固氮。
这解释了为什么湖泊底层/沉积物随深度由氧化逐渐转为还原，并出现 H₂S、CH₄。

## 5A　上传练习卷《Water & Atmospheric Chemistry》逐题精解

### Ⅰ. 单项选择

**1. 汽油车不会排放的气体 —— 答案：A（PAN）**
PAN（过氧乙酰硝酸酯，peroxyacetyl nitrate）是光化学烟雾中由烃 + NOₓ 在阳光下生成的**二次污染物（secondary pollutant）**，并非汽车直接排放。NO、CO、CO₂ 均为汽车尾气**一次污染物（primary pollutant）**。（Ch.11 p28；Ch.12 烟雾机理）

**2. 不是温室气体的是 —— 答案：D（NO）**
温室气体须能吸收地表红外：CO₂、CH₄、CF₄（全氟化碳 PFC，极强温室气体且寿命极长）、N₂O 都是；而 **NO（一氧化氮）**主要参与烟雾/臭氧化学，不是温室气体。注意陷阱：是 **NO** 而非 **N₂O**。（Ch.13 p44）

**3. 旧冰箱排放、缓慢破坏臭氧层的气体 —— 答案：B（C₂F₂Cl₂，即氯氟烃 CFC）**
CFC（含氯氟烃，chlorofluorocarbon）化学惰性、寿命长，升入平流层后被紫外解离出 Cl•，催化破坏 O₃。CO₂、SO₂、O₂ 不破坏臭氧层。（Ch.8 p46；Ch.13 p57）

**4. 去离子水中 Fe³⁺ 溶液最可能的 pH —— 答案：A（4.5）**
Fe³⁺ 是水合金属离子，水解放出 H⁺ 使水显**弱酸性**：Fe(H₂O)₆³⁺ ⇌ Fe(H₂O)₅(OH)²⁺ + H⁺。稀 Fe³⁺ 溶液约 pH 4–5，不是中性(7)、不是强酸(0)、更非碱性(10.5)。（Ch.2 酸度；Ch.3）

**5. 富营养化(eutrophication)的成因 —— 答案：C（水体营养物过度丰富）**
富营养化是 N、P 等营养盐过量 → 藻类暴发 → 死亡分解耗氧。A 杀虫剂、B 氟、D 为 PAN 伤叶，均无关。（Ch.2 p12；Ch.6 p15）

**6. 关于酸雨正确的是 —— 答案：D（具腐蚀性 corrosive）**
酸雨呈酸性、**氧化性**（非还原性，排除 A）；并非只在冬季形成（排除 B）；"烟+雾"是 smog 而非酸雨（排除 C）。酸雨腐蚀金属与碳酸盐石材：2H⁺ + CaCO₃ → Ca²⁺ + CO₂ + H₂O。（Ch.13 p54–56）

**7. 腐殖质(humus)是 —— 答案：B（由动植物残体形成的黑色软物质）**
腐殖质是土壤/水体中动植物残体经微生物降解再聚合形成的难降解有机物（腐殖酸 humic acid、富里酸 fulvic acid、胡敏素 humin）。（Ch.2 p55–56；Ch.15 土壤）

**8. 下列何种污染水"电子活度低/还原性"—— 答案：C（H₂S）**
H₂S 是强**还原剂（reductant）**，其污染水为还原性体系、**pE 低**（氧化能力弱）；Cl₂ 是强氧化剂(高 pE)；NaOH、NaCl 不涉氧化还原。
> 辨析：pE ≡ −log{e⁻}。**pE 低 ⇔ 还原性强**（电子易于给出）。本题考"识别还原性水体"，H₂S 是典型还原剂，故选 C。（Ch.3 pE）

**9. 藻类与真菌共生体 —— 答案：C（地衣 Lichen）**
地衣＝真菌(fungi)+藻类/蓝细菌(algae)的共生体(symbiosis)，是岩石风化的先锋生物。（Ch.5；Ch.14 风化）

**10. 反应 C₄H₈(CO₂H)… + 3O₂ → 短链酸 + 2CO₂ + 2H₂O 属于 —— 答案：D（β-氧化 Beta-oxidation）**

### Ⅲ. 简答题（要点式参考答案）

**20. Hg、Pb、HF 的环境化学行为**
- **汞 Hg**：来源——燃煤、氯碱、采金、火山。转化——无机 Hg 在厌氧底泥被微生物**甲基化（methylation）**生成 CH₃Hg⁺（甲基汞，脂溶、剧毒神经毒）。效应——沿食物链**生物放大**，引发水俣病(Minamata)。归趋——甲基汞富集于鱼体；可被去甲基化或随颗粒沉降。
- **铅 Pb**：来源——历史含铅汽油(四乙基铅 TEL)、采矿冶炼、铅蓄电池、含铅涂料。转化——多以 Pb²⁺、与硫/磷/碳酸根结合，迁移性较低。效应——神经毒性，损害儿童智力、造血系统。归趋——富集于土壤、沉积物及人骨。
- **氢氟酸 HF**：来源——铝冶炼、磷肥、玻璃/陶瓷、燃煤。行为——气态 HF 活性强，可被植物叶片吸收致**叶尖/叶缘坏死**，经牧草进入家畜引起**氟骨症/斑釉齿(fluorosis)**；腐蚀玻璃：SiO₂ + 4HF → SiF₄↑ + 2H₂O。
> 详见**第二部分**对应条目。（Ch.1 p35–36 Hg；Ch.6 p5–6 重金属；Ch.10 p26–28 HF）

**21. POPs 是什么？为何出现在偏远北极？**
POPs＝**持久性有机污染物（Persistent Organic Pollutants）**，特征"持久、生物累积、长距离迁移、高毒(3 个以上)"，如 DDT、PCBs、二噁英。出现于无源头的北极是因**全球蒸馏/分馏效应（global distillation / grasshopper effect）**：在温暖中低纬度挥发进入大气，随气流向极地输送，在寒冷高纬度**冷凝沉降**并蓄积，故"千里之外却在洁净极地检出"。（Ch.11 p3–4；Ch.6 p48,54）

**22. Fenton 反应方程式；如何降解苯甲酸/苯酚；能否处理 Cr(VI)？**
关键反应：**Fe²⁺ + H₂O₂ → Fe³⁺ + OH⁻ + •OH**。生成的**羟基自由基 •OH** 氧化性极强(E°≈2.8 V)，无选择性地攻击苯甲酸、苯酚等有机物的芳环与侧链，逐步开环、矿化为 CO₂ + H₂O。
**不能用于处理 Cr(VI)**：Cr(VI)(如 CrO₄²⁻)本身是氧化态污染物，去除需**还原**为 Cr(III) 再沉淀 Cr(OH)₃；而 Fenton 提供的是**氧化**性 •OH，方向相反、无效甚至无益。（Ch.3 p50–51）

**23. CEC 定义；导致沉积物 CEC 下降的情景**
CEC＝**阳离子交换容量（Cation Exchange Capacity）**，指单位质量固体所能吸附/交换的阳离子总量，单位 **meq/100 g**（毫克当量/100克）。测定：用 NH₄⁺ 饱和交换位点，再用 NaCl 置换并测 NH₄⁺。
**下降情景**：黏土矿物或有机质(腐殖质)含量减少、沉积物被粗砂稀释、**pH 降低**(可变电荷位点质子化、净负电荷减少)、矿物风化破坏层状结构等，都会使 CEC 下降。（Ch.4 p28–29；Ch.14 p11–13）

**24. 铝离子溶解产生中等酸性——方程式与解释**
**Al(H₂O)₆³⁺ ⇌ Al(H₂O)₅(OH)²⁺ + H⁺**（可简写 Al³⁺ + H₂O ⇌ Al(OH)²⁺ + H⁺）。高电荷小半径的 Al³⁺ 极化配位水分子，使其 O–H 键减弱、释放 H⁺，即**水合金属离子水解酸化**，因此富 Al³⁺ 的酸性土壤/酸化水体呈中等酸性。（Ch.15 p9–10）

**25. BOD 全称与解释**
BOD＝**生化需氧量（Biochemical Oxygen Demand）**，指水中微生物在好氧条件下分解有机物所消耗的溶解氧量（常用 BOD₅：20 ℃ 培养 5 天），单位 mg/L。BOD 越高表示可生物降解有机污染越重、耗氧越多，易致水体缺氧。（Ch.2 p13；Ch.6 p17–20）

**26. 碱度是什么？天然水碱度主要来源？大气 CO₂ 升高碱度会升高吗？**
**碱度（alkalinity）**＝水中接受质子(中和酸)的能力：[Alk] = [HCO₃⁻] + 2[CO₃²⁻] + [OH⁻] − [H⁺]。天然水碱度主要来源是**碳酸氢盐 HCO₃⁻**（其次碳酸盐、氢氧根），多由 CO₂ 溶解风化碳酸盐岩(CaCO₃)而来。
**CO₂ 升高时**：CO₂ + H₂O ⇌ H⁺ + HCO₃⁻ 同时增加 H⁺ 与 HCO₃⁻，二者对碱度贡献相消，故**纯水体系碱度基本不变**(pH 下降)。**但若有固相 CaCO₃ 可溶解**(CaCO₃ + CO₂ + H₂O → Ca²⁺ + 2HCO₃⁻)，则碱度会**升高**。（Ch.2 p21,p26）

**27. 农药→鱼→不可食用：术语与机理**
术语：**生物放大（biomagnification）**（伴随生物富集 bioaccumulation/bioconcentration）。机理：脂溶、难降解的农药(如 DDT)经食物链逐级传递，因不易代谢排出而在**高营养级**生物体内浓度**逐级放大**，鱼体浓度远高于水中，达到危害人体的水平，故不宜食用。（Ch.6 p21 BCF/BAF）

**28. CFC 催化破坏臭氧的光化学反应**
- 引发：CF₂Cl₂ + hν → Cl• + •CF₂Cl
- 催化循环：Cl• + O₃ → ClO• + O₂；　ClO• + O → Cl• + O₂
- **净反应：O₃ + O → 2O₂**（Cl• 再生，单个 Cl 可破坏上万个 O₃）
（南极臭氧洞：ClONO₂ + HCl → Cl₂ + HNO₃，春季 Cl₂ + hν → 2Cl•。）（Ch.8 p46；Ch.13 p57–61）

**S1**　亨利定律：恒温下气体在液体中的溶解度与其在气相中的**分压成正比**：[X(aq)] = K_H·P_X。升温使 K_H 减小（气体溶解度随温度升高而降低），故夏季或热污染时水中溶解氧降低，叠加升温加速耗氧的生化反应，水体更易缺氧。（Ch.2 p15–20；Ch.6 p17）

**S3**　富营养化＝水体中 N、P 等营养盐过量，导致藻类/浮游植物暴发(水华/赤潮)，死亡分解大量耗氧，DO 骤降、鱼类死亡、水质恶化。淡水中**限制性营养元素通常是磷(P)**。危害：缺氧、毒藻、生物多样性下降、供水受损。（Ch.2 p12；Ch.6 p15）

**S4**　BOD＝生化需氧量(微生物降解有机物耗氧)；COD＝化学需氧量(强氧化剂氧化所有可氧化物耗氧)；TOC＝总有机碳(直接测有机碳量)。大小关系一般 **COD ≥ BOD**（化学氧化更彻底，还包括难生物降解物），TOC 以碳计单位不同但可与前两者正相关。（Ch.6 p17–20）

**Ⅳ. 论述**

**L1**　**自然平衡(Chapman 循环)**：O₂ + hν(λ<242 nm) → 2O；O + O₂ + M → O₃ + M（生成）；O₃ + hν(220–330 nm) → O₂ + O；O + O₃ → 2O₂（消耗）。生成与消耗动态平衡，使平流层维持臭氧层并吸收 UV-B。
**CFC 破坏**：CFC 惰性升入平流层，被高能 UV 解离：CF₂Cl₂ + hν → Cl• + •CF₂Cl；催化循环 Cl• + O₃ → ClO• + O₂，ClO• + O → Cl• + O₂，净 O₃ + O → 2O₂，单个 Cl• 可破坏上万 O₃。
**南极臭氧洞**：极地平流层云(PSC)表面冬季积累 ClONO₂ + HCl → Cl₂ + HNO₃；春季阳光 Cl₂ + hν → 2Cl•，集中爆发性破坏臭氧。
**对策**：1987 年(1986)**蒙特利尔议定书**逐步禁用 CFC、哈龙；改用 HCFC（对流层即被 •OH 分解）、HFC（无 Cl）等。（Ch.8 p46；Ch.13 p57–61）

**L2**　主要平衡：CO₂(aq) + H₂O ⇌ H₂CO₃ ⇌ H⁺ + HCO₃⁻ (K₁)；HCO₃⁻ ⇌ H⁺ + CO₃²⁻ (K₂)；碱度 [Alk] = [HCO₃⁻] + 2[CO₃²⁻] + [OH⁻] − [H⁺]。
**封闭体系**加 CO₂：CO₂ + H₂O → H⁺ + HCO₃⁻，H⁺ 增加 → **pH 下降**；但同时增加的 H⁺ 与 HCO₃⁻ 对碱度的贡献相互抵消，**碱度不变**(若无固相溶解)。
**开放体系/有 CaCO₃**：CaCO₃ + CO₂ + H₂O → Ca²⁺ + 2HCO₃⁻，溶解碳酸盐 → HCO₃⁻ 增加 → **碱度升高**，pH 缓冲。结论：大气 CO₂ 上升主要降低无缓冲水体 pH(酸化)，对含碳酸盐水体则可通过溶解 CaCO₃ 提高碱度。（Ch.2 p21–26）

**L3**　**来源**：燃煤、氯碱工业、采金、火山、含汞废弃物。**形态转化**：水中以 Hg⁰、Hg²⁺、HgS、Hg(OH)₂ 等存在，氧化还原与 pH 控制其形态。**生物甲基化**：厌氧底泥中产甲烷/硫酸盐还原菌将 Hg²⁺ 转为脂溶性 CH₃Hg⁺、(CH₃)₂Hg。**生物放大**：甲基汞穿膜易、难排出，沿食物链(浮游生物→小鱼→大鱼)逐级放大，顶级鱼类浓度可达水体上万倍，致水俣病。**归趋**：随颗粒沉降入底泥、随鱼体迁出、部分挥发或被去甲基化。**防治**：源头削减(脱汞)、底泥治理/原位钝化、控制厌氧甲基化条件、对鱼类设食用限值。（Ch.1 p35–36；Ch.6 p5–6,p21）

**T1**　以氮循环为例，主要环节：**固氮**(N₂→NH₃) → 同化(植物吸收) → **氨化**(有机氮分解为 NH₄⁺) → **硝化**(NH₄⁺→NO₂⁻→NO₃⁻) → **反硝化**(NO₃⁻→N₂ 返回大气)。生物地球化学循环即元素在大气–水–土–生物各库间循环转化。（Ch.1 p22–27；Ch.5 p30）

**T2**　配位体(ligand)：能向中心金属提供孤对电子的分子/离子(Lewis 碱)；配位数(coordination number)：中心离子直接键合的配位原子数目；螯合物(chelate)：多齿配体与同一金属形成**环状结构**的配合物，比单齿配合物更稳定(螯合效应)。（Ch.2 p27–35）

**T3**　pE 形式：**pE = pE° + (1/n)·log([Ox]/[Red])**。与电极电势关系(25 ℃)：pE = Eh / 0.0592（Eh 单位 V），即 Eh = 0.0592·pE；pE/Eh 越高越氧化。（Ch.3 p17–19）

**T4**　生物富集(BCF)：生物**直接从水/介质**吸收并浓缩污染物，体内/水中浓度比；生物累积：经**多种途径(水+食物)**在生物体内随时间累积；生物放大：污染物沿**食物链逐级传递**，高营养级浓度逐级放大。（Ch.6 p21）

**T5**　HF 危害：对植物使**叶尖、叶缘坏死(necrosis)**，经牧草富集进入家畜引起**氟骨症/斑釉齿(fluorosis)**；腐蚀玻璃反应：**SiO₂ + 4HF → SiF₄↑ + 2H₂O**。（Ch.10 p26–28）

**T6**

| | 伦敦型(硫酸型/还原型) | 洛杉矶型(光化学/氧化型) |
|---|---|---|
| 成因 | SO₂ + 煤烟 + 雾 | 烃(VOCs) + NOₓ + 紫外光 |
| 季节/时间 | 冬季、清晨、低温高湿 | 夏秋、中午前后、强日照 |
| 化学性质 | 还原性 | 氧化性 |
| 主要污染物 | SO₂、硫酸雾、颗粒物 | O₃、PAN、醛、硝酸盐 |

（Ch.9 p20；Ch.12 p18–21）

**T7**　硝酸生成：NO₂ + •OH → HNO₃；N₂O₅ + H₂O → 2HNO₃；3NO₂ + H₂O → 2HNO₃ + NO。NOₓ 经大气氧化生成 HNO₃，是**酸雨中硝酸的来源**(与 SO₂→H₂SO₄ 并列两大酸)。（Ch.10 p23；Ch.13 p54–56）

**T8**　三效催化器在 Pt/Pd/Rh 催化下同时进行：氧化 2CO + O₂ → 2CO₂、CₓHᵧ + O₂ → CO₂ + H₂O；还原 2NO + 2CO → N₂ + 2CO₂。需将空燃比控制在化学计量比附近(λ≈1)，氧化与还原才能同时高效进行。（Ch.12 p9）

**T9**　LD₅₀＝**半数致死剂量(median lethal dose)**，指使受试群体 50% 死亡的剂量(mg/kg 体重)。**数值越小、毒性越大**(达到致死所需剂量越少)。（Ch.22 p34）

**T10**　合成氨：**N₂ + 3H₂ ⇌（高温高压、Fe 催化）2NH₃**。意义：人工固氮支撑化肥与全球粮食生产；但能耗巨大(化石能源)、过量氮肥流失致水体**富营养化**、并增加 N₂O(强温室气体)排放。（Ch.15 p20–23）

**Ⅳ. 论述**

**P1**　**来源**：燃煤(含硫)、有色冶炼(焙烧硫化矿)、火山。**转化**：气相 2SO₂ + O₂ →(尘/光催化) 2SO₃，SO₃ + H₂O → H₂SO₄；液相 SO₂ + H₂O₂ → H₂SO₄（云雾中主导）。**酸雨/烟雾**：H₂SO₄ 是酸雨主成分，也是伦敦还原型烟雾元凶。**效应**：刺激呼吸道、水/土酸化、腐蚀碳酸盐石材与金属、伤害植物。**治理**：燃前洗煤脱硫；钙基湿法脱硫 SO₂ + CaCO₃ → CaSO₃ + CO₂，2CaSO₃ + O₂ → 2CaSO₄(石膏回收)；另有双碱法、氨法、活性炭法等。（Ch.10 p5–13；Ch.13 p54–56）

**P2**　以电对的能斯特方程定边界：①水氧化限 ¼O₂ + H⁺ + e⁻ ⇌ ½H₂O，pE = 20.75 − pH；②水还原限 H⁺ + e⁻ ⇌ ½H₂，pE = −pH；③金属电对(如 Fe³⁺ + e⁻ ⇌ Fe²⁺)给水平线 pE = pE°(=13.2)，含氢氧化物沉淀的边界(如 Fe(OH)₃/Fe²⁺)随 pH 倾斜(pE = 22.2 − 3pH)。把各线绘于 pE–pH 平面即得各物种稳定区，全部落在①②之间(水的稳定域)。天然水 pE 介于约 −10(强还原底泥)到 +17(充氧表层水)之间：表层充氧水高 pE(氧化)，深层/底泥低 pE(还原)。（Ch.3 p32–48）（完整铁系推导见 4.10）

**P3**　**三要素**：紫外光 + 烃(VOCs) + NOₓ。**引发**：NO₂ + hν → NO + O；O + O₂ + M → O₃ + M；O₃ + NO → NO₂ + O₂(三者本构成 O₃–NO 光稳态)。**链传递**：RH + •OH → R• + H₂O；R• + O₂ → ROO•；**ROO• + NO → RO• + NO₂**——此步**不消耗 O₃** 就把 NO 氧化成 NO₂，破坏了原"O₃ + NO → NO₂"对 O₃ 的消耗通道，于是 O₃ 不断净生成、**积累**(同时醛、PAN 等生成)。**终止**：•OH + NO₂ → HNO₃；CH₃C(O)OO• + NO₂ → PAN。**防治**：削减机动车/工业 VOC 与 NOₓ 排放、安装催化转化器、改进燃料与燃烧、错峰限行。（Ch.12 p18–21）（详见 4.11）

### Ⅱ. 计算专项（务必掌握解题步骤）

**计算 1（亨利定律 / 溶解氧）**　某湖水 25 ℃ 与空气平衡，O₂ 分压 ≈ 0.21 atm，K_H(O₂)=1.28×10⁻³ mol·L⁻¹·atm⁻¹。求溶解氧浓度(mg/L)。
解：[O₂] = K_H·P_O₂ = 1.28×10⁻³ × 0.21 = 2.69×10⁻⁴ mol/L；
换算质量浓度：2.69×10⁻⁴ mol/L × 32000 mg/mol ≈ **8.6 mg/L**（与饱和 DO ~8.3 mg/L 吻合）。（Ch.2 p15–20）

**计算 2（ppm ⇄ mol/L）**　0.5 L 废水含 50 mg Pb²⁺，求质量浓度(ppm)与摩尔浓度。
解：50 mg ÷ 0.5 L = 100 mg/L = **100 ppm**；
摩尔浓度 = 100 mg/L ÷ 207000 mg/mol ≈ **4.8×10⁻⁴ mol/L**。（Ch.6）

**计算 3（pE–pH 边界推导）**　由水的氧化限 ¼O₂ + H⁺ + e⁻ ⇌ ½H₂O，pE° = +20.75，P_O₂ = 1 atm，推导 pE 关于 pH 的方程。
解：pE = pE° + log{ [H⁺]·(P_O₂)^{1/4} } = pE° + log[H⁺] = 20.75 − pH。
同理还原限 H⁺ + e⁻ ⇌ ½H₂(P_H₂=1)：pE = −pH。二者即天然水稳定域的上、下边界。（Ch.3 p32–35）

**计算 4（原子经济性）**　比较两反应的原子经济性(AE)：
(a) 加成：C₂H₄ + Br₂ → C₂H₄Br₂　→ 唯一产物即目标物，**AE = 100%**。
(b) 取代：CH₃Br + NaOH → CH₃OH + NaBr　→ AE = M(CH₃OH) / [M(CH₃OH)+M(NaBr)] = 32 / (32 + 103) ≈ **23.7%**。
结论：加成/重排反应原子经济性高、最绿色；取代/消除产生大量副产物 NaBr，浪费原子。（Ch.16–17 p16–17）

### Ⅲ. 概念巩固简答（每题 3 分）

**G1** 绿色化学 12 原则（任举 5 条）：①预防污染优于治理；②原子经济性最大化；③低毒/无毒合成；④设计更安全的化学品；⑤用更安全的溶剂与助剂；⑥提高能效(常温常压)；⑦使用可再生原料；⑧减少衍生化步骤；⑨催化优于化学计量试剂；⑩设计可降解产品；⑪实时监测防污染；⑫本质安全防事故。（Ch.16 p4–7）

**G2** E-因子(E-factor)＝**生产单位质量产品所产生废物的质量**＝(废物总质量 ÷ 目标产品质量)。E 越小越绿色；精细化工/制药 E 值远高于大宗化工。（Ch.17 p16–17）

**G3** RCRA 危险废物四大特性：**易燃性(ignitability)、腐蚀性(corrosivity, pH≤2 或 ≥12.5)、反应性(reactivity)、毒性(toxicity, 含 8 种毒性金属等)**。（Ch.19–23）

**G4** 致畸物(teratogen)致后代**先天畸形**；致突变物(mutagen)引起**DNA/基因突变**(可遗传);致癌物(carcinogen)诱发**癌症**。三者机理与终点不同，但常有交叉(许多致突变物也是致癌物)。（Ch.22–23）

**G5** 风化(weathering)三类：**物理风化**(温差、冻融、磨蚀，仅碎裂不变成分)；**化学风化**(水解、氧化、溶解、碳酸化，改变矿物成分，如长石→黏土)；**生物风化**(根系、地衣分泌酸、生物扰动)。（Ch.14 p16–20）

**G6** 卡诺效率 η = 1 − T_c/T_h(开尔文)，提高 T_h、降低 T_c 或采用热电联产/燃料电池可提高能效；**燃料电池**通过电化学(如 H₂ + ½O₂ → H₂O)将燃料化学能**直接**转为电能，不受卡诺循环限制，效率高、污染小。（Lec.18 p18,21）
